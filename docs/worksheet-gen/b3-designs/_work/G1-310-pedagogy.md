## B. THE SIX FACES

**Shared geometry.** A fragment is a set of cells on a local grid inside a bounding box <= 4 wide x 3 tall (d3 4x4 at cell 48). Cell value from the anchor `a` at local `(ar, ac)`: `v(r,c) = a + 10*(r-ar) + (c-ac)`; a cell's chart column is `col(v) = (v - start) % 10`. **Legality (the trap):** every cell needs `start <= v <= end` AND `col(a) + (c-ac)` in `0..9`: a piece never wraps a row edge (anchor 20 with a right neighbour is ILLEGAL though 21 exists). Shapes (4-connected, explicit cell lists per rotation, never computed): `sq3` (9) · `plus` (5) · `L3` (5, 4 rotations) · `T3` (5, 4 rotations) · `bar-h3` / `bar-v3` (3, d1) · `sq2` (4, d1) · `S/Z` (4, d3) · `sq3-holes` (7, d3) · `rect4x3` (12, d3). **No number appears twice on one page**, printed or hidden (an anchor of piece B must never hand over a blank of piece A): FORBIDDEN (P3).

**NEW primitive `primitives/chart-fragment.js`** (pure SVG on the tokens, the `hundreds-chart.js` cell idiom): `chartFragment({cells, anchor:[r,c], value:a, start, end, cell:60, mode:'anchor'|'full'|'error', badge?})` -> `{svg, meta, width, height}`. Anchor cell = `creamDeep` fill + numeral `data-lcs-anchor`; blank cells = the G1-129 dashed coral write-in cell (`data-lcs-cell-rc="r:c"`, NO value stamped as text); `full` prints every value (`data-lcs-cell`); `error` prints one stamped wrong value (`data-lcs-wrong`) and never the right one; root stamps `data-lcs-prim="chart-fragment" data-lcs-anchor-rc data-lcs-value data-lcs-start data-lcs-end data-lcs-cells`. Reused: `cardGrid`, `answerBox({w,h})` (`templates/components.js:105`), the `GIVEN` chip of `neighbors.js:9` (`tealSoft`), `hundredsChart({start,end,missing,cell})` for F1. Floors G1 44 / 26 / 6-12, G2 36 / 22 / 8-16 (`_tokens.js:69-71`).

### verify() rules (browser; every value re-derived from stamps, never read from text)
- Common: root `<div data-ws-content data-lcs-start data-lcs-end>`; for each `[data-lcs-prim="chart-fragment"]` rebuild `v(r,c)` from `data-lcs-value` + `data-lcs-anchor-rc` over `data-lcs-cells`; assert `start <= v <= end` and `0 <= col(anchor) + (c - ac) <= 9` for every cell (P1, P2); the shape is 4-connected; **the multiset of all values on the page (printed + hidden) has no duplicate** (P3); printed `<text>` equals its stamp; no `<text>` on the page equals a hidden value; `[data-lcs-cell-rc]` cells contain no text; piece count === `d.pieces`.
- F0: exactly one anchor per piece; blanks per piece 4-8 at d2 (`sq3` = 8); `anchorAt:'centre'` at d1 => every blank one move from the anchor.
- F1: chart `[data-lcs-cell]` set === the declared guides; piece cells map to chart cells `(row(v), col(v))`, none a guide cell, pairwise disjoint (P6); each piece's printed values are mutually position-consistent; letters A-D once each.
- F2: fold the arrow list from `data-lcs-start`: after every step `start <= v <= end`; a `>` step from `col 9` or a `<` step from `col 0` is a FAIL (P5, the map must stay honest); landing === `data-lcs-answer`; 8 distinct starts; arrows per item === `d.arrows`.
- F3: both clues resolve to the same `data-lcs-answer` (P7); `m1 !== m2`; neither clue's printed number equals the answer; the answer text appears nowhere on the page; clue kinds at d2 = one `10` and one `1`.
- F4: exactly one `[data-lcs-wrong]` per piece (P4), its stamped value !== `v(r,c)` and in `errorKinds` of `v`; cells >= 5 so the majority identifies the error uniquely (a 2-cell piece is ambiguous: FAIL); the right value is not printed anywhere; d3 `cleanPieces` count matches.
- F5: `rowsDown = row(B) - row(A)`, `colsRight = col(B) - col(A)` === the two `data-lcs-answer`s; at d2 both >= 1 (P9); at d1 exactly one is 0; A !== B.
