Keyword strategy must target long-tail, intent-specific queries — NOT broad head terms.

**Why:** Broad terms like "addition worksheets" or "word search worksheets" are dominated by established educational sites. We can't compete there. Our actual differentiator — a tool for CREATING worksheets to SELL on Etsy/KDP/TPT — is a niche where big educational sites don't play. That's where we should be laser-focused.

**How to apply:**
- NEVER target broad consumer keywords like "addition worksheets," "coloring pages," "word search puzzles"
- ALWAYS target long-tail seller-intent keywords like:
  - "printable word search generator with custom words Etsy"
  - "make your own addition worksheets with pictures"
  - "worksheet generator for selling on teachers pay teachers"
  - "create custom [product type] to sell on [platform]"
- Primary keywords should combine: [product type] + [creation intent] + [platform/selling context]
- Secondary keywords should include specific use-case modifiers: "with custom words," "with pictures," "commercial license," "bulk create"
- The keyword fingerprint should scream "I want to CREATE and SELL" not "I want to USE"
- This applies to ALL page types, ALL locales, ALL content files
- Existing content with broad keywords should be revised when touched
