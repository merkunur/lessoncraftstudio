- `G1-410` Read and Color: All Mixed Up — Read each sentence. Find its pictures in the big box and color exactly as many as the sentence says. · picture themes (scripts/worksheet-gen/types/g1/G1-410-read-and-color-the-picture.js)
- `G1-411` Read and Color: Stop at the Number — There are more pictures than the sentence asks for. Read the number and color only that many. · picture themes (scripts/worksheet-gen/types/g1/G1-411-read-and-color-stop-at-the-number.js)
