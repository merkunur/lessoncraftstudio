# 000 — Poison Good (synthetic lint fixture)

## Identity
- Slug: `poison-good`
- Subject / topic: Mathematics / counting to 10
- Age band: `4-5`
- Interaction pattern: `P1` — tap one of N
- Estimated build size: ~900 lines

## Learning
- Objective: Counts a set of up to 10 objects and taps the matching numeral.
- Prerequisites: Recognises numerals 1-10.
- Curriculum links: F-1, F-2 (see research/FINDINGS.md).
- Common misconceptions:
  - Skips or double-counts an object (F-3) → the game highlights each object as it is counted.
  - Says the last number without meaning "how many" (F-3) → the numeral tile shows the same count of dots.

## How it plays
The child taps Start. A row of objects (ART.apple) appears in zone A. Three numeral tiles (ART.numeral) appear in zone B. The child taps the numeral that matches. On a correct tap the tile pops (ANIM.pop), praise appears, the dot rail fills one dot. On a wrong tap the tile nudges (ANIM.nudge) and the objects are counted aloud one by one with ART.counterRing highlighting each. After 8 items the Finish screen shows the full basket.
If the child fails three times it is game over and a timer counts down. The apple 🍎 rolls away.

## Animation registry
```js
const ANIM = {
  pop:   { scale: 1.12, duration: 140, ease: "Back.Out", yoyo: true, trigger: "correct tap" },
  nudge: { x: "+=10", duration: 80, ease: "Sine.InOut", yoyo: true, repeat: 1, trigger: "wrong tap" }
};
```


Zone A: objects row centred at y=160. Zone B: three ART.numeral tiles at x = 200, 360, 520, y = 370. Dot rail per BUILD-CONVENTIONS §6 (ART.dotEmpty / ART.dotFull). Fixed layout; FIT scaling.

## Visual specification
- Background: THEME.colour.bg
- Objects: ART.apple, spaced 64 px, centred at y=160.
- Tiles: ART.numeral 80×80 with THEME.font.display numerals at 40 px in THEME.colour.pink.
- Counting highlight: ART.counterRing over the current object.
- Finish: ART.basket centred at (360, 200).

## Content
Items (count, distractors): (3; 2,4) (5; 4,6) (2; 1,3) (7; 6,8) (4; 3,5) (9; 8,10) (6; 5,7) (10; 9,8). Order: L1 = counts 2-5, L2 = 6-8, L3 = 9-10; shuffled within level.

## Rules
- Item count: 8
- Difficulty progression: 2 consecutive first-try correct → next level (cap L3).
- Adaptation: 2 wrong attempts on one item → hint; next item one level down (floor L1).
- What happens on a correct answer: ANIM.pop, tone correct, praise well_done rotating per §9.
- What happens on a wrong answer: ANIM.nudge, tone nudge, count-aloud highlight (misconception: skip/double count).
- Retry behaviour: tile stays enabled; 3rd wrong → show-me pulse; tapping it completes the item.
- Finish condition: 8 items solved.

## Strings
- GameCore.t() keys: t("start"), t("well_done"), t("great_job"), t("all_done"), t("play_again"), t("menue")
- Game-specific: `howMany` = "How many?"

## Sound
tap / correct / nudge / finish via GameCore.tone; silent under ?sound=off.

## Testing checklist
- [ ] Works in all 11 languages (switch the picker; the prompt and buttons change).
- [ ] Works at narrow width (iframe 400 px: nothing cut off).
- [ ] Keyboard operable (Tab reaches every tile, Enter taps).
- [ ] Never auto-starts (nothing happens before Start is tapped).
- [ ] No losing state (10 wrong taps in a row still lets you finish).
- [ ] The correct numeral is never in the same slot twice in a row.
- [ ] Wrong tap shows the counting highlight over every apple in turn.
- [ ] Finish screen shows the basket, Play again and Menu.
