## Concept & creative hook
**The Sunny-Side Diner.** The child is the waiter; a customer speaks a compound order over the brass order-rail ("I'd like *two pancakes* **and** *a milk*, please"). The authentic act: **listen → gather → say it back complete → get the smile.**
- **Two phases, one act — the tray ALONE never satisfies (the central honesty ruling):**
  - **Phase 0 — Tray-gather (SL.K.2):** the customer speaks item-by-item, each item materializes on a **visible picture order-pad** synced to TTS; the child gathers the matching food onto a **tray** (forgiving palette). Externalizes listening span — NOT a memory test, NOT the win. Tray matches → *"That looks right… now tell me my whole order!"* (food gathered, **nobody smiling yet** — comprehended, not yet produced).
  - **Phase 1 — Read-back (the L.K.1.F GATE), KEYSTONE fix #1:** when the read-back opens **the order-pad MODEL HIDES** (pictures flip face-down / fade to silhouettes / a blank ticket) so there is **no legible sentence-model to copy**; what REMAINS is the **gathered tray-OBJECTS**. The child must PRODUCE "I'd like two pancakes and a milk, please" from those objects: reference scaffolded (no memory confound on *what*), but the LANGUAGE (quantity words, agreeing plural, frame, conjunction) GENERATED, not transcribed. This is the line between an honest L.K.1.F game and a matching game.
- **Headline premium move — the conjunction is a COUPLER (Designer B's gift):** the read-back frame shows the two clause-halves visibly **APART** with a gap (`two pancakes` | gap | `a milk`); they **only snap together when the golden "and" coupler chip is placed** (a *clank* + flush-slide). Until then the order can't travel to the customer. Drop the "and" → the customer hears **only the first half re-voiced** with a questioning lilt + the coupler glints ("let's join them — two pancakes **and** a milk"). **The dropped conjunction is AUDIBLE + VISIBLE** — load-bearing-ness made physical, not just a validation rule.
- **Character-drives-pedagogy (variety diegetic, never a difficulty dial):** Shy Mouse forgets → the "and one more thing…" live extension; Hungry Bear → counts; Fussy Cat changes her mind / wants contrast → swap + the G1 correlative ceiling; Trainee Robot reads orders back WRONG → the repair beats (the robot is puzzled, never the child).
- **Anti-generic:** NOT a listening-comprehension + counting game with a read-back bolted on — (a) the read-back PRODUCES from objects (model hidden) → generation not copying; (b) the coupler + robot-repair + live-extension are THREE distinctive moves (not one toy + filler); (c) a board ships only if the gate proves the drop-the-conjunction AND right-tray-no-sentence solvers FAIL and the anti-copying invariant holds.

## Core loop & the 7 distinct experiences
**Loop:** customer speaks the order item-by-item onto the visible pad (+ the "and" connector animates in at the seam) → penalty-free **replay** → child gathers the **tray** (forgiving; count badges; **cannot hard-block** — after N attempts the customer diegetically completes it, so the primary L.K.1.F is never gated behind the co-primary, fix #3) → **the order-pad model HIDES, tray-objects remain** (fix #1) → child assembles the **sentence-frame** from chips (each spoken back), places the **coupler** to snap the halves → **"Say it back" lights on STRUCTURAL COMPLETENESS** (all required slots filled + coupler placed), **NOT correctness** (fix #4) → TTS voices it → correct→customer beams; **complete-but-wrong → still voiced + the customer responds DIEGETICALLY** ("hmm, I didn't order juice…"), loops with no fail state (never a hot-cold combination lock) → `ctx.correct()` once → a happy plate joins the vessel → reshuffle.

**The 7 distinct experiences (fix #2/#9 — distinct = a different PRODUCTION ACT, not a new food list; the former join-two/quantity/reproduce/expand-fragment collapse into ONE; add-conjunction collapsed into repair):**
| # | Production ACT (what the child GENERATES) | Render / distinct surface | Why non-guessable |
|---|---|---|---|
| **A ★** | **Assemble-from-scratch** — the full compound from the gathered objects (spine; the coupler is placed here). join-two / quantity-phrase / reproduce / expand-fragment ride here as emphasis | model hidden, tray-objects remain; the apart-halves frame + coupler | model hidden → PRODUCTION not copying; near-cousin distractor chips (milk AND juice; pancakes AND waffles); coupler obligatory |
| **B ★** | **Insert-the-missing-conjunction** (the pure coupler beat) — two halves present but APART, add the "and" | gap-slot empty, both halves filled | drop-the-conjunction IS the whole task; the halves won't join |
| **C ★** | **Repair-the-robot's-wrong-ITEM** — the Trainee Robot dropped/swapped a food; fix it | the robot's broken read-back; child repairs | the repair IS the expand act; the engine validates the COMPLETED form, child must GENERATE the fix |
| **D** | **Repair-the-robot's-wrong-AGREEMENT/COUNT** — the robot said "a pancake" for a two-order; fix to "two pancakes" (distinct from item repair) | the quantity slot wrong; child corrects the number word | per-item exact count load-bearing; agreement voiced correctly on fix |
| **E ★** | **Extend-mid-order ("and one more thing…")** — after a complete read-back, Shy Mouse appends → grow to a 3-item two-"and" (strongest live EXPAND) | the frame GROWS a second gap + coupler live; the tray gains an item | can't pre-build — revealed only AFTER the first compound is produced |
| **F** | **Change-your-mind SWAP** — Fussy Cat replaces one item; the child edits (a different edit than insert/extend) | one half re-opens for a replacement chip | the swap target is derived; a never-edit solver fails |
| **G** | **Join-two-customers** — combine two separate orders with "and" ("a salad for Cat **and** soup for Dog") | two booths/tickets; "and" joins the two | coordination across recipients; distinct from item-coordination |
| **H (ceiling, G1)** | **3-item two-"and" / correlative "both…and"** | two coupler slots / a paired correlative coupler | upper band, never the floor; **native-EXCLUDED** where a locale lacks it |

- **Honest count:** 7 distinct production ACTS (A-G) + the G1 ceiling band (H). The **three co-headline moves (fix #9)** = the coupler (A/B), the robot-repair (C/D), the live-extension (E) — multiple moves, not one toy + reshuffled food lists. Food-pair variety = within-skill reshuffle, NOT a distinct experience.
- **K-floor:** A, B, C, E. **Free slice = A + B + E.** Per-pass order-only reshuffle (same TYPE recurs with fresh foods).

## Win-states & juice (no competition)
No timer/score/streak/countdown/fail. **Satisfy = the complete spoken compound sentence** (the read-back gate). TTS ALWAYS voices the full agreement-correct compound on success ("Two pancakes **and** a milk!"), the customer beams (mood-glyph + posture + chime), a **happy plate** joins the **non-numeric vessel** (a row of plates filling — no number/bar). **Coupler juice:** the *clank* + flush-slide is the signature delight. **Diegetic no-shame (the consequence lives in the WORLD, never the child):** dropped item → "I also asked for a milk — can you add it?" (**adding it IS the expand act**); dropped conjunction → halves stay apart, the bare first half re-voices with a questioning lilt, the coupler glows + the complete form is MODELED-then-INVITED (never supplied); wrong/extra food → gently slid back, chips already correct stay placed. **Puzzlement is always the customer's or the robot's, never the child's** (comic kitchen steam, never a buzzer/X/sad sound). Full-pass keepsake = the full diner of happy plates → cross-game `GameCollection`. CSS/WebAudio; reduced-motion (clank→instant snap); mute-safe (structure is truth).

## Pedagogy
- **L.K.1.F GATED ON THE READ-BACK (production), never the tray** (gating on the tray makes the claim false). **PRODUCTION not COPYING (fix #1):** the order-pad model hides at read-back so the child generates the language from the gathered objects — the memory-vs-production tension resolved by scaffolding REFERENCE (objects) while hiding the LANGUAGE-MODEL.
- **Co-primary SL.K.2** honestly carried by the tray-gather phase (the input half of one comprehend-then-produce act).
- **Compound OBJECT at K ("a __ and a __")** — most dev-secure compound for a 5yo; two-clause = G1+; "but/or" = G1 (only the ceiling correlative band).
- **Counts SUBITIZABLE 1-3 (max 4) — language not math:** producing the number WORD + agreeing plural. **Gate on per-item exact count, NEVER a total.** 1.OA.A.2 soft never a gate (the moment a child must ADD to satisfy, it's a math game in a diner skin). **Diagnostic:** set every quantity to 1 → the game STILL teaches the compound sentence (quantity = expansion layer on top).
- **Plural agreement ENGINE-ENFORCED at K (§A.13.54):** the food chip carries singular/plural/gender surface; the utter-template voices "pancakes" when count>1; NEVER chip-concatenate; agreement rides correctly BY CONSTRUCTION (no morphology-fail); teaching is AUDITORY. (A future G1 variant can make the singular/plural CHOICE load-bearing.)
- **The conjunction = a SEPARATELY-PLACED OBLIGATORY VALIDATED token** (auto-insert = decorated). The **sentence FRAME** ("I'd like ___, ___ and ___ please") makes it a complete SENTENCE not a shopping list (a bare multiset of food chips can never enable "Say it back").
- **No-shame is diegetic:** the customer's need is genuinely unmet; repairing it IS the expand act; success always voices the full compound.

## Interaction & UX
- **Two-stage via shell `stage` (the layout multiplexer — only ONE work surface in DOM-flow):** stage 0 BUILD-TRAY (`trayMultiset===reduce(order.items)` NECESSARY not the win; tap-to-place FLOOR + `LCS.drag.linear` enhancement; **cannot hard-block** — diegetic auto-complete after N attempts, fix #3). Completing the tray reveals the read-back in place (NO inter-stage auto-advance; only `ctx.correct()` advances). stage 1 READ-BACK: **the order-pad model HIDES (fix #1), the gathered tray-objects remain**; the frame rail; chips into typed slots; each placed chip spoken back; the two halves APART until the coupler snaps them flush; **"Say it back" lights on STRUCTURAL COMPLETENESS not correctness (fix #4)** → `ctx.speak(assembledUtterance)` → semantic adjudication at VOICING (complete-but-wrong is voiced + diegetic response, no fail) → customer confirm → `ctx.correct()` once.
- **Slots-not-concatenation, agreement-aware utter-template (3 decoupled layers):** (1) DATA `order={items:[{food,quantity}], conjunction:{lemma,positions,correlative}}` — no baked sentence/boolean; engine DERIVES voice/pad/tray/read-back validity. (2) DOM chips = numerals+icons (the word lives in TTS → compact mobile). (3) localized utter-TEMPLATE (`f.plural(q)` from the lexicon, `{q}` number word, `{and}` lemma) → TTS speaks the grammatically-correct sentence (renders Finnish `kaksi pannukakkua` partitive-singular).
- **The coupler render — a DESIGNED gap at every width (fix #5):** two plate-halves + a central gap + the gold glinting coupler; placing it = *clank* + flush-slide. **At ≤360px the gap is a DETERMINISTIC VERTICAL layout, never emergent wrapping:** clause-half-1 (row 1) → gap-row with the "and" drop-slot (row 2) → clause-half-2 (row 3), VERTICAL snap. "Apart" is always a designed gap.
- **Listening-span scaffolds** (kill memory as a confound so PRODUCTION is the bottleneck): the order-pad stays visible THROUGH PHASE 0 (item-by-item synced + the "and" connector at the seam); penalty-free replay; each placed chip spoken back. (At read-back the pad MODEL hides — fix #1 — the gathered OBJECTS anchor reference.)
- **Mobile @280-768 — `stage`-multiplexed** (only one work surface in DOM-flow; hiding the pad model at read-back frees the column). The designed vertical-gap coupler layout (fix #5); chips ≥44px; tap-to-place floor; `{type:'lcs-activity-resize',height}` on every transition. **Mandatory `audit-game-mobile.js` 280-768 empty+filled + an eyeball screenshot confirming the coupler-snap reads correctly at 280px** (demonstrated, not asserted).

## Runtime mapping + MEASURED build-gate + PER-LOCALE
- **Round descriptor (DATA; engine never holds a baked sentence/boolean):** `{ type, order:{items:[{food,quantity}], conjunction:{lemma,positions,correlative}}, frame:{slots,prefill,blanks}, distractors:{foods,quantities} }`. All validity DERIVED; adding a type = a frame template + an order shape, zero engine change.
- **`verify-compound-order-core.js` (MEASURED — constructs rounds + runs solver bots against the REAL engine validity function; HALTS build):**
  1. **DROP-THE-CONJUNCTION solver FAILS (the decisive proof — analog of Game 5's counting-solver / Game 8's tile-piler):** a bot with a correct tray + correct quantities + correct foods that NEVER places the coupler must be REJECTED, re-voicing only the first half → proves this is a PRODUCTION game + the conjunction is load-bearing.
  2. **RIGHT-TRAY-NO-SENTENCE solver FAILS:** a bot matching `trayMultiset===reduce(order.items)` that never assembles the read-back must NOT satisfy → the tray alone never gates.
  3. **ANTI-COPYING INVARIANT GATED (fix #6 — encodes the keystone fix #1):** assert at `stage==='read-back'` the order-pad MODEL is NOT in DOM-flow / not legible as a copy-source (pad items `aria-hidden`/face-down/absent); the gathered tray-objects may remain. **Legible sentence-model present at read-back → FAIL.** (Makes the gate's other solver tests VALID — a static gate can't otherwise distinguish producing from copying.)
  4. **GRAB-FIRST-NOUN solver FAILS** (always the salient noun, ignoring the near-cousin → foods load-bearing) + **IGNORE-COUNT solver FAILS** (always quantity-1 → per-item exact count, never a total).
  5. **complete-compound bot PASSES** (frame ∧ conjunction-token ∧ each quantity-token ∧ each agreeing-noun → the one valid path).
  6. `trayMultiset===reduce(order.items)` **necessary NOT sufficient**; read-back validity requires `frame ∧ conjunction-token ∧ ∀quantity-token ∧ ∀agreeing-noun`.
  7. **"Say it back" lights on COMPLETENESS not correctness (fix #4):** enable = all required slots filled + coupler placed; correctness adjudicated only at voicing (no hot-cold oracle).
  8. **Compound-majority ≥80%** (single-item <20%; single-item rounds carry NO "and" chip).
  9. **AND-JOINS-DISTINCT-FOODS (fix #8):** the two items joined by the conjunction have DIFFERENT `food` lemmas → "and" coordinates DISTINCT referents, never degenerates into a count.
  10. **Counts ∈ {1,2,3} (max 4); AGREEMENT-CORRECT against the per-locale NATIVE-AUTHORED TABLE (fix #7), NEVER English-derived:** assert the utter-template output matches the locale's `{one,many,gender}` table for each (count, noun, locale); **FAIL on a missing locale table for any shipped locale** (Finnish `kaksi pannukakkua` partitive-singular; English `+s` rules FORBIDDEN as the source).
  11. **Conjunction SEPARATELY-PLACEABLE + obligatory (not baked); sentence-FRAME token present** (not a bare list); **≥7 distinct production-ACT types + order-only reshuffle** (pass-2 ≠ pass-1).
  - Plus standing gates: `audit-game-mobile.js` (both stages, empty+filled, 280-768, + the coupler-snap eyeball screenshot at 280px per fix #5), `audit-game-variety.js`, `audit-no-competition.js` (lcs-shell 0-line), SEO/JSON-LD §21.
- **PER-LOCALE — EXPENSIVE native authoring (NOT translation):** EN-first; each locale via a §A.13.48 3-agent native ensemble. **Finnish proves translation unworkable:** "two pancakes" = `kaksi pannukakkua` (partitive SINGULAR after a number, NOT number+plural) → only the slots-not-concatenation template + a native table renders it. **§A.13.58 per-locale gender** (resolve in its OWN locale). **Pro-drop / verb-led frames** (the `I'd like ___` template is EN-specific). **Conjunction euphony + correlative frames** (`sowohl…als auch` / `sekä…että`) native-authored; **some correlative frames native-EXCLUDED** where the locale's K register lacks a clean form. Framework-name localizes (§20.10/§A.13.49); the CCSS code `L.K.1.F` stays the machine/SEO anchor.
