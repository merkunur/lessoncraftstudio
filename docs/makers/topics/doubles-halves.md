- `G1-298` Doubles to 20: Just the Numbers — Write the double of each number. No pictures to count. · screen version (scripts/worksheet-gen/types/g1/G1-298-doubles-only-numbers-to-20.js)
- `G1-299` Halves to 20: Just the Numbers — Split each number into two equal parts. No pictures to count. · screen version (scripts/worksheet-gen/types/g1/G1-299-halves-only-numbers-to-20.js)
