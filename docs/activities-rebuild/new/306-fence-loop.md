## The skill
Rectangles can have the same perimeter and different areas (and the same area with different perimeters).

## The apparatus and its invention
THE FENCE LOOP: a closed fence loop of a fixed number of rails (say 16) on a peg board. The child drags a corner peg; the loop stays the same length — rails slide around the corner — so stretching one side shrinks the other. Grass tiles fill the inside live and the area readout changes while the rail counter never does. Tasks: make a pen with area 15 using these 16 rails; then 'same grass, new fence': a fixed patch of 12 tiles, rearrange into another rectangle and count the new fence.

- **Misconception the apparatus makes visible:** Believing the same fence always encloses the same space (and that bigger perimeter means bigger area).
- **Pictures:** farm animals (one animal grazing in the pen as delight)
- **Settings:** Fix: the fence / the grass · Board: up to 20 rails / up to 30
- **Rounds:** Generated targets with exactly one rectangle solution where possible (or any solution accepted, checked by the model), ≥ 8 rounds, alternating fix-fence/fix-grass on the mixed setting.
- **Worksheet types it covers:** G3-339
- **Distinct from:** Mending Fences measures one given fence; the loop holds perimeter constant while area moves, the exact 3.MD.D.8 contrast.
- **Build risk:** Low.
