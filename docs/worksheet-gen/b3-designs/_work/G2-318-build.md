2. **`exemplar(loc)` cannot be `exemplars[theme]`**: the unit-axis contract (`lib/unit-axis.js`) is locale-only, and `{U}` in the title resolves at the strings boundary with no theme. `exemplar(loc)` = `exemplars[WAVE_THEME]` (`forest creatures` → hedgehog, the design's recommended wave theme). A unit-less build on ANOTHER animal theme would print a hedgehog title over the theme's own exemplar (fox / lion / …), so it REFUSES with "pin the unit with unitOverrides" (measured: `render/one.js G2-318 animals 2 en` refuses; `… animals 2 en fox` renders). **The wave must pin `themeOverrides` (an animal theme — `enumerate.js` cannot tell `fruits` from `forest creatures`, only the spec's exemplar join can, and a fruit theme refuses) and, off `forest creatures`, `unitOverrides:{'G2-318':'<animal>'}`.** `units(loc)` = the table animals with a `name` + `title` literal, the wave-theme animals FIRST (so `unitsPerType:N` fans `forest creatures`), then the rest, then `blank`.
