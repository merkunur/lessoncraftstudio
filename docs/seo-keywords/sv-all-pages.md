## Regler mot kannibalisering

| Regel | Beskrivning |
|-------|-------------|
| App vs. Verktyg | App-sidor riktar sig mot sökord med « skriva ut + sälj + kommersiell ». Verktygssidor riktar sig mot « gratis + online + ingen registrering ». |
| Guide vs. App | Guider använder informationella sökord (« hur », « guide », « steg-för-steg »). Appar använder transaktionella sökord (« skapa », « generator »). |
| Paket vs. App | Paket använder sökord med « paket / bunt ». Enskilda appar använder den specifika generatortypen. |
| Idé vs. Guide | Idéer använder sökord med « nisch / verksamhet ». Guider använder « guide / strategi ». |
