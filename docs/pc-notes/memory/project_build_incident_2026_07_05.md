## Gotchas that corrupted everyone's experiments (memorize these)
- **deploy.sh self-pull race:** the in-script `git pull` cannot change the ALREADY-RUNNING script (bash keeps the old fd across git's rename) → **committed deploy.sh knob changes take effect one deploy late**. For build-knob changes: pull/edit on the server BEFORE launching, and **verify via `tr '\0' '\n' < /proc/<buildpid>/environ | grep NODE_OPTIONS`** — never trust the file on disk.
- **Do NOT kill slow builds mid-seal.** Kills destroy near-complete builds AND their cache progress (webpack serializes the pack only on graceful finish) — the accretion ladder is how heavy builds eventually complete.
- **deploy.sh mislabels failures**: read the log for `heap out of memory` (OOM) vs nothing (timeout/kill).
- Weekly Sunday 01:00-04:00 backup window starves `nice -10` builds — avoid deploying then.
