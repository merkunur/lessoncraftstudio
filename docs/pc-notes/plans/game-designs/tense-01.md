## §2 — The standard + the load-bearing cognition
**L.1.1.e (SOLE tag, `also_teaches: []`)** — use verbs to convey a sense of past/present/future. **Fences:** L.2.1 sentence-repair, L.2.4.b derivational-affix (meaning-transform — tense keeps the SAME meaning, only re-times), L.1.1.c agreement / plural-s (NO 3rd-sing "walks", NO "cats"), L.1.2 spelling (**WHOLE pre-spelled tiles, NEVER letter-assembly** — a wrong choice is a TENSE error never a spelling error). **Cognition:** recognize + PRODUCE (produce load-bearing); "convey a sense of" = TIME MEANING, not spelling accuracy. **IRREGULAR verbs are the anti-cheat spine** (went/ran/saw/ate/had/made/came/got — only the PAST is irregular; present/future stay regular run/ran/will run); ~50/50 regular/irregular (DON'T go irregular-heavy — vocab burden drifts off-standard; keep all verbs in known 6-year-old oral vocab). **CUE-ABSENT is the assessment** (cue-present only as an early scaffold; ~1/3 cue → 2/3 no-cue; NEVER a load-bearing round with BOTH a matchable cue AND a regular verb). Time conveyed cue-free via PICTURE-ASPECT (finished/ongoing/about-to) + a STATE-CONTRAST context sentence in TEXT (so an SR child reads the time from words — TIME always in the text, never only the picture).

## §3 — THE ARCHITECTURE REWORK (the heart; the deepest flaw + fix)
**The critic's deepest catch — the OPTION-SURFACE LEAK (the prime-suspect picture-aspect cheat was a SYMPTOM).** The load-bearing claim "all 3 options are the same verb → morphology-proof → form↔time is load-bearing" is **FALSE as built**: the **future option carries the free word "will"** (a `FUTURE_WILL_SOLVER` reads scene-time and taps the "will"-tile — ZERO tense knowledge, scores 1.0 on futures); and once future is trivial, past/present collapses to a 2-way where — by the irregular spine — the **past is the NOVELTY-OUTLIER** among regular forms (an `ODD_FORM_OUT_SOLVER`: "weird word = past"; the irregulars, meant to DEFEAT suffix-match, accidentally hand the child a novelty heuristic the gate's morphology-solver doesn't even model). **The gate scans the CONTEXT sentence for cues but NEVER the OPTION tiles.** A child passes WITHOUT connecting form to time.

**THE FIX — audit the OPTION SURFACE, not just the stimulus:**
1. **`OPTION_SURFACE_NON_DIAGNOSTIC` assert** — NO single surface feature of the option set (function-word presence, token count, orthographic-novelty rank, position, color) correlates with the answer above chance (≤0.45 across the key); enforced by a must-FAIL solver PER feature (`FUTURE_WILL`, `ODD_FORM_OUT`, `TOKEN_COUNT`, `POSITION`, `COLOR`). This is the option-side analog of the existing stimulus-side cue-balance — and it's the half that hides.
2. **EN future = "will + verb" ONLY in the assessment band** (reserve "going to" for the reveal — a multi-word periphrastic is itself a token-count tell); the option-balance assert requires future-target rounds where the future tile's token-count matches a distractor so "spot the will / spot the longer one" is non-diagnostic.
3. **Include fully-REGULAR verbs in the ASSESSMENT band** (walk/walked/will walk) where past is NOT a novelty-outlier, so "weird=past" has nothing to grab.
4. **Strike the "morphology-proof because same verb" claim** from the pedagogy → replace with the **option-surface-non-diagnostic principle** (form↔time is load-bearing ONLY when no option-surface feature is diagnostic).
5. **The morph mechanic is a POST-CORRECT teaching REVEAL only** — demoted because a morph-as-consequence (choose the time-window → the verb auto-morphs) PERFORMS the form-production for the child (the Game-65 scaffold-performs-the-standard lineage); the graded act is the PRODUCTION (select the form), not the simpler choice (tap the time) that triggers the auto-production. The picture-aspect cheat is CURED as a byproduct (with a non-diagnostic option surface, a child who reads the picture-time but doesn't know which form = which tense faces 3 same-verb tiles with no tell → the form↔time link is genuinely load-bearing).

## §4 — Anti-cheat architecture (the gate; consumes the option surface)
- **OPTION-SURFACE LEAK (the deepest cheat) — killed** by §3 (`OPTION_SURFACE_NON_DIAGNOSTIC` + `FUTURE_WILL`/`ODD_FORM_OUT`/`BINARY_PAST_PRESENT`/`TOKEN_COUNT`/`PICTURE_ASPECT_ONLY` all must FAIL).
- **MORPHOLOGY / CUE — killed:** irregular spine (`MORPHOLOGY_MATCH_SOLVER` misfires; `MORPHOLOGY_NEQ_ANSWER` on every irregular round) + cue-absent assessment (`CUE_KEYWORD_SOLVER` blind) + `CONTEXT_COPULA_SOLVER` (reads tense off "was/is" in the context — killed by conveying time via NON-VERB state-contrast OR decorrelating the copula tense from the target tense on a controlled share).
- **ZONE-COLOR/POSITION (both designers' flag) — killed** in which-tense mode: **randomize zone position + color per round** (the time-LABEL text stays — forces reading the label, i.e. form→time-word); `ZONE_POSITION_SOLVER` + `ZONE_COLOR_SOLVER` fail.
- **PRESENT-BY-ELIMINATION — killed:** present-target rounds include a REGULAR past distractor (so "odd=past" can't pre-clear past) + the which-tense mode (present is one of three zones, not a leftover form); `PRESENT_DEFAULT_SOLVER` + `PRESENT_BY_ELIMINATION_SOLVER` fail; verdict-balanced-across-tenses (no tense >0.45 of the answer key).
- **ORDER-EVENTS picture cheat — killed:** order-events orders the VERB FORMS (3 sentences, same verb's 3 forms); pictures NON-orderable (identical/absent); `PICTURE_SEQUENCE_SOLVER` fails.
- **Structural asserts:** `ANSWER_DERIVED_NOT_STORED` (answer = `verb[TIME]` computed; mutate round TIME → form flips; mutate a surface cue → unchanged), `IRREGULAR_VERBS_PRESENT ≥N`, `CUE_ABSENT_ROUNDS_PRESENT ≥N`, `REGULAR_VERBS_IN_ASSESSMENT_BAND`, ORACLE (`verb[TIME]`) passes, ≥7 variety. POSITION/FIRST/RANDOM baselines fail.
- **Wrong-tap re-show — no-reveal:** re-conveys the TIME (re-emphasize the finished/ongoing/about-to evidence), never names the verb or reveals the form.

## Cohort doctrine this game adds
**The OPTION-SURFACE LEAK lesson — PROGRAM-WIDE.** When an answer is a CHOICE among options and the anti-cheat rests on "the options are all variants of one thing, so no surface separates them," AUDIT THE OPTION SURFACE, not just the stimulus — the cohort's gates already balance the STIMULUS-side cues (the context/sentence) but routinely MISS the OPTION tiles, and a leak lives there: a free FUNCTION WORD ("will" → future), a TOKEN-COUNT difference, an orthographic-NOVELTY outlier (the one irregular form among regulars → "weird = the answer"), or a fixed POSITION/COLOR — each maps to the answer WITHOUT the target cognition. **Worse, an anti-cheat LEVER can CREATE the leak: making the past irregular (to defeat suffix-match) makes it the novelty-outlier among regular present/future forms — the fix for one cheat manufactures the next.** **The fix: an `OPTION_SURFACE_NON_DIAGNOSTIC` assert — NO single surface feature of the option set (function-word, token-count, novelty-rank, position, color) correlates with the answer above chance — enforced by a must-FAIL solver PER surface feature, run over the RENDERED option tiles.** Generalizes to EVERY multiple-choice / pick-from-options game in the catalog: stimulus-side cue-balance is HALF the job; option-side surface-balance is the other half, and the second is the one that hides. (Companion: a MORPH/TRANSFORM mechanic that produces the answer-form AS A CONSEQUENCE of a simpler choice [tap the time → the verb auto-morphs] PERFORMS the production cognition FOR the child — the Game-65 scaffold-performs lineage; demote it to a post-correct teaching reveal, and make the GRADED act the production [select the form] itself, never the simpler trigger choice. And: a "non-numeric abundance vessel" that fills MONOTONICALLY with progress is a soft score / "X of Y" in disguise — fill it non-monotonically/decoratively.)
