## The skill
Trace and then write a whole word left to right, and a short sentence with a finger-space between words.

## The apparatus and its invention
THE SPACE STONE. Writing lines across the stage hold a word (or a sentence of sight words) in dotted letters. The child traces each letter in order along its guide; only the next letter's start dot is lit, so a word is a left-to-right run, not a set. In sentence rounds, after each word the child must drag a small grey "space stone" (a finger-space) to the line before the next word's dots appear; dropped too close, it nudges the next word along until there is a gap. Copy setting: the model word is above and the line below is empty — the child traces on a faint guide that fades letter by letter (the guide steps away, the child keeps writing).

- **Misconception the apparatus makes visible:** Writing letters in the wrong order, running words together, and starting a word anywhere on the line.
- **Pictures:** one library picture per word for picture words (first words); none for sight-word sentences
- **Settings:** Content: picture words / long words / capitals / sight-word sentences · Guide: dotted / fading
- **Rounds:** 9 words per content set from the per-locale sight-word and picture-word lists (the worksheet banks), sentences 3–5 words; trace completion only by path so one right result.
- **Worksheet types it covers:** K-239, K-259, K-260, K-261, K-262, K-263, K-284, K-289, K-290, K-291, K-310, K-311, K-315, K-388, K-391
- **Distinct from:** Penny / Snippy trace single letters; the Fading Line traces numerals. Word order and the space between words are new.
- **Build risk:** Per-locale fonts and letterforms (de Grundschrift, sv/no school letters) — must use each locale's school print, as the letter traces do; tracing accuracy at 360 px.
