Characters

Poses live in the base sheet; animation clips are optional. New characters appear in the Studio's picker on its next load.

Backgrounds / scenes

Any size accepted — automatically cover-fitted to 1600×1000 WebP. Keep scenes under 300 KB where possible (school tablets).

🧺 Props (the objects teachers place on pages — animals, food, things) come from the worksheet image library and are managed in the Image Library Content Manager. Anything you add there shows up in the Studio's picture picker. After adding new themes/images, run node scripts/storybook/build-library-manifest.js once (or ask the tech side) to refresh the props index the Studio boots from.

Add a character

Sheet contract: export JSON (Hash) from TexturePacker. Frames become poses named after the frame files — include a frame named neutral (→ pose_neutral, required). All frames must share one canvas size (recommended 512×640, full body, feet at bottom-center). The sheet is re-baked upright automatically.
A single transparent PNG/WebP becomes a one-pose (neutral) character — great for simple characters or mascots. You can never add clips to grow it later without re-uploading as a sheet.

Add animation clips to

TexturePacker pair again. Frames grouped by animation (or by name_0001… numbering) become clip_<name> animations (24-48 frames @12fps recommended, ≤2 clips per character). Multipack clip sheets (.clips-1.*) are a CLI-only workflow (pack-atlas.js).

Add a background / scene

Any image size — it is cover-fitted to 1600×1000 (the storybook design space) and saved as WebP. Pre-composed opaque scenes work best; aim for ≤300 KB after conversion (a size badge shows on the card).
