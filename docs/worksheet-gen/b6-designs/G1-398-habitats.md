**The rule that locks the type.** Every animal carries a hand-read `lives` list in `data/b6/habitats.js` (EVERY habitat it truly lives in, not the favourite one); a base page is legal only if **each animal's `lives` meets the page's windows in EXACTLY ONE window**, so two right answers are impossible by construction. The polar window is one drawing for two habitats (`polar-arctic`, `polar-antarctic`); an Arctic animal and an Antarctic animal never share any page of any face (penguins never meet walruses, white seals or narwhals). ## 2 The base page

**Concept.** "The Habitat Museum." A 2 x 2 wall of four framed cut-away windows (B), each an EMPTY place (no animal drawn inside it), each with a coral letter disc in its top-left corner and a name plaque on its bottom rail; under the wall a drawer of eight animal cards, each over an empty letter box. The child looks into a window, reads the place (a wave line over deep water, a small water bowl inside land with reeds, trees with roots in the soil, an iceberg mostly under the waterline, the flat umbrella tree, a wall of giant leaves, a flowered hill), finds where each animal lives and writes that window's letter under it. **Composer.** (1) Window set: generic locales draw 4 of their 7 ids by seed with <= 1 near pair; fixed-set locales (de, es, pt, sv, da, no, fi) use their 4; the window→letter assignment is `rng.shuffle` (the same habitat is not always A). (2) Eligibility per animal: `lives ∩ pageHabitats` has exactly one element (the polar window counts as the ONE pole present on the page; a page holds Arctic or Antarctic animals, never both); plus the page rules of §5 (coastal, look-alike, group, co-occurrence). (3) Per-window counts: draw a vector in [1,3] summing to 8, not all equal, respecting each window's eligible pool (polar is capped at 1 when an ocean window shares the page: penguin OR walrus only). (4) Drawer order: `rng.shuffle`, re-drawn until no two adjacent cards share a letter, each drawer row holds >= 3 distinct letters, the letter sequence is not sorted, not constant, not strictly alternating. The seed is locale-neutral in the pictures and positions; the WINDOW SET is locale data, so a locale's shipped instance is its own and the tell statistics are measured per locale.

**Answer-hiding + uniqueness.** The windows print the place, a letter and a plaque; the drawer prints only pictures; each letter lives ONLY in `data-lcs-answer` of an empty `blankNumeralBox` (m: always stamps the attribute, renders empty). Stamps: window card `data-lcs-window="<letter>" data-lcs-habitat="<habitat key>"` (the tile id AND, for polar, the pole: `polar-arctic|polar-antarctic`); animal card `data-lcs-animal="<bank key>" data-lcs-answer="<letter>"`. `verify(page)` re-derives, from a `lives` map serialised into the root `data-lcs-lives` (JSON, the page's animals only): every animal's `lives ∩ pageHabitats` has exactly one element and its window letter === `data-lcs-answer`; every window holds >= 1 animal; the per-window count vector is not all equal; no Arctic + Antarctic mix; boxes empty (no text node); no animal name anywhere in the body; no `<text>`/`<image>` inside any window svg; window letters A..D unique.
