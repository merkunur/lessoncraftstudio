# TOOL #38 — THE DRAW BAG (`draw-bag`) — LIVE 2026-07-31

v4 catalog slot C1, third of wave 1. Commit `fa5c2fed` (28 files, 5,011 insertions —
apparatus + 120-bag library + 9 gate scripts + registration, all in one).

**THE BAG · THE RECORD · THE GUESS.** The class commits a guess onto three wordless shelves;
the guess **freezes** on the first draw; each draw lands permanently on a record and the piece
**goes back in**; the SAME bag can then be run a second time, and record two lies UNDER record
one. Open the bag last: contents beside the frozen guess, **nothing marked**.
**THESIS: the same cause produces two different pictures.**

## ⭐⭐ THE LAW-LEVEL LESSON: A BAN CAN BE TOO WIDE
My D14 likelihood ban covered the **subject** word as well as the **verdict**, so the German
panel's own name `Der Zufallsbeutel` — from *Zufallsexperiment*, the actual Grundschule register —
**would have failed the build**, and the same ban rejected the official KMK / BNCC / Lgr22 strand
names in landing prose. That is the recorded `par`-rejects-correct-French defect in a new dress:
a fence that rejects correct native prose teaches a panel to reword AROUND it rather than report
it. **Fix: bans are poison-tested in BOTH directions** (a must-FIRE string and a must-PASS string),
the tool strings keep the full ban, and landing prose carries an explicit auditable exemption list
for official strand names. The v4 law already said authored language is chrome "(title, settings,
the paid chip)" — **naming the domain is not delivering a verdict.**

## ⭐ THE ENGLISH SOURCE IS A LOCALE TOO
**Seven** native panels independently found the same defect, and it was in MY ENGLISH:
*"keep every piece you draw"* reads as sampling **without** replacement — a mathematics inversion
that kills the second run and the record. de *"bleibt liegen"*, fr *"reste posée"*, es *"se queda
a la vista"*, nl *"blijft liggen"*, sv *"ligger kvar"*, da *"bliver liggende"*, it *"resta lì"*,
fi *"jää näkyviin"* all say the piece stayed OUT. Every locale now states **both halves with two
different subjects** (the DRAW stays on the record / the PIECE goes back). Panels audit your
source, not just their own copy.

## THE GATES AND WHAT THEY CAUGHT
`verify-` **D1–D19**, ⭐ **D3 is the theorem**: the walk is checked against an **expanded-array
oracle — a different algorithm** — over every index of every bag, because χ² cannot see a
modulo-bias mutation over ≤24 outcomes (χ² is only the backstop). `mutate-` **79/79 killed** ·
`local-test-` **29** incl. an **L8 POISON block that proves the sweep can fail** · `smoke-`
11 fresh browsers × 34 keys, numeric placeholders `[0-9]+` never `.{1,60}?` · locale-layout
**11×6 in the densest state** · liveness **124/0/0** across three entitlement states ·
**0 lines to lcs-shell or any protected core** (provable: `git status` showed 0 modified tracked
files before registration).

Caught: **6 gate defects on the first run** — all mis-measurements (SVG `points` fired the verdict
ban; the CSS string fired the frequency-numeral ban; `\b(osannolik)\b` misses *osannolikt*; a
comment made the tool fail for saying it does NOT touch the roster; `indexOf` anchored on the
first `fillBtn` and reported a live control dead) — **each fixed in WHAT is measured, never in a
threshold**. Then: a **dead "Shapes" chip** (idempotent at rest — the option that IS the state is
now disabled); the guess block as **three empty desktop bands**; a **0.375px** miss that wrapped
the sixth piece; and a **1091px cut-off at 768 in ALL ELEVEN locales** that the English sweep
could not see because it never opened the reveal with two full records.

⚠ **AND A GATE THAT HANGS IS A GATE THAT SURVIVED.** An unbounded `while (T.canDraw(s))` met a
mutation that stopped the record filling; the harness scored it TIMED OUT, which counts as
SURVIVED. No loop in a gate may depend on the tool terminating.

⚠ **"Reachable" below 768 is NOT measured by scrolling.** `lcs-shell.css` sets
`html,body{height:100%;overflow:hidden}` on purpose; production grows the IFRAME from
`.lcs-app`'s own height (`lcs-shell.js:914`). A scroll-and-re-measure check fails on every phone
while production is fine, and "fixing" the tool to satisfy it would break the shell contract.
Measure the last control against **the card**. (Measured: 902px inside a 926px card at 360.)
