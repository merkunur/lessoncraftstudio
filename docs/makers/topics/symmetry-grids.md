# Maker: Symmetry & Grid Copy (`symmetry-grids`)

Group **math** · language need **none** · 10 existing templates + 2 new · replaces old app(s): `draw-and-color`

## Settings a teacher sets

- grid size
- picture
- axis: vertical / horizontal
- coordinates labels on/off
- (plus the settings every maker has: language (one of our 11); template (gallery by sub-topic); level 1-3; picture theme / own pictures where pictures appear; number of problems / page fill; title + instruction text (editable); answer key on/off; pages: add / duplicate / delete; regenerate (new seed, same settings); paper: Letter for en-US, A4 elsewhere (switchable))

## Templates from today's worksheet types

**Copy a picture square by square onto an empty grid (with and without letter–number labels)**

- `K-286` Copy the Grid Picture — Look at the picture on the left. Color the same squares on the empty grid so the picture appears again. (scripts/worksheet-gen/types/k/K-286-grid-copy.js)
- `K-298` Copy the Grid Picture: First Steps — No letters or numbers here. Color the same squares on the empty grid. (scripts/worksheet-gen/types/k/K-298-grid-copy-6x6.js)
- `K-299` Copy the Picture Using Letters and Numbers — Use the letter and number of each square to copy the picture. (scripts/worksheet-gen/types/k/K-299-grid-copy-with-letters-and-numbers.js)
- `K-300` Copy the Picture on an 8x8 Grid — A bigger grid: find each square by its letter and number, then copy. (scripts/worksheet-gen/types/k/K-300-grid-copy-8x8.js)

**Complete a half-drawn grid picture so it is symmetrical (vertical and horizontal mirror lines)**

- `G2-253` Complete the Symmetry Picture — Each picture is only half done. Color the squares on the other side of the line to make it symmetrical. (scripts/worksheet-gen/types/g2/G2-253-symmetry-drawing.js)
- `G2-264` Easy Symmetry Drawing — Each picture is only half done. Color the squares on the other side of the line to make it symmetrical. (scripts/worksheet-gen/types/g2/G2-264-symmetry-drawing-easy.js)
- `G2-265` Hard Symmetry Drawing — Each picture is only half done. Color the squares on the other side of the line to make it symmetrical. (scripts/worksheet-gen/types/g2/G2-265-symmetry-drawing-hard.js)
- `G2-266` Mirror Pictures: Heart and Butterfly — Each picture is only half done. Color the squares on the other side of the line to make it symmetrical. (scripts/worksheet-gen/types/g2/G2-266-symmetry-hearts-butterflies.js)
- `G2-267` Mirror Pictures: House and Crown — Each picture is only half done. Color the squares on the other side of the line to make it symmetrical. (scripts/worksheet-gen/types/g2/G2-267-symmetry-house-crown.js)
- `G2-268` Mirror Below the Line — Each picture is only half done. Color the squares below the line to make it symmetrical. (scripts/worksheet-gen/types/g2/G2-268-symmetry-horizontal-mirror.js)
