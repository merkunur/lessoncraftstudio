## Règles anti-cannibalisation

| Règle | Description |
|-------|-------------|
| App vs. Outil | Les pages app ciblent les mots-clés « créer + vendre + à imprimer ». Les pages outil ciblent « gratuit + en ligne + sans inscription ». |
| Guide vs. App | Les guides utilisent des mots-clés informationnels (« comment », « guide », « étape par étape »). Les apps utilisent des mots-clés transactionnels (« créer », « générateur »). |
| Pack vs. App | Les packs utilisent des mots-clés « pack / lot ». Les apps individuelles utilisent le type de générateur spécifique. |
| Idée vs. Guide | Les idées utilisent des mots-clés « niche / business ». Les guides utilisent des mots-clés « guide / stratégie ». |
