**The rule that locks the type.** Every item is a FRAME instance: a panel literal `text` = `{name}` FIRST + verb + exactly one complement slot whose name is a FORM SELECTOR (`{thing}` -> `objForms[key].unique` (de: the accusative phrase "den Ball", correct because every thing-frame verb is signed `objCase:'acc'`; sv / da / no: the definite "bollen"; fi: `{part}` -> `.part`), `{place}` -> `places[key].text`, `{time}` -> `times[i].text`, `{n} {pl}` -> `numberWord(n, loc)` + `objForms[key].pl` (fi: `{n} {part}`)), a declared `kind` (`thing | place | time | count`), and a `q` object with exactly two question literals `q.who` and `q.<kind>`, each opening with `qPrefix + qwords[k]` and containing every NON-asked slot and never the asked one. The composer chooses the row's `ask ∈ {who, kind}`; the ANSWER is `chips.indexOf(ask)` (base) / `qwords[ask]` (F2) / the filled `q[ask]` (F4) / the constituent literal itself (F1 / F3, answered by kind). The marked span = the substituted literal of the asked slot (for `count`, the number word ONLY: marking "three apples" would admit `what`). The code substitutes and marks; it never inflects, capitalises, strips or shortens a literal. Single-answer is by CONSTRUCTION (one marked slot, one kind per slot), and the panel still signs every frame (`signed:true`) after reading a render, because the code cannot see that a `when` literal is really a `where` ("at the party").
