## The skill
A map uses symbols, and the key tells what each symbol means; you can find and count things using the key.

## The apparatus and its invention
THE KEY STENCIL. A bird's-eye town of apparatus blocks (streets, a park, a river) dotted with small map symbols (simple geometry: a triangle tree, a square house, a cross, a circle pond) drawn at two sizes and two shades. The key strip shows each symbol beside its library picture (tree, house, car, tent, lake). The child drags a key symbol over the map like a stencil: every matching symbol, whatever its size or shade, lights through it. The child sets the count on the key with + and − beads. Right: the count locks and the lit symbols ripple. Miss 1: one unlit match blinks; Miss 2: the stencil sweeps the map once by itself. WHERE-IS-IT task: "the tree next to the river" — the child taps the one symbol that fits the key and the place.

- **Misconception the apparatus makes visible:** Takes a symbol's size or colour for its meaning, or counts the key itself.
- **Pictures:** Key pictures: tree (apple tree), miscellaneous (house), vehicles (car, bus), camping (tent, lake), around-the-house (mailbox); map symbols are apparatus geometry.
- **Settings:** Symbols: 3 / 5 · Task: find and count / where is it.
- **Rounds:** 9 maps, symbols placed on a grid at random with 2–6 of each; every map has the asked symbol at two sizes; counts distinct per symbol; one right count.
- **Worksheet types it covers:** G1-379
- **Distinct from:** Bramble's Parking Tower is position words; no map activity exists.
- **Build risk:** Map symbols are geometry (tool-grade) but must not become hand-drawn objects.
