# Maker: Same & Different, Shadows & Pairs (`same-different`)

Group **visual** · language need **none** · 11 existing templates + 2 new · replaces old app(s): `odd-one-out`, `shadow-match`, `missing-pieces`, `grid-match`, `matching`

## Settings a teacher sets

- task: odd one out / twins / shadow / part-whole / mirror / match pairs
- pictures or shapes
- how close the distractors are
- (plus the settings every maker has: language (one of our 11); template (gallery by sub-topic); level 1-3; picture theme / own pictures where pictures appear; number of problems / page fill; title + instruction text (editable); answer key on/off; pages: add / duplicate / delete; regenerate (new seed, same settings); paper: Letter for en-US, A4 elsewhere (switchable))

## Templates from today's worksheet types

**Visual discrimination: find the identical twins, the pairs, and the one that differs (in detail, size or shape)**

- `K-039` Same and Different — Three pictures are the same. Circle the one that is different. · picture themes (scripts/worksheet-gen/types/k/K-039-same-and-different.js)
- `K-044` Find the Different Size — Look at each row. Circle the one that is a different size. · picture themes (scripts/worksheet-gen/types/k/K-044-odd-one-out-size.js)
- `K-058` Find the Pairs — Every picture has a twin. Draw a line between each pair. · picture themes (scripts/worksheet-gen/types/k/K-058-match-identical-pairs.js)
- `K-062` Find the Twins — Two pictures are exactly the same. Find them and circle both. · picture themes (scripts/worksheet-gen/types/k/K-062-find-the-same-two.js)
- `K-078` Shape Twins — Every shape has a twin. Draw a line between each pair. (scripts/worksheet-gen/types/k/K-078-shape-matching.js)
- `K-080` Which Shape Is Different? — Look at each row. Circle the shape that does not belong. (scripts/worksheet-gen/types/k/K-080-odd-shape-out.js)

**Which one does not belong (by category)**

- `K-043` Which One Is Different? — Look at each row. Circle the picture that does not belong. · picture themes (scripts/worksheet-gen/types/k/K-043-odd-one-out-category.js)

**Match a picture to its shadow; recognise a whole picture from a part (visual closure)**

- `K-057` Match the Shadow — Draw a line from each picture to its shadow. · picture themes (scripts/worksheet-gen/types/k/K-057-shadow-match.js)
- `K-069` What Is It? — Only part of the picture is showing. Circle the whole picture it belongs to. · picture themes (scripts/worksheet-gen/types/k/K-069-visual-closure.js)

**Compare two pictures and find what changed / what is missing**

- `K-061` Spot the Differences — Compare the two pictures. Circle what changed on the right. · picture themes (scripts/worksheet-gen/types/k/K-061-spot-the-difference.js)

**Recognise the mirror image (reflection) of a picture**

- `K-063` Mirror, Mirror — Circle the picture that shows the mirror image. · picture themes (scripts/worksheet-gen/types/k/K-063-mirror-match.js)
