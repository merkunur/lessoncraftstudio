**The rule that locks the type.** Every word shown is a panel-signed citation literal inside a **synonym group** (all members mutually substitutable for a child in that locale's school register) tagged with a locale-neutral CONCEPT id; a closed row is single-answer because **exactly one choice shares the target's group, no choice is the target's antonym (read from `bank('opposites', loc).pairs` + `.prefix.items`), no choice is in a `near` pair with the target or the answer, and no two choices share a group**; where context decides (F4) the panel authors the whole sentence × bank FIT MATRIX and the validator requires a permutation matrix. Semantic fit is never inferred by code; the code substitutes literals and never inflects.

## 2 The base page

**Concept. "Linked Words: eight twin cards" (A).** Eight identical cream cards in a 2 x 4 grid. Each card is topped by a tealSoft BAND carrying the joined-rings mark and ONE big target word; under it a 2 x 2 square of four identical white word tags. The child reads the band word and circles the one tag that means the same. One apparatus, repeated; no pictures, no lines, no bank; generous air (14 px column gap between tags, 10 px row gap, so a pencil loop never touches a neighbour). The four tags on a card are the SAME width (the grid cell), so a long word is never "the special one". Chosen over B's washing line for the base (critic §1 rows 1-2): four choices instead of three, a calm page instead of 32 socks and 32 pegs, and a fit proved by a real render at ONE font size in every locale.

**Instruction (en source):** "Read the big word on each card. Circle the word under it that means the same." (79)

**Composer.** The seed is locale-neutral over CONCEPT ids (§5 `CONCEPTS`): the composer walks a seeded permutation of the concept list and takes, in order, the first 5 adj and 3 verb concepts the locale has signed (`groups[].concept`); the same seed therefore draws the same meanings in every locale that signed them, and only the words change. Per card: target = a seeded member of the concept's group, answer = another member; three distractors of the SAME `pos`, drawn from groups that are not targets on this page, with at most one (d2) from the target's `domain` (feelings, size, speed, sound, looks, cleverness, difficulty, health, begin-end, move, speak, take-give; a panel tag per group) so the card is not solved by topic alone. **All 40 words on a page are pairwise distinct** (8 targets + 8 answers + 24 distractors). Answer slots `rng.shuffle([0,0,1,1,2,2,3,3])`, re-drawn until no slot repeats on three consecutive cards in reading order (1..8 row-major). Card order = draw order (no ascending anything). Nothing on the page depends on the locale except the literals.

**Answer-hiding + uniqueness.** The answer is one of four identical white tags; no colour, order, size or length marks it. Stamps (never visible): card `data-lcs-target="<groupId>:<word>"` `data-lcs-domain`; each tag `data-lcs-tag data-lcs-group="<groupId>" data-lcs-slot="0..3"`; the root `data-lcs-face="base"`. **No `data-lcs-answer` string anywhere** (the answer is derived). `verify(page)` re-derives, per card, the answer = the unique tag whose group === the target's group and FAILS on 0 or ≥ 2; FAILS if any tag word ∈ `antonymsOf(target)` ∪ `antonymsOf(answer)` (opposites `pairs` a↔b and `alt`) ∪ prefix items, if any (target|answer, tag) ∈ `near`, if two tags share a group, if a tag's pos ≠ the target's, if more than one tag shares the target's domain, if any word repeats on the page, if a group is a target twice; slot counts exactly 2 each; no 3-in-a-row slot.
