## 2. Concept & creative hook
**Pip — a luminous moth-firefly in a warm glass lantern — WATCHED a short wordless picture-story but can't keep it. "You watched it too… help me remember?" The CHILD is Pip's memory: each key detail answered FROM THE STORY lights a new firefly-mote inside the lantern, and Pip's memory of that story glows back to life.** The emotional inversion that makes it premium and NOT a quiz: the child is NOT tested — the child is the one who REMEMBERS, and Pip is the one who forgot. Comprehension-as-companionship.
- **THE STORY IS A WORDLESS PANEL-SEQUENCE (Path B — mute-safe, pre-reader-native):** the child swipes through 4-5 wordless panels (child-paced, free re-watch); the narrative lives in the GAP between panels. The comprehension questions are about the RELATIONSHIP BETWEEN panels (sequence/causation/feeling-arc) — so the answer is in NO single panel (picture-leak structurally impossible).
- **THE ART IS COMPUTED FROM THE STORY-GRAPH (the critic's deepest fix — the un-circular gate):** every panel renders EXACTLY the entities the descriptor's `panel.inPicture` declares (a closed per-story entity registry); the CA5 art brief is GENERATED from it. So "what the art shows" is GROUND TRUTH the gate checks — the illustrator can't draw the answer into the support panel, and the SR child's alt-text shows exactly the same entities. The gate tests what the child CONSUMES (the art), not the author's model of it.
- **THE TROPE IS THE EFFECT, NEVER THE CAUSE (readability without the cheat):** the legible visual tropes that let a pre-reader read the story (a wilt = sad, tears = sad) are licensed ONLY on the feeling/outcome panels (the readable REACTION) — the CAUSE is always a story-specific EVENT the genre doesn't pre-wire (Pip is sad because the lantern's lid blew open in panel 2 and the warm-mote escaped — NOT "because the flower wilted"). The child reads the effect via trope (readability preserved); the cause requires tracking a specific earlier panel (a `TROPE_SOLVER` that picks the genre-default cause FAILS).
- **THE PROUD SCAFFOLD (RL.K.1 "with prompting and support"):** a wrong tap is NOT a fail — Pip gently re-tells the CONTEXT beat ("remember, the lid was open…" — additive, never narrowing, never the answer panel) and re-asks with FRESH foils (no elimination-funnel). The scaffold IS the standard.
- **THE ASK VERB, GENERATIVE (operator-ruled):** "Help Pip ask the troupe a question" — a frame with a child-selected SLOT ("Ask Pip: *Why did ___ happen?*" → the child taps WHICH event to inquire about); ≥3 valid fillers; the character answers from the story. The child is the QUESTIONER (knowing which detail is question-worthy = comprehension), not picking a "right question" chip.
- **THE PAYOFF:** a detail answered-from-the-story → a light-thread flows tap→lantern, a new firefly-mote ignites, Pip wobbles happily ("Yes — that's exactly what happened to me!"); `ctx.correct()`. By story's end the lantern is a warm crowded galaxy of motes — Pip's restored memory (a `GameCollection` glow — non-numeric AND non-content, NO count).
- **Anti-generic statement:** NOT a comprehension quiz with a character skin — (a) cross-panel integration + the entity-registry kill the picture-leak; (b) the equally-plausible distractors + the `PLAUSIBILITY_SOLVER` kill the generic-default; (c) the no-keyword-overlap + the `KEYWORD_SOLVER` kill the keyword-match; (d) the trope-is-effect-not-cause + the `TROPE_SOLVER` kill the genre-schema cheat (the critic's pre-loaded one); (e) **the entity-registry + the blind annotator + the human bypass-pilot kill the deepest one — the circular gate (the art is bound to the gated descriptor + validated by a non-author channel).**

## 3. Core loop & the honest 5 cognitions (§A.13.60 waiver — the critic's audit; the over-claimed 7 collapses to 5)
**Loop (witness the story → help Pip remember):** Pip dims → the child watches the 4-5 wordless panels (free re-watch) → the panels tuck into the lantern → Pip asks (a context panel re-shown for support, NOT the answer panel) → the child performs a comprehension ACT → correct → a mote ignites + `ctx.correct()`; wrong → Pip re-tells the CONTEXT beat (additive) + re-asks with FRESH foils (not a fail). **No timer/score/streak/countdown/fail/attempts/"X of Y", NO quiz framing.** `nextTask` reshuffle over STORIES + item-order.

**The honest 5 genuinely-distinct child-ACTIONS (§A.13.60 — the critic's audit: who/what/where collapse into ONE recall; causation/feeling-cause/prediction into ONE causal-trace; the 5 are kept distinct by ARTIFACT [the entity-registry types them] + the generative ASK):**
| # | Experience (`qtype`) | The child's ACTION | Why genuinely distinct (artifact / facet) |
|---|---|---|---|
| 1 ★ | **match-a-detail** (`recall`) — who/what/where | recall a key detail bound to the story (which character/object/place) | a CHARACTER/OBJECT/PLACE entity (the registry types it) — identity-binding, no causal trace |
| 2 ★ | **trace-the-causal-spine** (`cause`) — the KEYSTONE | bind an effect to its story-specific CAUSE across panels (why did X happen) | an EVENT entity ≥1 panel before the effect (NOT a trope) — cross-panel causal integration |
| 3 ★ | **read-the-feeling-because** (`feelingCause`) | bind a character's feeling to the EVENT that caused it (how + why) | an EMOTION entity tied to an event (artifact-distinct from #2's event) — the SEL facet, event-bound |
| 4 ★ | **order-the-sequence** (`sequence`) — max 1/story | order 2-3 shuffled panels back into the order they happened | a DIFFERENT interaction (order, not select) + temporal integration — fences RL.K.2 (never reorder-ALL) |
| 5 ★ | **pose-a-question** (`ask`, GENERATIVE — operator-ruled) | fill a question frame's SLOT ("Ask Pip: why did ___?") by tapping which EVENT is question-worthy | the child is the QUESTIONER (the ASK verb) — metacognitive (which detail is causally central); ≥3 valid fillers |
- **Honest framing (critic F-6 + waiver):** 5 genuinely-distinct child-ACTIONS, kept distinct by ARTIFACT (the entity-registry types character/object/place/event/emotion) + the generative ASK + the order interaction — NOT the over-claimed 7 (who/what/where are ONE recall; causation/prediction are the causal-trace; padding via question-words is the §A.13.60 enemy). A **documented §A.13.60 partial-waiver at 5** (matching the Games 52/54/55/57 ~5-6 precedent); the ≥7 EXERCISE variety comes from the 5 qtypes × ≥3 DISTINCT STORIES (story-variety is the real variety surface — §20.2 Fisher-Yates reshuffles ORDER, can't manufacture stories); `audit-game-variety.js` confirms 5 distinct actions + ≥3 stories + ≥7 exercises + reshuffle. **CAUSATION (#2) mandatory in every story (the keystone); feeling-cause (#3) in most.**
- **Free slice = match-a-detail + trace-the-causal-spine + order-the-sequence** (one short story) — proves the cross-panel comprehension core; the picture/plausibility/keyword/trope solvers all fail.

## 6. Interaction & UX
- **Runtime: witness the wordless story → help Pip remember.** `story-core.js` holds the authored story-GRAPH `{ id, entities:[{id, kind:'character'|'object'|'place'|'event'|'emotion', sprite}], panels:[{inPicture:[entityId], caption?}], beats:[{event, causalLink, feeling}], questions:[{ qtype, prompt, requiresBeats:[i], visiblePanelsAtAsk:[p], choices:[{text, answerEntityId, correct}], retell:{contextBeat} }] }` + the per-mode graders (the correct chip is authored BUT validated by the blind annotator + the bypass-pilot, NOT trusted). **The answer = `f(having processed THIS rendered narrative)`, never `f(one panel)` / `f(general plausibility)` / `f(keyword)` / `f(genre trope)` / `f(the author's annotation alone)`.**
- **State separation (anti-cheat — the critic's deepest fix):** the ART is RENDERED from `panel.inPicture` (the entity-registry — single source of truth; the gate's `inVisiblePicture` is GROUND TRUTH, not an author flag). `snapshot()` exposes the question prompt + the choice chips (text + id, NO `correct` flag) + the CONTEXT panel (not the answer panel). `facts()` (gate-only) exposes per-choice `{answerEntityId, correct, plausibleInGeneral, isGenreTropeCause, keywordOverlap (recomputed from the tokenized prompt), inVisiblePicture (recomputed from panel.inPicture)}` + `requiresBeats`.
- **Commit + the no-fail scaffold (no Check button, no quiz):** the tap IS the commit; `ctx.correct()` auto-advances on a correct detail. A wrong tap → the additive context re-tell + fresh foils (NOT a fail, NOT a buzzer, NO counter). The ASK slot-fill: tap the event into the frame slot → Pip answers from the story (`ctx.advance()`). The sequence: tap panels into order. (All chips/slots tap-to-place, ≥44px.)
- **Mobile @280px (§A.13.55):** vertical flex; the panel-strip swipeable (one panel at a time at 280px); the question + chips as wrapping DOM `<text>` ≥44px; the sequence-tiles full-width; `overflow-x:hidden`, clamp() fonts, vw not vh/vmin (§A.13.47). `audit-game-mobile.js` watch/ask/answered at 280-768.
- **Accessibility (SR first-class — the critic's F-8):** each panel has alt-text GENERATED FROM `panel.inPicture` ONLY (`SR_ALT_TEXT_ENTITY_PARITY` — the SR child sees exactly the entities the sighted child sees, no answer-leak); the question + chips announced; the context re-tell announced on a wrong; full keyboard (swipe panels via arrows; tab chips/slots + Enter); reduced-motion (static mote-ignite); mute-safe (the panels + DOM text carry 100% — audio narration is enrichment; verify a sound-off solve path).
