## The skill
Find the unknown factor of a known total and read one array as four related facts.

## The apparatus and its invention
THE ARRAY FRAME: a box of N counters (library pictures, identical) waits above an empty frame whose number of rows is fixed and shown. The child drags the frame's right edge outward one column at a time; counters pour in row by row. When the frame is too wide the last column hangs half-empty, too narrow and counters stay in the box — the only stopping place where both are clear is the missing factor. Then a cover card slides over one side's label at a time: the four number sentences (r×c, c×r, N÷r, N÷c) are completed by tapping the uncovered numbers, so each fact is read off the same frame.

- **Misconception the apparatus makes visible:** Treating division and multiplication as unrelated facts; adding the two given numbers to find the missing factor (24 and 6 -> 30).
- **Pictures:** one library picture per round as the box label (fruits, vegetables, toys, insects-and-bugs); the counters inside the frame are identical library pictures only when the total ≤ 30 (cells ≥ 64 px at 360), otherwise drawn apparatus dots in the shell palette
- **Settings:** Missing: the columns / either side · Facts: missing factor only / all four facts
- **Rounds:** Totals from tables 2-10 with both factors ≥ 2, ≥ 8 rounds, no total repeated; which side is fixed alternates with no streak > 2; numeric answers so position is not a tell.
- **Worksheet types it covers:** G3-311, G3-312, G3-369
- **Distinct from:** Build an Array (2.OA.C.4) builds from two given numbers; the frame starts from the TOTAL and one side. Echo Grove only matches a written product.
- **Build risk:** Medium: a 10×10 frame of pictures must keep pictures ≥ 64 px at 360 — use small counters with a picture legend above; check rule 4 floor.
