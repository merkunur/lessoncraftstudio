### Base: Four Seasons Sort (K-322, CODE, `mode:'base'`)
**Move:** CLASSIFY a marker by season (the 4-bin classic, pedagogy 4 per §18: the markers are weather + nature + activity, not clothes). **What the child does:** draws a pencil line from each picture to the season box whose icon and name it belongs to. **Layout (inner 675 x 722):** a row of 4 `markerTile` (icon 88, tile 112, gap 48 -> 592) above, the 4 `seasonBin` in a row in the middle (4 x 150 + 3 x 25 = 675), a row of 4 `markerTile` below (dots on the top edge). Heights 112 + 190 + 112 = 414; the two gaps absorb the slack (154 each at 722, 200 at 814), so every line has room and no line crosses another picture (top tiles connect down, bottom tiles up). Bin name pill 18 px: widest `Primavera` / `Frühling` / `Printemps` 9 glyphs ~ 78 px *est.* (Baloo 2 700 22 = 10.6 px/glyph, K-321 m) <= 150 - 32. **Bin order** = `SEASONS[loc].cycle` from `cycleStart` (de Frühling-first, the Jahreszeitenuhr; en/es/pt/fr/it/nl/Nordic/fi winter-first; panel decides). **Ladder** (config keys; guards key on these): d1 `{perBin:1, iconPx:100}` 4 items; **d2 `{perBin:2, iconPx:88}` 8 items** (the K density ceiling is 4-8, brief; 12 is d3); d3 `{perBin:3, iconPx:56, rows:3}` 12 items (3 rows of 4: top, bottom and a second bottom row; `writeNames:true` = the name pill becomes a 40 px `schoolLines` lane so the child writes the season, K whole-word floor 40). **Pool:** `pool(loc, season)` = neutral minus the locale's `veto` list, or the locale's `override[season]` when present; sample-or-throw (`sampleEntries` pattern, `who:'K-322'`); refuse the face when any season pool < perBin. Both rows `rng.shuffle`, re-shuffled until neither row is in bin order and no row is single-season. **Verify:** 4 `[data-lcs-bin]` distinct keys in `cycle` order; every `[data-lcs-item]` key ∈ bins; each bin receives exactly `perBin`; no item noun equals a bin icon noun; no noun twice; no row in bin order; `img.complete && naturalWidth > 0`; icons >= 56; no localized B&W marker in any `src` (`BW|SW|BN|NB|ZW|SH|PB|MV|SV`). Node gate: every item key === the bank's season for that `(theme, noun)`. **Query face:** the bare head ("four seasons sorting" / "Jahreszeiten zuordnen" / "clasificar las estaciones" / "sortera årstider" / "vuodenajat lajittelu").

### F1: Which Season Is It? (`mode:'which'`, K, CODE)
**Move:** INFER a season from a SET of markers (synthesis, the reverse of the sort) and pick it among four with distractors. **Layout:** `cardGrid({cols:2, rows:2})`: `markerRow` 3 bare icons 78 gap 24 (282 <= 294) + 12 + `seasonChoiceRow` 4 tiles 68 (icon 56 = the K floor) gap 6 (290 <= 294) = 158 <= 314; badges 1-4; no text on cards. Choice row = the 4 icons in the locale's `cycle` order on EVERY card (the child learns one strip), so the correct position moves because **the 4 cards are the 4 seasons in random order** ("circle the same tile everywhere" fails). **Config** `{layout:'which', cards:4, markers:3, choices:4, distinctSeasons:true}`; d1 `{cards:4, markers:2, choices:2}` (winter/summer tiles only); d3 `{cards:6, rows:3, markers:3, choices:4}` (stage 191: 78 + 12 + 68 = 158 <= 191; two seasons repeat). **Verify:** the 3 markers share exactly one season and are distinct nouns; the choice tiles are exactly the 4 keys in `cycle` order; `data-lcs-answer` === that season; at d2 the 4 answers are a permutation of the 4 seasons; no marker is a bin icon. **Query face:** "which season" / "welche Jahreszeit ist das" / "qué estación es" / "vilken årstid" / "mikä vuodenaika".

### F2: Season Wheel: Put the Seasons in Order (`mode:'wheel'`, K, CODE)
**Move:** SEQUENCE the cycle (every framework: the year as a circle; de Jahreszeitenuhr, fr la roue des saisons, it il ciclo delle stagioni, pt a roda das estações). **Layout:** NEW `seasonWheel({d:420, slots, arrows:true})`: a teal ring, 4 round slots at N E S W (d 120) with clockwise curved arrows between them; ONE slot given (icon 56 + name 16 px, tealSoft fill), three slots empty dashed coral circles; below, 3 loose `markerTile`-style icon+name tiles (150 x 100, gap 40 -> 530) in scrambled order; the child draws a line from each tile to its slot. 420 + 20 + 100 = 540 <= 722. **Config** `{layout:'wheel', given:1, tiles:3}`; d1 `{given:2}`; d3 `{given:1, givenIcon:false}` (the anchor shows its name only). Given slot = `cycleStart` at N. **Verify:** slots carry `data-lcs-slot` keys clockwise = `cycle` rotated so the given sits at N; exactly `given` slots filled; tiles = the other keys, scrambled ≠ clockwise order; one solution by construction (fixed direction + one anchor). Same cycle in all 11 (pt-BR shifts MONTHS, not the order): **no refusal anywhere.** **Query face:** "season wheel / seasons in order" / "Jahreszeitenuhr" / "la roue des saisons" / "årstidshjul" / "vuodenaikojen kierto".

### F3: What Does Not Belong? (`mode:'odd'`, K, CODE)
**Move:** EXCLUDE by season (3 markers of one season + 1 intruder from another; concept-based, unlike K-043's identity rows). **Layout:** `display:grid; grid-template-rows:repeat(4, minmax(112px,1fr)); gap:10px` = 722 at the floor; each row a `.ws-lane` with 4 bare icons 78 in 98 tiles, gap 24 (464 <= 639), badges 1-4; the child crosses out (or circles) the one that does not belong. **Config** `{layout:'odd', rows:4, items:4}`; d1 `{rows:4, items:3}` (2 + 1, icon 88); d3 `{rows:5, items:5}` (4 + 1, icon 68, rows minmax 96). **Verify:** exactly one item's season differs; the majority season has >= 3 pooled items in this locale (else the row's season is skipped, and the face refused below 4 rows); nouns distinct; the odd index is not the same on every row; the 4 rows' majority seasons are the 4 seasons at d2. **Query face:** "what does not belong" / "was passt nicht dazu" / "qué no pertenece" / "vad passar inte in" / "mikä ei kuulu joukkoon".

### F4: Months and Seasons: Colour the Season (`mode:'months'`, **G1**, CODE)
**Ownership ruling:** K-322 owns the month -> season link; K-321 never prints a season, and this face never scrambles, numbers or names a month: the 12 names come from `calendar.js` in calendar order and the only question is the season. **Move:** MAP each month to its season with a colour code (the year as 4 x 3). **Layout:** `seasonLegend` (4 entries: icon 40 + name 17 px + `codeColors` swatch 22; winter blue, spring green, summer yellow, autumn orange) 60 + 12 + a 3 x 4 grid of month tiles 200 x 88 (name Baloo 2 700 22 left, a 36 px empty circle right, `data-lcs-month`, `data-lcs-season`) gap 12 -> 444; total 516 <= 722; widths 3 x 200 + 2 x 30 = 660 <= 675; widest month `marraskuu` 105 (m, K-321) + 36 + 40 padding = 181 <= 200. The child colours each circle. **Config** `{layout:'months', months:12, legend:'color'}`; d1 `{months:4}` (Jan Apr Jul Oct, tiles 300 x 120); d3 `{legend:'write'}` (an `answerBox` 120 x 40 instead of the circle; the child writes the season name, G1). **Table:** `SEASONS[loc].monthSeason[12]` = north `[w w sp sp sp su su su au au au w]`, **pt-BR `[su su au au au w w w sp sp sp su]`**; the panel may only override the whole 12-tuple. sv/da/no/fi keep the three-month school blocks (Lgr22 material: vintermånaderna december januari februari); fi `kesäkuu` / `syyskuu` encode their season in the name (2 of 12; the point of the Finnish names, not a leak). **Verify:** every tile's season === the table; each season has exactly 3 months at d2; the legend has 4 distinct swatches from `codeColors`; tiles in calendar order. **Query face:** "months and seasons" / "Monate und Jahreszeiten" / "los meses y las estaciones" / "månader och årstider" / "kuukaudet ja vuodenajat".

### F5: Draw the Tree in Four Seasons (`mode:'tree'`, K, OPEN-ENDED)
**Move:** REPRESENT a season's markers on one constant object (de "Der Baum in den vier Jahreszeiten", fr "l'arbre au fil des saisons", it "l'albero nelle quattro stagioni", nl "de boom in de vier seizoenen", sv "trädet under året"). **Layout:** `cardGrid({cols:2, rows:2})`: header (icon 40 + season name Baloo 2 700 20) + 10 + NEW `bareTree({w:260, h:250})` (trunk + 6 branches, teal stroke 3, no leaves, a ground line; `data-lcs-open`) = 300 <= 314; cards in `cycle` order. No verify; layout lints only. **Config** `{layout:'tree', figure:'tree'}`; d1 = 2 cards (summer / winter, tree 300); d3 `{figure:'tree', caption:true}` (a 40 px `schoolLines` lane under the tree: "In winter the tree ..." written by the panel as a literal per season). **Re-target knob:** `figure:'frame'` renders an empty white frame instead of the tree (a data decision): **pt-BR re-targets to "Desenhe o tempo em cada estação"** (a deciduous cycle is a temperate model; BNCC EI works from the child's own environment); every other locale keeps the tree. **Query face:** "draw" / "zeichnen" / "dibuja" / "rita" / "piirrä" + tree.

**PARAM vs CODE.** All five variations are CODE faces (a `layout` knob + a `verify()` branch, stamped only when declared; the base stays byte-identical, `b3-baseline --check`). `tools/gate-variation-distinct.js` compares `difficulty[2]`: every face's resolved d2 differs from the base's by `layout`, so none is a re-labelled level.

**Rejected non-moves.** Theme swap (the pools ARE the theme) · marker category per page (a pool filter; clothes = K-207, weather/activities cannot fill 4 bins) · "dress the season" (K-207) · "circle the winter things" (the base with one bin; its query face is already carried by ~100 theme-fanned landings per locale, m) · my favourite season (K-323) · trace / write the names (K-284 / G1-244; base d3 keeps the write lane unpublished) · season -> weather match (no autumn weather art) · a rainy/dry MX page (G2+ geography) · count the snowmen · d1/d3 relabelled.
