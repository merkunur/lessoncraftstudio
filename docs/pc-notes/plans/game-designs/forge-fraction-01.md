## 2. Concept & creative hook
**Pip the fox runs a chocolate FORGE.** Bars aren't shaded — they're **forged from pieces**. An empty order box + a wall of **molds**; each mold forges one size of chocolate piece.
- **THE MOLD IS THE DENOMINATOR — BY SIZE, NOT LABEL (the critic's deepest fix):** the molds are **UNLABELED** — each is identified ONLY by a visible **sample piece** sitting in it (a fat 1/3 slab, a thin 1/8 sliver). To fill an order for 3/4 the child must recognize "fourths → the slab THIS big" by SIZE (the order shows `3/4` as notation; there is no printed `4` on a mold to digit-match), pick that mold (DENOMINATOR step), and forge three pieces (NUMERATOR step = iterate the unit). **The bar emerges FROM the pieces** — there is never a pre-divided whole to shade.
- **WRONG MOLDS ARE REACHABLE (the critic's fix B):** every round offers ≥2 selectable molds (the correct 1/b + plausible foils 1/k); the correct one is NOT visually privileged; mold positions randomize per round. A child who forges three 1/3-pieces for a 3/4 order builds a WHOLE → `evaluate` REJECTS it. The denominator is a real, failable size judgment, not a free symbol-match.
- **NO FILL-TELL (the critic's F2):** the whole's far edge is NOT shown as a "fill-to-here" line during the build (no boundary to eyeball-match; the order box reads as a box/shelf, not a measured bar with a visible end); the target is **notation-only** (`3/4`) except the magnitude-match round (#6), where the whole's total length is randomized so a remembered fill-length can't transfer. No mid-build warmer/colder.
- **THE UNIT IS HANDLED EXPLICITLY:** the atomic action is "forge ONE more 1/b" (Pip counts neutrally "one-fourth… two-fourths…" — identical narration right or wrong, no thermometer). On denominator-critical (same-numerator) rounds a non-graded **`ctx.advance()` "how big is one piece from this mold?"** micro-beat forces the size→denominator binding before forging.
- **PERFECT-EACH-ORDER COMMIT (operator-chosen):** the child builds and **freely adjusts** — tap a placed piece to **un-forge** it (drag-back) — then makes ONE deliberate **"hand over the order"** commit. The commit is **SPENT**: correct → the customer beams + the built bar joins Pip's shelf; off → Pip warmly "wraps it up" (no red, no shame) → either way the NEXT order (a different fraction) arrives. No re-handing-over the same box; the child gets one honest, fully-reasoned attempt per order (no probe).
- **EQUAL-PARTS IS A FORGE-REFUSAL (the critic's F8):** the unit-fractions-need-equal-parts round presents an unequally-partitioned whole; forging a unit into it **REFUSES** ("these parts aren't equal — there's no '1/3' here; let's use a fair mold") — a CONSTRUCTION consequence, not an E14 "pick the equal shape" recognition.
- **Anti-generic statement:** NOT shade-N-cells-with-a-fox — (a) no pre-divided whole + the unit-tile mechanic kill shade-the-numerator; (b) **UNLABELED molds + reachable wrong molds + the size→denominator binding kill mold-match** (the critic's deepest catch); (c) no fill-line kills the perceptual fill-tell; (d) commit-is-spent kills the infinite-probe; (e) forge-refuses-on-unequal makes equal-parts a construction act; (f) the gate proves count-the-numerator + glow-chaser + unequal-parts + denominator-blind + overfill + mixed-size + **mold-matcher + commit-prober** solvers ALL fail while the iterate-the-unit oracle passes.

## 3. Core loop & the 6 genuinely-distinct cognitions
**Loop (`stage`: pick-the-unit-by-size → iterate → hand over):** an order arrives (notation `a/b` + spoken) → the child picks the mold whose SAMPLE PIECE is the right size (denominator) → forges 1/b pieces into the box, adjusting freely (un-forge to drag-back) → makes ONE deliberate "hand over" → correct → customer beams + bar joins the shelf → `ctx.correct()`; off → warm "wrapped up" → next (different) order. **No timer/score/streak/countdown/fail/attempts/"X of Y".** Per-pass order-only reshuffle.

**The 6 pedagogy-locked SCORED cognitions (each a different reasoning ACT within fraction-as-quantity; LEAD with #4 so cell-counting is impossible from round one). Each round carries a `cog`:**
| # | Cognition (`cog`) | The child's act | Why genuinely distinct |
|---|---|---|---|
| 1 ★ | **build-a/b** (`build` — the spine) | pick the 1/b mold by size, forge a pieces | iterate the unit fraction a times = a/b as a quantity |
| 2 ★ | **name-the-unit-1/b** (`name`) | "this one piece is what fraction of the whole?" → tap/read 1/b | clause-1 (define the unit) — naming the atom vs assembling the molecule |
| 3 ★ | **equal-parts** (`equal` — forge-REFUSES on unequal, ONE round) | try to forge into an unequally-partitioned whole; it refuses; switch to a fair mold | "1/b only exists when parts are equal" — a construction consequence, NOT E14 recognition |
| 4 ★ | **denominator-changes-the-amount** (`denom` — construct-both-observe) | build 3/4, then build 3/8 (fixed numerator) — the amounts differ because the unit is a different size | reasoning about b's ROLE; NO question/graded magnitude choice (comparison is OUT) |
| 5 ★ | **the-whole-matters** (`whole` — strict, ONE round) | build 3/4 of a small bar AND a big bar — both three-fourths, the big one is more chocolate | the fraction = the SHARE, the whole = OF-WHAT (native-educator ratify-or-cut, F7) |
| 6 ★ | **show-a/b-as-a-target-amount** (`magnitude`) | produce/match a target AMOUNT (whole length randomized) | quantity-as-magnitude — a/b as "this much," a single magnitude |
- **+ the non-graded #7 — cross-shape invariance** (`ctx.advance()` beat, NOT a scored 7th): build a/b on a bar, then Pip asks "same amount of chocolate on the PIZZA?" — the child AFFIRMS invariance across model (reasoning, not a re-skin rebuild).
- **Honest framing (pedagogy + critic F5):** **6 genuinely-distinct SCORED cognitions** — NOT padded to a fake 7th. Cross-shape is a non-graded invariance-affirmation discovery beat. **OUT as scored cognitions:** equivalence-as-task (`3.NF.A.3`), number-line placement (`3.NF.A.2`), unit-fraction COMPARISON ("which is bigger 1/4 or 1/8"), improper/mixed.
- **§A.13.60 ≥7 distinct-to-the-child experiences:** met by the **6 distinct cognitive ACTS × genuine fraction/shape variety** (b ∈ {2,3,4,6,8}, bar + circle, the invariance beat) — genuinely-different fractions + models = the §A.13.60 standard (NOT number-swap padding, which the operator rejects). Order-only reshuffle + §20.2 per-session Fisher-Yates; **no back-to-back same-fraction across denominators** (anti fill-transfer).
- **Free slice = build + denominator-changes-the-amount + name-the-unit** — proves iteration, the denominator's role, and the unit-fraction; the mold-matcher + count-the-numerator + commit-prober + fill-tell solvers all fail.

## 5. Pedagogy
- **3.NF.A.1 instantiation:** the child reasons "to make a/b, reach for the 1/b-mold (by SIZE) and forge a of those pieces" — that sentence IS the standard, and it IS the interaction. The amount a/b is built by iterating the unit fraction; the result is a single quantity.
- **THE KEYSTONE RULES (pedagogy + critic):** (i) **ITERATE the unit** (atomic "add one more 1/b," never shade). (ii) **the tile's SIZE carries the denominator** (UNLABELED molds — the acid test made real; kills mold-match). (iii) **wrong molds reachable + a real size judgment** (denominator is failable). (iv) **no fill-line / no mid-build signal** (kills the fill-tell + glow-chase). (v) **commit-is-spent, one deliberate attempt** (kills the probe). (vi) **equal-parts via forge-refusal** (construction, not E14 recognition). (vii) **b ∈ {2,3,4,6,8}, a≤b, allow a=b, no improper** (the CCSS Grade-3 bound, hard-gated).
- **§20.8 demonstrate-don't-touch (the critic's headline):** as a labeled-mold / fill-line / infinite-probe design it TOUCHED 3.NF.A.1 (a child digit-matches the mold + fills-till-it-looks-right + probes the commit — zero quantity reasoning). As an UNLABELED-mold (size-judged) + no-fill-line + spent-commit + forge-refuses design it DIRECTLY INSTANTIATES the standard (recognize 1/b by size + iterate it a times is the only path). The line is exactly: the mold is judged by SIZE not label; the commit is spent. The gate (mold-matcher + commit-prober + count-the-numerator + fill/glow-chaser + unequal-parts + denominator-blind all FAIL; the iterate-the-unit oracle PASSES) is the machine-checked proof.
- **also_teaches:** `3.NF.A.3`/`3.NF.A.2` ONLY where a round genuinely surfaces them (light — e.g. the invariance beat lightly gestures A.2 length). **NEVER `2.G.A.3`** (tagging it re-imports the E14 collision the re-tag exists to avoid). Distinct from E14 = construct vs recognize.
- **Grade fit + bounds:** b ∈ {2,3,4,6,8} (hard gate); a ≤ b; allow a=b (4/4 = the whole — reached by iterating four explicit fourths, SR reads "four fourths" not "one whole", capped to occasional); NO improper/mixed (Grade 4). LEAD with same-numerator/different-denominator (3/4 vs 3/8). Models: bar (default) + circle (pizza).
- **No-shame:** the filling shelf is the intrinsic reward; off-builds wrap up warmly + flow on; the forge refuses unequal parts gently; Pip never fails the child.

- **Runtime: pick-unit-by-size → iterate → hand over.** `forge-core.js` holds the round `{ id, cog, model ('bar'|'circle'), b (denominator→b equal slots), a (target), molds[{den, sampleSize, equal}] (≥2, UNLABELED, positions randomized, ≥1 wrong reachable), targetMode ('notation'|'magnitude'), wholeLength (randomized for magnitude) }` + `selectMold/forgeUnit/unForge` + `evaluate(round,state)` → correct = (placed.length===a) AND (every placed.unitDen===b — UNIT-SIZE GATE) AND (all-same-size) AND (no-overlap/in-bounds). **The answer = `f(recognize 1/b by size + iterate it a times)`, never `f(shade N cells)` / `f(digit-match the mold label)` / `f(fill till it looks right)` / `f(probe the commit)`.**
- **State separation (anti-cheat):** `snapshot()` exposes `{ cog, molds (UNLABELED — sample piece by SIZE only, NO printed denominator), order (notation a/b, NO fill-line target except magnitude), box (placed pieces, NO progress indicator), shelf }`. `facts()` exposes per-round `{ unitFractionIsTheTile (===true), moldsUnlabeled (===true), wrongDenominatorReachable (===true; ≥2 molds, correct not privileged), denominatorAffectsValidity (===true), equalPartsForgeRefuses (===true for cog=equal), noFillLineTarget (===true except magnitude), noGlowTelegraph (===true; nothing changes at count===a), commitIsSpent (===true; no re-hand-over), answerIsQuantityNotCellcount (===true), countBounded (===true), bInGradeSet (b∈{2,3,4,6,8}), aLessEqualB (===true), noComparisonVocab (lint, all 11 locales), noProgressIndicator (===true) }`.

## 8. Runtime mapping + MEASURED build-gate + PER-LOCALE
- **Round descriptor (DATA; answer emergent from the build, NEVER per-cell):** `{ id, cog (build/name/equal/denom/whole/magnitude), model ('bar'|'circle'), b (∈{2,3,4,6,8}), a (≤b), molds[{den,sampleSize,equal}] (≥2 UNLABELED, ≥1 wrong reachable, positions randomized, correct not privileged), targetMode ('notation'|'magnitude'), wholeLength (randomized for magnitude) }`. `makeRounds`: ≥7 experiences spanning the 6 cognitions + the invariance beat; LEAD with same-numerator/different-denominator; no back-to-back same-fraction across denominators; b∈{2,3,4,6,8}, a≤b; order-only reshuffle.
- **`verify-forge-core.js` (MEASURED — drives the REAL `evaluate`; HALTS build) — the critic-armed solver set:**
  1. **ITERATE-THE-UNIT ORACLE PASSES 100%:** selects the mold where `sampleSize===1/b`, forges a pieces of size 1/b → `evaluate` returns correct.
  2. **COUNT-THE-NUMERATOR solver FAILS:** forges a pieces of a WRONG size → unit-size gate rejects (3 of 1/3 = a whole ≠ 3/4); assert `denominatorAffectsValidity`.
  3. **MOLD-MATCHER solver (the critic's DEEPEST — NEW) FAILS:** picks the mold by digit-matching the order's denominator → on UNLABELED molds there is NO digit to match → it must guess size → fails ≤ chance; assert `moldsUnlabeled` + `wrongDenominatorReachable` (≥2 molds, correct not privileged, a wrong path reachable AND failing). **If a mold-matcher solver the gate catches cannot be written, the cheat is still live.**

  7. **DENOMINATOR-BLIND solver FAILS:** always uses a fixed mold → fails on every round where b≠that mold (wrong molds are reachable + failing).
