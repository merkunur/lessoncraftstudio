## 5 Quality verdict

I would print this for my class. The base is the page I would build myself if I had time: a real plant, roots underground in a soil box you can see into, a pod you can see the seeds in, and numbered tags so the children write every answer in one tidy column that I can mark by following six threads. The needs page makes them check two things at once, which is the actual science, instead of letting them circle the one picture that is not a toy. The cut-and-glue wheel gives them a finished life-cycle diagram to keep, and it closes back to the seed, which is the point the chicken page cannot make. What would embarrass me: a child writing "seed" on the pod because the ring sits too close to the window (the gate and one human read at 100 % must catch it), a German colleague marking celery wrong because her book calls it a leaf stalk (hence the per-locale refusal), and the flower page sold as grade 2 when most of Europe teaches it in grade 3 or 4, which is why it is filed at G3 and says so.
