## §1 — Concept / world
**The Twin Moons of Pebblefall.** Wren, a barefoot tide-keeper, works a moonlit beach with you; the village's law is FAIRNESS (unequal shares make the creatures droop — the felt equal-partition stakes). Two moons embody the two meanings as **physically-OPPOSITE vessel behaviors** — 🌕 **Silver Moon = baskets, grow the contents** (partitive); 🌙 **Amber Moon = boats of a fixed cargo, grow the number of boats** (quotitive). The hands do opposite things. Non-numeric abundance vessel: the tide-line of shells gets prettier across a session (never a count). `ctx.correct()` auto-advances.

## §2 — The standard + the load-bearing cognition
**3.OA.A.2 (Grade 3, SOLE primary)** — interpret whole-number QUOTIENTS via equal partitioning, BOTH meanings: PARTITIVE (share N among G groups → how many in EACH; quotient counts objects-per-share) + QUOTITIVE (make groups of size S → how many GROUPS; quotient counts number-of-groups). **3.OA.A.3** (word problems) = content layer, NOT tagged. **Cognition (pedagogy ruling, AS RE-CENTERED by the critic):** modeling = scaffold; the GRADED assessment = (1) PRODUCE the correct equal-partition STRUCTURE from which-quantity-is-given (not surface-handed) + (2) INTERPRET what the quotient COUNTS under a NEUTRAL, noun-decorrelated prompt, having been given only ONE of {#groups, group-size}. **Numbers:** whole quotients ONLY (no remainders — defer to 4.OA), total ≤100, param & quotient 2-10 (concrete rungs ≤24-30). **FENCES:** E13 array-multiplication (never "how many altogether"; the total is GIVEN, the unknown is a PART), free equal-grouping "Ring the Groups" (always fix total + one parameter), fractions (whole-number count, no ½/¼ language), quotitive ≠ subtraction-operation framing, missing-factor (a valid strategy but neutralized by the unit gate — never FRAME the task as find-the-missing-factor). Numbers/words = real DOM/SVG `<text>`.

## §3 — THE ARCHITECTURE REWORK (the heart; the deepest flaw + fix)
**The critic's catch — the (value,UNIT)-pair gate looks airtight but is a CLEVER-HANS / LEXICAL-TELL cheat one level below it, and a recall-fluent child bypasses the whole standard.** (A) **PROMPT-KEYWORD-MATCH (binding):** the interpretation prompt TELEGRAPHS the unit — "how many in EACH basket?" → tap "in each basket"; "how many BOATS?" → tap "boats". The unit is FULLY DETERMINED by the prompt noun → a child copies the noun, passing the (value,unit) gate with ZERO understanding. A keyword-matcher is ADAPTIVE (reads the prompt, flips exactly when the meaning flips) so it tracks the meaning PERFECTLY while modeling none of it — and the FIXED-policy `MEANING_CONFLATION_SOLVER` structurally CAN'T catch an adaptive cheat. Twin Tide is its EASIEST round (value held constant → the round is 1 BIT, and that bit is the prompt noun). (B) **STRUCTURE IS HANDED:** the surface pre-draws the partitive groups / hands the quotitive size-template → "structure matches meaning" is a TAUTOLOGY (the surface IS the structure; the child fills it). (f) **THE FLOOR — RECALL ∘ KEYWORD-COPY:** by Grade 3 the VALUE (12÷3) is a recall fact → it comes free → the ONLY thing graded is the unit → and the unit is keyword-copied → **the entire graded interaction reduces to "read the noun, tap the matching chip"** (zero partitioning, zero meaning-distinction). **The structural truth (the ceiling):** natural language FAITHFULLY signals partitive vs quotitive ("shared among" vs "groups of" genuinely reflect which quantity is given), so the classify-from-words task is INHERENTLY a partial VOCABULARY task — the MORE readable the prompt, the MORE leaky (inverted quality gradient) → classification CANNOT sit on the grade boundary.

**THE FIX — re-center the GRADED core onto the cognition that survives KEYWORD-STRIPPING (the design STAYS flagship — "build it & say what it counts," not "match the noun"):**
- **GRADED CORE 1 — PRODUCE-THE-STRUCTURE (not surface-handed).** The groups are NOT pre-drawn. The child must DECIDE the structure from which-quantity-is-given: given "3 baskets" (a COUNT) → lay out 3 groups + share; given "baskets of 3" (a SIZE) → form groups of 3. The structure they BUILD reflects their reading of which quantity was named. `STRUCTURE_HANDED_SOLVER` (accept a pre-drawn structure) must FAIL — there IS no pre-drawn structure to accept.
- **GRADED CORE 2 — GIVEN-QUANTITY INFERENCE under a NEUTRAL prompt (the keyword-stripped meaning-distinction).** The interpretation prompt names NO unit ("What does the **4** count?"); the situation gives the SAME noun both ways but varies WHICH quantity is named — "you have **3 baskets**" (count → quotient counts objects-PER-basket) vs "each basket holds **3**" (size → quotient counts BASKETS) — so the ONLY disambiguator is WHAT-WAS-NAMED (a count vs a size), NOT a keyword. The answer chips are ROLE-described + noun-VARIED ("how many in one group" / "how many groups there are"), never echoing the prompt. The load-bearing clause is `GIVEN_QUANTITY_INFERENCE`; `RECALL_FACT_SOLVER` must FAIL EVEN WHEN THE VALUE IS CORRECT.
- **DEMOTE to illustrative/scaffold (NOT graded):** Twin Tide (value-constant → 1 leaky bit) + "Which Moon is this?" (keyword-classifiable from the word-problem) — kept as lovely teaching beats, stripped of assessment weight (the lexical-classification task is a partial vocab task that must NOT sit on the grade boundary).

## §4 — Anti-cheat architecture (the measured gate)
NEW `verify-quotient-share-core.js` (window-shim; drives the REAL core; `derive(descriptor)` is the ONLY place the answer exists — `{total,divisor,meaning,context}` → (groups, each, askedValue, unit, givenKind); NO stored quotient/structure/unit). `grade()` = **(A) equal-partition** (every share equal + pile==0) **∧ (B) structure CHILD-PRODUCED matches the given-quantity** (not a pre-drawn fill) **∧ (C) interpretation value+unit meaning-correct under the NEUTRAL prompt**. Solvers — ALL must FAIL:
- **`PROMPT_KEYWORD_MATCH_SOLVER`** (NEW — the key one; ADAPTIVE) — picks the unit/role chip with maximal lexical overlap with the prompt string → must FAIL via the NEUTRAL noun-free prompt + a generation-time assert `token-overlap(prompt, correct_chip) ≤ token-overlap(prompt, distractor_chip)` for EVERY round (correct chip never the most prompt-similar).
- **`STRUCTURE_HANDED_SOLVER`** (NEW) — accepts a pre-drawn structure → must FAIL (no structure is pre-drawn; the child produces it).
- **`GIVEN_QUANTITY_INFERENCE` assert + `RECALL_FACT_SOLVER` must fail even with correct value** (NEW floor-fix) — a solver that supplies the correct recalled VALUE but infers the unit by anything other than which-quantity-was-given must FAIL; the load-bearing clause is "was I given the COUNT or the SIZE?" with the noun held constant.
- **`MEANING_CONFLATION_SOLVER`** (fixed-unit policy) + **`UNEQUAL_DEAL_SOLVER`** (A fails) + **`ROUND_ROBIN_NO_INTERPRET_SOLVER`** (perfect deal but no interpretation → C fails, `INTERPRETATION_REQUIRED`) + **RANDOM** — all FAIL.
- Structural asserts: `EQUAL_PARTITION_REQUIRED`, `STRUCTURE_PRODUCED_NOT_HANDED`, `PROMPT_DECORRELATED_FROM_UNIT` (the token-overlap assert), `GIVEN_QUANTITY_LOAD_BEARING ≥N` (same-noun count-vs-size rounds where only what-was-named disambiguates), `ANSWER_DERIVED_NOT_STORED` (mutate total/divisor/meaning → answer moves; the partitive↔quotitive flip witness), `ANSWER_INFO_ABOVE_1_BIT` (the response is a STRUCTURED assemble-the-interpretation, not a 2-chip toggle; on any value-constant round the child reconstructs the full relationship 12 = 3 × 4 read two ways), ≥7 variety, `CONTEXT_INVARIANT` (mutate context → grade unchanged).
- **Wrong-answer re-show (no-reveal):** unequal partition → pulse the differing shares ("this has 5, this has 3 — fair shares only"); wrong meaning → re-orient to which-quantity-was-GIVEN ("you were given 3 baskets [a count] — so the answer counts what's in EACH"), gesturing at the given, never the value; right-value-wrong-unit → sweep the referent (the containers vs the objects-in-one). Single-commit teaching, never reveals the number.

## Cohort doctrine this game adds
**The CLEVER-HANS / LEXICAL-TELL lesson — PROGRAM-WIDE.** When a standard's target distinction is FAITHFULLY SIGNALED BY NATURAL LANGUAGE (partitive "shared among" vs quotitive "groups of"; author's-purpose cue-words; main-idea topic-words; tone words; part-of-speech-from-a-sentence; word-problem-type), the answer is recoverable by **KEYWORD-MATCHING it to the PROMPT** — a CLEVER-HANS cheat: a child copies the noun/cue from the question and passes WITHOUT the cognition. The crucial trap — **an ADAPTIVE keyword-matcher (reads the prompt, flips exactly when the meaning flips) tracks the meaning PERFECTLY while modeling NONE of it, and a FIXED-POLICY gate solver (the usual "always-answer-X" conflation solver) STRUCTURALLY CANNOT catch it** — you need an ADAPTIVE (prompt-reading) gate solver that maximizes prompt↔answer lexical overlap. The TELL is an **inverted quality gradient**: the MORE natural/readable the prompt, the MORE leaky (good prose = good keywords), so the classify-from-language task is inherently a partial VOCABULARY task that must NOT sit on the grade boundary. And the FLOOR — if the VALUE is independently recallable (a times-table fact, a memorized answer) AND the only residual signal is the keyword-copyable label, the WHOLE assessment reduces to "copy the noun from the question," and the `ANSWER_DERIVED_NOT_STORED` value-witness does NOT save you (the cheat RECALLS the value, doesn't store it). **THE FIX: (1) a `PROMPT_KEYWORD_MATCH_SOLVER` (adaptive, lexical-overlap) must FAIL + NEUTRAL noun-free prompts + a generation-time `token-overlap(prompt, correct) ≤ token-overlap(prompt, distractor)` assert; (2) RE-CENTER the graded core onto the cognition that survives KEYWORD-STRIPPING — INFER FROM WHICH QUANTITY/FEATURE IS GIVEN (hold the noun CONSTANT, vary only what-was-named: a COUNT vs a SIZE) so the disambiguator is structural not lexical, AND make the structure CHILD-PRODUCED not surface-handed; (3) raise the answer's information content ABOVE 1 BIT (a structured assemble-the-answer, not a binary chip; never hold every other quantity constant). Demote the keyword-classifiable rounds to illustrative scaffold.** The re-center KEEPS the game flagship (scope unchanged; no operator fork — like Game-74). Generalizes to EVERY classify-from-language / match-the-meaning game.
