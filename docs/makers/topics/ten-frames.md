# Maker: Ten Frames, Tally Marks & Quick Look (`ten-frames`)

Group **math** · language need **none** · 10 existing templates + 3 new · replaces old app(s): —

## Settings a teacher sets

- frame: five / ten / double ten
- range
- dots or pictures
- task: count / fill / match / make ten / tally
- (plus the settings every maker has: language (one of our 11); template (gallery by sub-topic); level 1-3; picture theme / own pictures where pictures appear; number of problems / page fill; title + instruction text (editable); answer key on/off; pages: add / duplicate / delete; regenerate (new seed, same settings); paper: Letter for en-US, A4 elsewhere (switchable))

## Templates from today's worksheet types

**Count a set (scattered, framed, in an array) and name / write / match the number, to 10–20**

- `K-004` Ten-Frame Count — Count the pictures in the frame. Write the number. · picture themes (scripts/worksheet-gen/types/k/K-004-ten-frame-counting.js)
- `K-024` Frame Match — Draw a line from each number to its ten-frame. (scripts/worksheet-gen/types/k/K-024-match-frame-numeral.js)

**Make a set of a given number (fill the frame, colour exactly N)**

- `K-005` Fill the Frame — Draw a dot in the frame for each one the number shows. (scripts/worksheet-gen/types/k/K-005-fill-the-ten-frame.js)

**Represent a count with tally marks (bundles of five) and read a tally back as a number**

- `K-014` Make Your Tally — Count the pictures. Draw tally marks in the box. · picture themes (scripts/worksheet-gen/types/k/K-014-write-the-tally.js)
- `K-015` Read the Tally — Count the tally marks. Write the number. (scripts/worksheet-gen/types/k/K-015-read-the-tally.js)
- `K-025` Tally Match — Draw a line from each number to its tally marks. (scripts/worksheet-gen/types/k/K-025-match-tally-numeral.js)

**Subitize: recognise small quantities and dot / dice / frame arrangements at a glance**

- `K-017` Quick Look! — Do not count one by one! Look quickly and circle how many. (scripts/worksheet-gen/types/k/K-017-subitizing-dots.js)
- `K-018` How Many? Quick! — Look quickly and circle how many you see. · picture themes (scripts/worksheet-gen/types/k/K-018-subitizing-icons.js)

**Add two groups within 10-12 using a picture, ten-frame, domino or dice model**

- `G1-105` Ten-Frame Addition — Count the two colors. Write the addition sentence’s answer. (scripts/worksheet-gen/types/g1/G1-105-ten-frame-addition.js)

**Find the partner that makes 10 (number bonds to 10)**

- `G1-106` Make 10! — How many more dots to make 10? Write the missing number. (scripts/worksheet-gen/types/g1/G1-106-make-ten.js)
