## Reglas anti-canibalización

| Regla | Descripción |
|-------|-------------|
| App vs. Herramienta | Las páginas de apps apuntan a palabras clave « crear + vender + para imprimir ». Las páginas de herramientas apuntan a « gratis + online + sin registro ». |
| Guía vs. App | Las guías usan palabras clave informacionales (« cómo », « guía », « paso a paso »). Las apps usan palabras clave transaccionales (« crear », « generador »). |
| Paquete vs. App | Los paquetes usan palabras clave « pack / paquete ». Las apps individuales usan el tipo específico de generador. |
| Idea vs. Guía | Las ideas usan palabras clave « nicho / negocio ». Las guías usan palabras clave « guía / estrategia ». |
