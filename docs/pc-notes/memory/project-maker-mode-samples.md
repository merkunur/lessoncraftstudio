The 36 worksheet-generator ("maker") landing pages (`/[locale]/tools/<native-slug>`, `MakerLanding.tsx`) now carry a **"See what you can make"** section: one playable sample deck per real exercise MODE the generator produces (e.g. addition → find-addend / image-image / image-number / mixed), each with a localized mode name + 1-sentence explanation, in the page's language. **COMPLETE + LIVE in all 11 locales.** Operator brief: "show deck samples in the corresponding language so users see what they can create; show + explain each exercise mode; professional design." Plus: crossword/wordsearch/matching makers also show a **cross-language ("learn a language") strip** linking to `/learn`.

**Architecture:**
- `frontend/lib/seo/maker-samples.ts` — `fetchMakerSamples(makerKey, locale)` → `{kind:'interactive'|'pdf'|'none', multiMode, samples[], crossLanguage[]}`. Mode set is DB-honest (`groupBy exerciseMode`, published, `MONOLINGUAL_WHERE`); one representative deck per mode (greedy bucket, recent-first), **per-mode EN fallback** when a locale lacks a mode (chip shows the sample's real language). null mode = key `'default'`, included only when ≥25% of the largest named mode (else straggler dropped). **If a multi-mode maker collapses to <2 showable modes in a locale → theme-varied single-mode fallback** (no lone mode card). Single-mode makers show 3 theme-varied samples. **PDF-only makers (coloring/writing/draw-and-color/drawing-lines) have 0 decks → kind:'none' → no section.** `picture-path` exerciseType set = `['picture-path','picture-trail']` (EN emits picture-trail, §15.10).
- **CRITICAL: the playable deck URL is the DIRECTORY `deckAssets().deckDir` (`/<locale>/decks/<slug>/`), NOT `deckHtml`.** nginx serves the deck at the trailing-slash directory; `/deck.html` AND the no-trailing-slash form both 404. (Initial bug: used deckHtml → all thumbnails 404 on click. Fixed `fef348f2`.) Thumbnails are fine via `deckAssets().thumbnail`.
- `frontend/components/makers/MakerSampleTile.tsx` (client, cloned from `FeaturedDeckTileV3`; Direction-A palette; thumbnail→modal-iframe play; `variant:'interactive'|'pdf'`; honest language chip) + `MakerSamples.tsx` (server section: mode grid 1-col@375/2@sm/3-4@lg + cross-language strip with coral accent + `makerScreenshots()` for JSON-LD). **Section guard:** renders only when `labels.samplesHeading` exists (so an untranslated locale shows nothing, not a heading-less grid). Wired into MakerLanding after the hero; `WebApplication` JSON-LD gains `screenshot[]` (ImageObject of the sample thumbnails — NOT per-sample LearningResource, which belongs to the deck landings).
- **Content** in `frontend/messages/maker-content/<locale>.json`: `MakerEntry` gains optional `modes` (modeKey→explanation), `modeNames` (override names for null/'default' + the taxonomy-nameless image-only/findBig/orderAsc + friendly symbol names), `samplesIntro` (single-mode). `labels` gain the 7 chrome keys. Mode display NAMES come from `topics-taxonomy axes.exercise-mode.<mode>.name.<locale>` via `getExerciseModeName` (already 11-locale); only the explanations were authored.

**i18n:** EN authored directly (29 makers, 56 mode explanations + modeNames + 7 single-mode intros + chrome) via `scripts/seo-landing/inject-maker-modes-en.js`. The 10 other locales translated by native agents → `scripts/seo-landing/maker-modes-<locale>.json` (source = `maker-modes-en.json`) → merged via `inject-maker-modes.js <locale>`. `[NSR-FLAG][fi]`.
