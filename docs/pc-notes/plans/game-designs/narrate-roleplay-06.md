## Concept & creative hook
**The Lost-and-Found Puppet Theater.** **SOCK** works the front counter + CAN SEE the bin; **the child is Sock's voice** (the puppeteer). **SHADOW** works BEHIND THE CURTAIN + CANNOT SEE the bin — Shadow only HEARS what Sock says, then emerges to fetch/point/draw exactly what the words described.
- **The physical can't-see asymmetry IS the pedagogy:** a vague turn can't secretly succeed. "The cup" with two cups → Shadow honestly holds both: *"This one? Or this one? I can't tell from back here!"* The child SEES the message wasn't enough — the visible consequence that builds the metalinguistic awareness 5-6yos lack.
- **OCULAR + per-round (fix #4):** EVERY round shows Shadow physically losing sight — Shadow peeks, Sock "no peeking!", Shadow ducks behind the curtain, **the bin visibly greys on Shadow's side**. The asymmetry is ocular + repeated, never narrative-and-once. Shadow's confusion is **empathetic/apologetic** (worried face, "I tried! tell me more?"), NEVER buzzer-like — the miss is the MESSAGE's fault.
- **The puppeteer-authors-the-voice frame** solves the no-mic problem honestly: the child ASSEMBLES Sock's turn from meaning-part tiles (slot-filling production, developmentally correct for K, NOT oversold as free authorship per fix #1), taps "Tell Shadow" → Sock's mouth flaps + TTS voices the line → Shadow acts.
- **The minimal SUFFICIENT description wins — say enough, NOT too much (the keystone, fix #1):** Shadow holds only a few words. Ramble (pile every tile) → *"too many words — I forgot half! Just what I need?"* → Shadow fetches randomly (a visible over-spec consequence, symmetric to under-spec). BOTH vague AND kitchen-sink fail; only *sufficient* wins — the real K skill (kids over-tell as much as they under-tell).
- **Anti-generic:** NOT a manners quiz / line-pick MCQ in a puppet skin — (a) the listener physically can't see → clarity non-fakeable; (b) correctness DERIVED from cardinality + the memory cap, never a stored key; (c) politeness tiles mechanically INERT; (d) a board ships only if the gate proves under- AND over-spec both fail and a random-tile-piler can't brute-force it.

## Core loop & the distinct experiences
**Loop:** (1) setup + the ocular asymmetry (duck-and-grey-out, fix #4); bin populated w/ target+distractors. (2) **Stage 0 compose** — assemble Sock's turn from chips into a bounded **"Sock's words" tray** (composed turn visibly assembles — authorship felt); per-tap chip TTS (icon+word chips); vagueness allowed; **"Tell Shadow" gates on STRUCTURAL COHERENCE (fix #2)** — the object slot must be filled before attributes attach (no "red … behind" without a noun → a meaningful turn, not a tile-mash). (3) "Tell Shadow" → draft bubble POPS to Sock (the compose→resolve phase-transition signal, fix #6a) → mouth-flap → `ctx.speak(utter(turn))`. (4) **Stage 1 resolve(turn,tray) + memory cap (DERIVED, never stored):**
- **clear-and-minimal** (match-set===1 AND attrs ≤ cap) → fetch → reunion → `ctx.correct()`.
- **ambiguous** (≥2) → Shadow holds the set, worried, **asks the missing-slot CATEGORY** ("which color?") — withholds content → additive revise (tiles preserved) → `ctx.wrong()` (no penalty).
- **overwhelmed** (attrs > cap) → forgets half, fetches randomly → "too many words — just what I need?" → the child TRIMS.
- **wrong** (===0) → closest honest match, puzzled → treated like ambiguous.
(5) **Repair = content-withholding + CHILD-attributed (fix #3):** Shadow asks the category; success is ALWAYS the child supplying it — "resolve kindly" NEVER means Shadow guesses right; a stuck child gets the palette scaffolded to the **correct disambiguator as the only remaining tap** (even the floor win is the child supplying the missing info). Cap at ONE category-prompt before the scaffold-to-one floor (no spiral).

**Distinct experiences — HONEST re-count (fix #5): ≈6 visibly-distinct LISTENER-ACTIONS × varied referential contexts, ≥7 rounds (NOT "9 distinct"):**

|---|---|---|---|
| **A. DRAW-IT** (Shadow draws the description part-by-part on a chalkboard; incomplete turn = a visibly UNFINISHED picture) — ★ SPINE/HERO | describe-for-a-listener-who-can't-see (audience design) | the purest non-fakeable referential test — under-spec is LITERALLY a half-drawn picture | the render is a pure function of the words; over-spec → can't draw it all ("too much!") |
| **B. FETCH-FROM-BIN** | fetch-the-one (add the disambiguating attribute) · name-the-object · same-name-trap (joint necessity: two cups AND two balls, only "red cup") · complete-the-thought (topic-OPENING fragment only; ellipsis accepted in response contexts) · repair-the-fragment | sufficiency / disambiguating specificity / completeness | cardinality + memory cap; every proper subset of the minimal set → ambiguous (gate-proven); politeness inert |

Draw-it (A) is the hero; the fetch-family (B) is content-varied supporting cast, never 6 reskins.

## Win-states & juice (no competition)
No timer/score/streak/countdown/fail — and explicitly **NO clarity-meter/stars** (would re-introduce a score). **Win = Shadow understanding + ACTING** (object slides over / the drawing completes / mood lights up / the ticket stamps — "I made myself understood" = the object moved). Reunion: the lost kid lights up, Sock+Shadow bow, the reunited object joins a **Lost-and-Found shelf** filling across the session (the non-numeric vessel). Ambiguous/overwhelmed/wrong is warm: no buzzer/X/sad-sound; Shadow's confusion is empathetic + about the WORLD ("can't tell from back here!" / "too many words!"), tiles persist, the missing slot glows additively. Full-pass keepsake = the filled shelf card → cross-game `GameCollection`. CSS/WebAudio; reduced-motion; mute fully playable (bubble + visible action); eyes-closed playable (TTS + `ctx.announce`).

## Pedagogy
- **The clarity construct (SL.K.6's express-ideas-clearly facet):** enough of the RIGHT info, well-enough-formed, that a listener could understand + ACT = completeness · sufficiency · disambiguating specificity · appropriate word choice — **AND the keystone: NOT TOO MUCH** (over-telling defeats clarity; the memory cap instantiates it).
- **The 4 IMPOSTORS held CONSTANT** (each a different standard; if any discriminates the winner → REJECT): politeness (SL.K.1.b — chips INERT), grammar-in-isolation (L.1.1.j — no decoy rude/ill-formed), vocabulary breadth, listening-comprehension (the child PRODUCES; the listener's comprehension is the *consequence*, not the *test*). THE TEST: would a RUDE ungrammatical plain-word utterance with the right specific info still WIN? yes → clarity (ship). Can a polished-but-vague one win? yes → wrong thing (reject).
- **No-mic honesty (the build record + on-page note, fix #6):** the activity page carries a visible scope note — *"This game builds clear expression — choosing the right words so a listener understands. (Speaking aloud is practiced with a grown-up.)"* SL.K.6 stays the framework/SEO anchor (JSON-LD `targetName` + the `/standards/` hub) but the hub does NOT present full SL.K.6 coverage; co-primary L.1.1.J reflects the mechanic's true center of gravity; a future "say-it-louder" game reserves the audibility facet.
- **Referential communication = the gold standard, dev-correct for K** (Krauss & Glucksberg describer/guesser). The caveat that justifies the design: 5-6yos are systematically bad at message adequacy AND bad at detecting their own inadequacy → that's WHY it's the curriculum; under-spec must have a VISIBLE consequence + the asymmetry must be PHYSICAL (a secretly-seeing listener reinforces vague messages).
- **No-shame = natural-consequence-then-repair (HONEST + child-attributed):** Shadow is confused *only and exactly when the turn is genuinely insufficient* (gate-guaranteed); the repair names the missing CATEGORY, withholds the CONTENT; success is ALWAYS the child supplying it (never Shadow guessing right, fix #3); cap at one prompt → scaffold-to-one floor; reward = being understood.
- **Complete-ENOUGH not full-sentence-formalism** (SL.1.6 = complete *when appropriate*): accept natural ellipsis in response contexts ("The red one, please"); require completeness only in topic-opening fragment rounds. **Per-language:** pro-drop locales (es/it/pt/fi) — a subjectless sentence is CLEAR → the completeness slot is per-language data, NEVER engine-inferred.

## Interaction & UX
- **The mechanic:** correctness = the CARDINALITY of the match set `resolve(turn,tray)` returns AND attribute-count ≤ Shadow's memory cap. Adding "red" collapses two cups to one; piling six attributes overwhelms Shadow → only the *minimal sufficient* turn wins. Listener action DERIVED; no `correctAnswer` ever stored.
- **Engine data:** round stores the listener's WORLD (`tray`: target+distractors `{object, attributes, position}`) + the child's structured `composedTurn` (`intent, object, attribute[], quantity, position, feeling, reason` + inert `politeness`) + per-round `memoryCap` (= minimal-sufficient attr count + small tolerance) + a per-language `completeness` flag. `resolve` = pure: filter by object → narrow by each attribute → quantity/position → `matches===1 && attrs≤cap`→`'clear'`; `attrs>cap`→`'overwhelmed'`; `===0`→`'wrong'`; `≥2`→`'ambiguous'`. **`utter(turn)` = a LOCALIZED TEMPLATE** from slots (NOT chip-concatenation — load-bearing for agreement langs §A.13.54: "rote Tasse" not "rot Tasse"); same string → bubble DOM AND `ctx.speak`.
- **DOM:** `.ps-stage[.ps-puppets(Sock+Shadow) + .ps-tray/.ps-curtain(bin/chalkboard/shelf)]` + `.ps-compose[.ps-sock-words(bounded composed-turn tray) + .ps-chip-rail + .ps-say-btn]` + `[aria-live]`. Chips real `<button>` (≥44px + keyboard/AT). Mouth-flap CSS gated by speech start/end; two distinguishable voices.
- **Stage machine** (shell `stage`; NO Check button; only `ctx.correct()` advances): stage 0 compose (coherence-gated Tell-Shadow) → pop-to-puppet + speak → stage 1 resolve. Ambiguous/overwhelmed/wrong → category-prompt + additive revise + `ctx.wrong()` (no penalty).
- **Mobile @280-768 — PHASE-BASED region swap (fix #6a), NOT co-render-everything:** **Compose phase** = Sock (small, top) + the bin + the chip rail + Tell-Shadow; Shadow a small ducked silhouette behind the greyed curtain. **Resolve phase** = the curtain expands, Shadow emerges, the bin/chip-rail collapse, Shadow's action (fetch OR **the chalkboard fills the freed space** for draw-it) gets the real estate; the draft bubble pops here (one fast, skippable beat). **≤~6 icon+word chips per round**; chips ≥44px tap-to-place primary (drag enhancement via `window.LCS.drag.linear`); placed tiles → the bounded "Sock's words" tray. Bubble `line-clamp:2` but FULL text to TTS. Pass `audit-game-mobile.js` 280-768 empty+filled **incl. the draw-it worst case (chalkboard + max chips)**.

## Runtime mapping + MEASURED build-gate + PER-LOCALE
- **Round descriptor (DATA; engine never holds a localized sentence):** `{ listenerAction:'draw|fetch|reach|mood|sort|two-turn', tray:[{object, attributes, position}], target, memoryCap, completeness:<per-locale flag>, chips:[…], promptKey, exchanges? }`. NO `correctAnswer`; outcome only from `resolve`.
- **`verify-puppet-speak-core.js` (MEASURED — drives the real `resolve` + the real round set; HALTS build):**
  1. **Under-spec PROVABLY ambiguates (the original core anti-cheese):** enumerate the minimal sufficient attribute set; EVERY proper subset → `'ambiguous'`(≥2) or `'wrong'`. **If any incomplete build yields the singleton target → REJECT the round.**
  2. **OVER-spec is NOT a free win (fix #8, the keystone's gate):** a turn carrying > (minimal+tolerance) attributes yields `'overwhelmed'`. **If over-specifying still yields `'clear'` → REJECT** (teaches tile-piling).
  3. **Minimality rewarded:** the minimal-sufficient turn is `'clear'` AND ≥1 over-specified turn is penalized → "pile everything" provably not dominant.
  4. **Adversarial RANDOM-TILE-PILER must FAIL** (replaces the vacuous 1-of-N guesser): random-order +1-per-turn-until-non-ambiguous must NOT reliably reach `'clear'` within the repair cap (overshoots `'overwhelmed'` or misses the right attributes); win-rate above a low threshold → REJECT. Plus **LAZY-VAGUE must FAIL** + **pick-politest must FAIL** (the polite option is never the clear one).
  5. **Listener-derived-not-stored:** no `correctAnswer`/answer-index; outcome only from `resolve`.
  6. **Politeness-null:** removing ANY politeness tile leaves `resolve` unchanged (manners axis INERT).
  7. **Polite-vague decoy MUST exist** (≥1 polite+grammatical+under-informative resolving ambiguous/wrong; no decoy rude/ill-formed); **politeness non-discriminating** (only-clear ≠ only-polite else REJECT).
  8. **≥2 genuine candidates** (referential rounds share the head noun) + **joint-necessity** (multi-attribute: neither attribute alone → singleton).
  9. **Clarity the discriminator ≥85%**; **no length/position tell** (clear option NOT reliably longest — over-spec penalized — and NOT in a fixed slot).
  10. **"Tell Shadow" structural-coherence gate (fix #2):** the object slot must be filled before attributes attach (no attribute-without-noun turn is sayable).
  11. **Self-repair reachable + child-attributed (fix #3):** the prompt names the missing slot CATEGORY (not content); accept = the previously-missing slot now filled; the floor scaffolds to the correct disambiguator as the only remaining tap; "resolve kindly" never marks `'clear'` without the child supplying the missing info.
  12. **≥7 distinct by (listener-action × skill-facet × content-context)** (fix #5) — REJECT "same listener-action + same skill-facet + only tray-config differs"; the draw-it spine present; ≥~6 listener-actions across the set.
  13. **Conversation ≥2 exchanges** in sustain rounds (turn 2's resolve depends on turn 1's world-state).
  14. **Asset/image hygiene** (referential nouns → color images §5) + `utter()` template present for every round (no chip-concatenation path).
  - Plus standing gates: `audit-game-mobile.js` (every listener-action, compose + resolve phases, incl. draw-it worst case), `audit-game-variety.js`, `audit-no-competition.js` (lcs-shell 0-line; no clarity-meter), SEO/JSON-LD §21.
  - **Playtest observable added to the §20.4 eyeball gate (fix #7/#8c — the static gate can't read communicative INTENT; the design carries it, the eyeball confirms it):** the operator confirms a live round where **Shadow asks "which color?" and the child supplies ONLY the color** — the observable distinguishing message-design intent from blind tile-piling.
