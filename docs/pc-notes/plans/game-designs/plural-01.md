## §1 — Concept / world
**The Doubling Pond.** A Mirror-Moon pond — an HONEST mirror that gives back the TRUE plural, never the lazy +s. One foot leans over → the reflection rises as FEET (not foots). The binding metaphor: *more-than-one means the TRUE changed name, not a sprinkled s* (+s is the visible-but-wrong "lazy" option). The child PRODUCES the plural by ASSEMBLING it from the word's letters (the constrained-build, per the rework) — the +s tile always offerable as the reject-distractor. NO-CHANGE creatures (fish/sheep) rise IDENTICAL ("already many"). Non-numeric abundance vessel: the moonlit bank populates with the creatures brought across (never a count). `ctx.correct()` auto-advances.

## §2 — The standard + the load-bearing cognition
**L.2.1.b (Grade 2, SOLE primary), IRREGULAR plurals ONLY** — form & use frequently occurring irregular plural nouns. **Cognitions (pedagogy):** (1) PRODUCE the irregular form, RESISTING the over-learned +s [primary — the Grade-2 cognition is INHIBITING +s]; (2) DISCRIMINATE regular-vs-irregular; (3) NO-CHANGE judgment (fish→fish). **RECALL is the legitimate skill** (irregulars are LEXICALLY stored — don't fake a generative rule; "knows the form AND knows it's NOT +s"); families (oo→ee, -ren) are memory aids, lone-wolves (mouse→mice, person→people) are wholes. **Canonical set (~10-13):** vowel-change (foot→feet, tooth→teeth, goose→geese [oo→ee]; man→men, woman→women [a→e]; mouse→mice), suffix (child→children [+ren]; ox→oxen bonus), no-change (fish, sheep, +deer); person→people DEFER from production (recognition-only — no letter-transform). **FENCES:** the regular +s plural (transform-machine-07, L.K.1.c — never a PRODUCTION target here; regulars appear ONLY as discrimination foils), possessives (L.2.2.c — no apostrophes), verb-agreement (L.1.1.c), counting (math). Letters/words = real DOM/SVG `<text>`.

## §3 — THE ARCHITECTURE REWORK (the heart; the deepest flaw + fix — a WITHIN-FAMILY re-center menu→build)
**The critic's catch — the transform-the-stem MENU-SELECT looked like production but has THREE stacked guess-floors the single-commit / no-pre-commit-oracle guard does NOT touch (those kill CROSS-round trial-and-error, not WITHIN-item guessing):**
- **(A) MENU GUESS-FLOOR (~1/2-2/3, not 1/3).** A pick-from-2-3 menu hands a non-knower: (i) **+s is SCHEMA-ELIMINABLE for free** — the game TEACHES "+s is punished" in ~3 rounds → drop it → 1/2; (ii) **AUDITORY RECOGNITION shortcut** — high-frequency irregulars are HEARD ("feet") → `ee`-sound vs `ea`-sound disambiguates WITHOUT producing the form (recognition riding on auditory familiarity). The Game-77 exception does NOT transfer — its select-space ITSELF encoded the skill (a constrained build from the word's own letters; NO eliminable distractor, NO auditory shortcut). A `MENU_GUESS_SOLVER` (eliminate +s, guess the rest) passes ~50-65% + the gate didn't model it.
- **(B) PRE-HIGHLIGHT (the biggest leak — structural).** Pre-segmenting the word + highlighting the changeable tile HANDS: that it changes (vs +s), WHERE it changes. The child only picks the vowel-transform (the §A guess). A `CUE_CLASSIFY_SOLVER` (pre-highlighted-internal-tile → vowel-change-class) routes every round without knowing a word.
- **(c) NO_CHANGE_DISCRIMINATING≥N gives FALSE COMFORT** — it catches ALWAYS_TRANSFORM but NOT the cue-classifier (a non-knower rejects +s + uses the pre-highlight cue [no salient mutable tile → leave-it] to pass no-change WITHOUT knowing fish→fish).
- **(d) the 70/30 DISCRIMINATION MIX hands a 70% floor** to an always-+s guesser (the base rate rewards the wrong instinct). **(e) unconstrained BUILD-FROM-TILES is a SPELLING test** (children = spell c-h-i-l-d-r-e-n; a child who KNOWS the form but misspells fails → orthography graded as morphology, construct contamination).

**THE FIX — RE-CENTER the GRADED surface onto CONSTRAINED BUILD-FROM-TILES (the genuine production, à la Game-77's actual mechanic); the discrete-symbolic-production exception HOLDS on the build surface, NOT the menu (MID-SIZE; menu = scaffold):**
- **GRADED CORE — CONSTRAINED BUILD.** The child ASSEMBLES the plural from a CONSTRAINED tile set = the singular's letters + EXACTLY the target-transform letters + a `+s` reject-distractor tile (NOT a full alphabet → bounds spelling to the morphological CHANGE, not spell-cold). Correct = the produced ordered string === `derivePlural`. The mutable region is **NOT pre-located** (the word is presented whole; the child LOCATES where to change = part of knowing the form). For **no-change**: offer the singular's letters + a `+s` tile; correct = assemble UNCHANGED, don't use the s (a production reject-of-+s, not a 1-of-N button). The `+s` tile is ALWAYS offerable (the reject-+s cognition).
- **MENU-SELECT = scaffold** (an easier first-attempt/hint; does NOT feed the grade — the Game-78-style partial demote).
- **PRE-HIGHLIGHT REMOVED** on the graded surface; **TREE-TYPE / class-cue rendered POST-COMMIT only** (feedback/celebration, never a pre-commit rule-class oracle — the mismatched-harvest round's no-cue property becomes universal).
- **DISCRIMINATION MIX BALANCED for grading** (no 70%-regular-bias floor); the unreliable-animal-cue (mouse/goose change → "animal→leave-it" fails) retained for no-change.

## Cohort doctrine this game adds
**The MENU-SELECT-GUESS-FLOOR / CONSTRAINED-BUILD lesson — PROGRAM-WIDE (it SHARPENS the Game-77 discrete-symbolic-production exception).** A discrete-symbolic-production game's GRADED surface must be a genuine PRODUCTION (the child ASSEMBLES + commits a full ordered output), **NOT a MENU-SELECT (pick-from-2-3)** — because every menu introduces guess-floors the single-commit / no-pre-commit-oracle guard does NOT touch (those kill CROSS-round trial-and-error, never WITHIN-item guessing): (1) a **within-item GUESS-FLOOR** (1-of-K baseline); (2) a **SCHEMA-ELIMINABLE distractor** (if the game teaches "X is always wrong" — like +s — the child eliminates it for free, halving the menu); (3) for high-frequency LEXICAL items, an **AUDITORY/RECOGNITION shortcut** (the child recognizes the right option by familiarity WITHOUT producing the form). **The Game-77 exception (a small select clears WITHOUT a re-center) holds ONLY when the select-space ITSELF encodes the skill with NO eliminable distractor and NO recognition shortcut — i.e. a CONSTRAINED BUILD from the item's own elements (Game-77's letter-drop), NOT a menu of pre-formed options.** COMPANION leaks (all must be barred from the graded surface): **PRE-HIGHLIGHT / pre-segmentation** hands half the production (THAT it changes + WHERE) — the child must LOCATE the change (part of knowing the form); any **pre-commit CLASS-CUE** (a metaphor/tree-type/category that signals the rule-class) is a free oracle → render it POST-COMMIT; a **DISCRIMINATION base-rate** (e.g. 70/30 regular/irregular) hands an N% floor to a constant-guesser → BALANCE the graded mix (a `REGULAR_BIAS_SOLVER` must fail at chance); and **build-from-tiles must use a CONSTRAINED tile set** (the item's letters + exactly the target-transform letters + the reject-distractor) — NOT a full alphabet, else it's a SPELLING test that over-shoots a MORPHOLOGY standard (a knower who misspells fails = construct contamination). **THE FIX: grade on constrained-BUILD; locate-the-change is part of the cognition (no pre-highlight); class-cues post-commit; bound the tile-set to the morphology; balance discrimination base-rates; add `MENU_GUESS` / `CUE_CLASSIFY` / `REGULAR_BIAS` solvers + a selection-vs-production assertion that the graded answer is unreachable by any K-way pick.** Generalizes to EVERY produce-the-form game (irregular plurals, contractions, verb-tense, spelling-patterns, build-the-word): the genuine production is a constrained-build the child generates, not a menu they recognize-from.
