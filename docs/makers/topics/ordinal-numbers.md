## Settings a teacher sets

- places to 5 / 10
- start end (flag left/right)
- numerals or words
- (plus the settings every maker has: language (one of our 11); template (gallery by sub-topic); level 1-3; picture theme / own pictures where pictures appear; number of problems / page fill; title + instruction text (editable); answer key on/off; pages: add / duplicate / delete; regenerate (new seed, same settings); paper: Letter for en-US, A4 elsewhere (switchable))

## Templates from today's worksheet types

**Ordinal numbers: find / name the 1st–10th in a line, counting from the marked end (either end)**

- `K-320` Ordinal Numbers: Find the Place — Start at the flag. Count to the number of each chip and make the mark it shows. · screen version · picture themes (scripts/worksheet-gen/types/k/K-320-ordinal-numbers.js)
- `K-336` Ordinal Numbers from Either End: Find the Flag — Look for the flag first: it can stand at either end. Start there, count to the number of each chip and make the mark it shows. · screen version · picture themes (scripts/worksheet-gen/types/k/K-336-ordinal-numbers-either-end.js)

**Ordinal numbers: write the missing ordinals, match ordinal words, which place, who wins the race**

- `G1-315` Write the Missing Ordinal Numbers — Some places are already written. Write the missing ordinal numbers in the empty boxes, counting from the flag. · screen version · picture themes (scripts/worksheet-gen/types/g1/G1-315-ordinal-numbers-write.js)
- `G1-316` Ordinal Words: Draw a Line to the Picture — Read each ordinal word and draw a line to the picture standing in that place, counting from the flag. · screen version · picture themes (scripts/worksheet-gen/types/g1/G1-316-ordinal-numbers-words.js)
- `G1-317` Which Place? Write the Ordinal Number — Find each small picture in its line and write which place it stands in, counting from the flag. · screen version · picture themes (scripts/worksheet-gen/types/g1/G1-317-ordinal-numbers-which-place.js)
- `G1-318` Who Wins the Race? Write the Place — Look how close each runner is to the finish line. The nearest is 1st. Write 1st, 2nd, 3rd, 4th, 5th and 6th. · screen version · picture themes (scripts/worksheet-gen/types/g1/G1-318-ordinal-numbers-race.js)
