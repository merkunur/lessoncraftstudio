## Templates from today's worksheet types

**Clap and split words into syllables, missing syllable, syllable scramble, 2 or 3 syllables, syllable cards**

- `G1-305` Syllable Division — Say each picture word and clap its parts. Draw one scoop under every syllable you hear. · screen version · picture themes (scripts/worksheet-gen/types/g1/G1-305-syllable-split.js)
- `G1-325` Write the Word in Syllables — Read the word beside each picture. Copy it on the line and write a small dash between its syllables. · screen version · picture themes (scripts/worksheet-gen/types/g1/G1-325-syllable-split-write-the-word-in-syllables.js)
- `G1-326` Missing Syllable — Say the picture word. One syllable is missing. Write the missing syllable in the box. · screen version · picture themes (scripts/worksheet-gen/types/g1/G1-326-syllable-split-missing-syllable.js)
- `G1-327` Syllable Scramble — The syllables of each picture word are mixed up. Read them, put them in order, and write the word on the line. · screen version · picture themes (scripts/worksheet-gen/types/g1/G1-327-syllable-split-syllable-scramble.js)
- `G1-328` Two or Three Syllables? Split and Sort — Clap each word in the bank. Write it with a dash between its syllables in the 2 column or the 3 column. · screen version · picture themes (scripts/worksheet-gen/types/g1/G1-328-syllable-split-two-or-three-syllables.js)

**Read word-family / syllable words (carpet), join syllables, words with blends, read syllabified words and find the picture**

- `G1-306` Word Families: Read and Write — Read every word on the carpet out loud. Say each picture word, find it on the carpet, then write its beginning on the line before the ending. · screen version (scripts/worksheet-gen/types/g1/G1-306-syllable-reading.js)
- `G1-330` Word Families: Read and Circle — Read the words on the carpet out loud. Say each picture word, then circle the one word under the picture that names it. · screen version (scripts/worksheet-gen/types/g1/G1-330-syllable-reading-read-and-circle.js)
- `G1-331` Join the Syllables and Write the Word — Read the two syllables on each card in order. Say them together, then write the whole word on the line. · screen version (scripts/worksheet-gen/types/g1/G1-331-syllable-reading-join-the-syllables.js)
- `G1-332` Word Family Carpet: Read and Color — Read every word on the carpet out loud. Then find each picture's word on the carpet and color that word in the picture's color. · screen version (scripts/worksheet-gen/types/g1/G1-332-syllable-reading-carpet-read-and-colour.js)
- `G1-333` Word Families with Blends — Read every word on the carpet out loud. Say each picture word, find it on the carpet, then write the two letters it starts with on the line. · screen version (scripts/worksheet-gen/types/g1/G1-333-syllable-reading-with-blends.js)
- `G1-334` Read the Syllables, Find the Picture — Read each word syllable by syllable. Find its picture in the bank at the top and write the picture's number in the box. · screen version (scripts/worksheet-gen/types/g1/G1-334-syllable-reading-read-the-syllabified-words.js)

**Every syllable has a vowel (find the vowel in each syllable)**

- `G1-329` Vowel King — Every syllable has one vowel. Look at the example, then put a dot on the vowel inside each syllable arc. · screen version · picture themes (scripts/worksheet-gen/types/g1/G1-329-syllable-split-vowel-king.js)
