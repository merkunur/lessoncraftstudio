## The skill
Form cursive lowercase letters, capitals, the joins between letters and whole words; read words written in cursive.

## The apparatus and its invention
A RIBBON of ink follows the finger along a ghost path of the letter in the locale's school script. The ribbon never lifts between joined letters: a join stroke connects the end of one letter to the start of the next, and the ribbon only advances when the finger stays inside the path (it frays and stops if the child cuts a corner). Dots on i/j and crosses on t are added last, after the word — they appear as separate small targets that light only when the joined word is complete. Read mode: a cursive word on the ribbon and three library pictures; the child taps the picture.

- **Misconception the apparatus makes visible:** Lifting the pen between letters, forming letters separately and joining afterwards, dotting/crossing mid-word.
- **Pictures:** library nouns for words and the read mode (animals, fruits, toys)
- **Settings:** Level: letters / joins / words / capitals with names · Mode: write (trace) / read cursive
- **Rounds:** ≥ 8 items per level from the locale script; read mode answer position balanced across 3 pictures.
- **Worksheet types it covers:** G2-377, G2-384, G2-385, G2-386, G2-387, G3-401
- **Distinct from:** Penny's Alphabet Trace and Snippy's Letter Trace are print letters. The ribbon is about joining, which print tracing never asks.
- **Build risk:** HIGH: per-locale school cursive fonts (Playwrite vendored for 9 locales; sv/fi have no joined school script — refusal as in the worksheets); tracing must follow the font's centre-line path (the letter-tracing centerline precedent). No free handwriting recognition.

## Merged into this instrument (cover each as a setting or round set)
- grade 3 "The Joined Line" (joined-trace): Trace joined (cursive) letters and a short sentence, keeping the pen on the line through each join. — THE JOINED LINE: a sentence in a vendored school cursive font on writing lines; a pen tip waits at the first entry stroke. The child drags along the grey guide; ink follows only while the finger stays within the guide's corridor, and each join between letters is a marked bridge — lifting the finger before a bridge leaves a gap that blinks. When the sentence is done, the inked sentence slides up and a second copy line shows the same sentence as dots only (fading guide) for a second trace.
