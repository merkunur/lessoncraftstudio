## The skill
Read and make a pictograph whose key says each picture stands for 2 (half a picture for 1).

## The apparatus and its invention
THE DOUBLE STAMP. A graph board with 3–4 rows, each labelled by a library picture, and a key card: one picture = 2. Make mode: a small table gives each row's count; the child presses a rubber stamp along a row, and each press prints one picture worth 2. An odd count can only be reached with the HALF-STAMP, which prints half a picture worth 1; a whole picture where a half is needed overshoots and the row's last print flashes. Read mode: a finished graph; the child taps a row and types its real count. Bars setting (absorbed Value Bricks): the board becomes a bar graph whose bricks are stamped with the scale (2, 5 or 10) and the axis counts by the scale — 35 needs seven 5-bricks; a half-brick exists only where the scale needs it. Miss 1: the prints in the row count up by the key under each print (2, 4, 6 …); miss 2: each print splits into its units. Right: the row's total appears at its end and the key card glows.

- **Misconception the apparatus makes visible:** Counting the pictures as ones (a row of 4 pictures read as 4, not 8), and not knowing what a half picture means.
- **Pictures:** fruits / animals / toys / sports (row labels + stamp face)
- **Settings:** Mode: make the graph / read the graph · Graph: pictograph (picture = 2, or = 5) / bar graph of value bricks (brick = 2, 5 or 10)
- **Rounds:** ≥ 8 rounds: fresh counts 2–16 per row with ≥ 1 odd count per round in make mode; the row asked is chosen at random; no two rows equal.
- **Worksheet types it covers:** G2-238, G3-332, G3-333, G3-334
- **Distinct from:** Pip's Stacking Fence (graph-it) builds bars at one unit per block; the stamp is a SCALED unit, which no activity teaches.
- **Build risk:** Low.

## Merged into this instrument (cover each as a setting or round set)
- grade 3 "The Value Bricks" (value-bricks): Read and build scaled bar graphs and pictographs where one brick or picture stands for 2, 5 or 10. — THE VALUE BRICKS: a data table on the left; on the right a graph whose bricks each carry a stamped scale value (5). The child drags bricks onto each column until it reaches the table value — 35 needs 7 bricks, and the axis numbers count by 5 beside them. A half-brick (worth 2 or 5 of 10) is available only on the scale settings that need it. In read mode the bars are built and the child types each value; a pictograph setting swaps bricks for library pictures with a key 'one picture = 5'. Miss: the bricks in the column count up by the scale aloud and on screen.
