# Maker: Counting (`counting`)

Group **math** · language need **little** · 14 existing templates + 3 new · replaces old app(s): `find-and-count`, `find-objects`

## Settings a teacher sets

- number range (1-5, 1-10, 1-20)
- answer mode: circle / write / match
- how many cards
- kinds of pictures in a scene
- (plus the settings every maker has: language (one of our 11); template (gallery by sub-topic); level 1-3; picture theme / own pictures where pictures appear; number of problems / page fill; title + instruction text (editable); answer key on/off; pages: add / duplicate / delete; regenerate (new seed, same settings); paper: Letter for en-US, A4 elsewhere (switchable))

## Templates from today's worksheet types

**Count a set (scattered, framed, in an array) and name / write / match the number, to 10–20**

- `K-002` Count and Circle — Count the pictures in each box. Circle the right number. · picture themes (scripts/worksheet-gen/types/k/K-002-count-and-circle.js)
- `K-006` Count and Write — Count the pictures in each box. Write the number. · picture themes (scripts/worksheet-gen/types/k/K-006-count-scattered-write.js)
- `K-007` Count and Match — Count the pictures. Draw a line to the right number. · picture themes (scripts/worksheet-gen/types/k/K-007-count-and-match.js)

**Make a set of a given number (fill the frame, colour exactly N)**

- `K-011` Count and Color — Color exactly as many pictures as the number shows. · picture themes (scripts/worksheet-gen/types/k/K-011-count-and-color.js)

**One-to-one correspondence: give each one a partner**

- `K-012` One for Each — Give each one a partner. Draw a line to connect them one by one. · picture themes (scripts/worksheet-gen/types/k/K-012-one-to-one-match.js)

**Count each kind in a mixed scene (classify, then count)**

- `K-013` Count Each Kind — Count each kind of picture. Write how many you find. · picture themes (scripts/worksheet-gen/types/k/K-013-count-by-category.js)
- `K-060` I Spy… — Look closely! Count each kind and write the number. · picture themes (scripts/worksheet-gen/types/k/K-060-i-spy-count.js)

**Odd or even by pairing up: one left over means odd**

- `K-016` Odd or Even? — Pair them up! If one is left over, the number is odd. · picture themes (scripts/worksheet-gen/types/k/K-016-odd-or-even-pairs.js)

**How many altogether: put two groups together and count all**

- `K-028` How Many Altogether? — Count both groups together. Write how many in all. · picture themes (scripts/worksheet-gen/types/k/K-028-how-many-altogether.js)

**Estimate a quantity, then check by counting**

- `K-029` Take a Good Guess! — Do not count! Circle the better guess, then check by counting. · picture themes (scripts/worksheet-gen/types/k/K-029-estimate-then-count.js)

**Ordinal numbers: find / name the 1st–10th in a line, counting from the marked end (either end)**

- `K-030` First, Second, Third… — Start at the arrow. Circle the picture at the position shown. · picture themes (scripts/worksheet-gen/types/k/K-030-ordinal-circle-nth.js)
- `K-031` What Position? — Start at the arrow. Write each marked picture’s position in its circle. · picture themes (scripts/worksheet-gen/types/k/K-031-ordinal-write.js)

**Search a busy scene for every one like the target (pictures, shapes; the shape of everyday objects)**

- `K-059` Find and Circle — Find every picture like the one in the box. Circle them all. · picture themes (scripts/worksheet-gen/types/k/K-059-find-and-circle.js)
- `K-070` Shape Hunt — Find every shape like the one in the box. Circle them all. (scripts/worksheet-gen/types/k/K-070-find-the-shapes.js)
