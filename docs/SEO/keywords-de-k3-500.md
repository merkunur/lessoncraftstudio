# German K-3 worksheet keyword inventory — 500 base keywords (2026-07-12)

**Purpose:** the base-keyword inventory German K-3 teachers actually search for worksheets with, for a LATER long-tail-formation + page-application step (NOT yet applied anywhere; §21.5a churn freeze holds). Machine-readable twin: `keywords-de-k3-500.json`.

**Method:** 10 parallel native-German keyword web-research agents (one per demand segment), each doing live web research (SERP titles, competitor category trees: grundschulkoenig.de, materialguru.de, grundschule-arbeitsblaetter.de, kribbelbunt.de, raetseldino.de, eduki.com, 4teachers.de, wegerer.at, betzold.de …). 790 unique raw candidates → force-dropped non-worksheet intent (craft/classroom-management/therapy-shopping) → scored (autocomplete-confirmed > topic/level > format) → exactly 500. **143 (28.6%) are confirmed in the 2026-07-06 google.de autocomplete harvest** (`harvests/de.json`, 2,367 uniques) — the unconfirmed rest is deliberate coverage-expansion beyond that harvest's deck-type-seeded scope (Sachunterricht, seasonal, teacher-register, DaZ).

**Complements (do not duplicate):** `demand-map-de.md` (Fach×Klasse structure + P0/P1 gaps) · `demand-terms-de.json` (97 distilled single-axis titles).
