## The per-story recipe (proven on #1)
1. Claim a registry row (premise/setting/storyId, status in_progress) + design per playbook (arc, guide+companion, ladder).
2. `blueprint.json` → `gate-story.js --blueprint` clean.
3. Art: character rigs (reuse roster; new companions via style-lib) + `art/<id>-art.js` → run → **Read the rendered frames/scenes/props and iterate** (the arm-angle/claw-geometry class of defect only shows visually).
4. `blueprint-to-skeleton.js <id>` → hand-finish story.json: **cast poses/atlasClips/clips.fallbackPose (skeleton emits neutral-only + duplicate relative-path assets — fix both)**, `alignment.grade`, zones. strings.json → 11-locale slots (en filled, 10 × ""). Write library-meta.json + `audio/en/README.txt`.
5. Gauntlet: `validate-story` (audio WARNs expected) → `gate-story --grade <G> --blueprint` → `gate-library` → `qa-storybook --story=<id>` → **personally Read screenshots desktop-first** → fix → re-run to 0.
6. Bookkeeping: registry row shipped; curriculum-ledger shippedIndex.entries (shape `{storyId,pointId,library}`) + point shipped++.
7. Commit + push (story binaries ARE git-tracked — pips-picnic precedent). NO deploy, NO SEO row (preview-only program).

## Hard-won on story #1 (don't re-derive)
- **PK number-ceiling ≤5 HARD** scans every taskData integer AND numeral strings. `sb-count-tap` = total 3..10, target 2..total-1 → "exactly 1" via sb-find-object single-sought-target (+decoys, ≥2 targets), "exactly 5" via choice-board count-group/numeral (values ≤5) or connect-dots (points are x/y = exempt).
- **sb-dot-stamp PK cap: ≤4 dots** (band fatal maxTaps), centres ≥180du apart.
- **choice-board subject needs `type`**: `{type:'group', image, count, alt:'@key'}` renders a counted group; without `type` it silently doesn't render (the p07 invisible-subject defect).
- **Narration must match what the child SEES** (cards, not "pails") — playbook prompt patterns.
- **Numeral-option pages at 360px**: subject + 3 tiles → 31px taps (WARN); use 2 options.
- **Count-tap zones**: scatter fills the zone — place the zone over believable ground (waterline/sand), not sky.
- Golden-hour/overlay scenes trip the gate-library pixel-sample WARN (~12% vs 5% budget) — deliberate per the style standard's time-of-day rule; judged fine, leave the threshold alone.
- Preview: `node scripts/storybook/preview-server.js` (5178) or studio-server (5055); qa/preview serve the repo `mini tools/` root — the frontend/public mirror is NOT read locally.
