- **Persons** carry `{id, path, sex:'f'|'m', age:'baby'|'child'|'adult'|'elder', look:{hair, beard, glasses}}`; ego = `path:''`, `age:'child'`, marked with a coral star + name plate. Tree geometry is DERIVED from paths (generation row = path length relative to ego's parents), never hand-placed.

- **"Baby" is not a kin word.** A baby is a SIBLING; the kin literal is the diminutive sibling form (row `Zy/By`). A page never offers both `brother` and `baby brother` unless the graph holds an older brother AND a baby brother (validator rule 6).
- **Family shapes** (bank, invented, varied by seed): `two-parent`, `one-mother`, `one-father`, `grandparent-home` (ego lives with grandparents, parents not drawn), `extended` (a parent's sibling + cousin), `siblings 0..2`, `baby 0..1`; **`two-mothers` / `two-fathers` are bank shapes behind a per-locale flag `allowShapes`** (open question F.1, operator rules). With two same-sex parents the word `mom`/`dad` has two referents, so the validator simply never ASKS it on that page (the figures are still drawn); single-answer holds by construction. Every page's shape is recorded in `data-lcs-shape` so the gate can report the shape mix per locale (target: no shape > 50 % of a locale's decks).

### D.4 Validator (`tools/validate-b5-draft.js`, family rules)
1. Every path used by any family has a `kin[loc]` entry, and every `kin` value exists in `words`.
2. `kin` is a FUNCTION of the path only (no entry keyed on name or shape).
3. Every family: exactly one ego; every non-ego path resolves in the graph (a `MZ` requires `M`).
4. Word→person uniqueness on every asked item (base, F2 badges): `|{p : kin[p.path]=w}| = 1`.
5. Person→word uniqueness on every chip row / bank (F4): no two bank words valid for one riddle.
6. `brother` and `By` both offered only if the graph has both an older brother and a baby brother (same for sister).
7. F3: name gender tag = box figure sex; names on a page pairwise distinct; no given name in a clue.
8. F4: answers pairwise distinct per page; distractors share a generation with ≥ 1 answer.
9. F1: the three words in a row have pairwise distinct generations; no row in answer order; nl `neef/nicht` absent from `generationOK`.
10. F2: every glyph of every row word in tracing coverage; word fits the lane at glyphH 40 (render-measured).
11. No riddle/clue frame contains an article or possessive that agrees with the answer (panel tags each frame `agreesWithAnswer:false`; the validator also greps the frame for the locale's list of possessive/article tokens immediately before `___`).
12. No frame is first person (locale list: my/mein/meine/mon/ma/mi/meu/minha/mio/mia/mijn/min/mitt/mi/minun/-ni).
13. fi: no field (strings, titles, slugs, meta) contains `sukupuu`; pt: no title is bare `família`; it: no title is bare `La famiglia`; de: no title starts `Meine Familie`; sv: no field contains `släktord`.

15. `strings.<mode>.instruction` of `tree-template` contains none of the locale's M/F literals and no imperative "draw your family" equivalent (panel-supplied ban list).
