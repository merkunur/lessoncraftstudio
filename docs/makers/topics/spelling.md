## Templates from today's worksheet types

**Build / complete CVC words from letters**

- `K-224` Missing Sound — Write the missing letter to finish each word. (scripts/worksheet-gen/types/k/K-224-cvc-missing-letter.js)
- `K-231` Build the Word — Use the letters to build the word for each picture. (scripts/worksheet-gen/types/k/K-231-build-the-word.js)

**Apply a position-dependent spelling rule (e.g. ck/k, tch/ch, -dge/-ge, ai/ay; -s/-es/-ies plurals): fill, spot and sort by the rule letters**

- `G2-315` Spelling Rules: {UNIT} — Read the rule in the box. Say each picture word, then write the missing rule letters in the dashed boxes. · screen version (scripts/worksheet-gen/types/g2/G2-315-spelling-rules.js)
- `G2-324` Which One? {UNIT} — Look at the picture and read the word. Circle the right letters under it, then write them in the dashed box. · screen version (scripts/worksheet-gen/types/g2/G2-324-spelling-rules-which-one.js)
- `G2-325` Rule Detective: {UNIT} — Read each word. Find the rule letters, circle them in the word, then copy them into the small box. · screen version (scripts/worksheet-gen/types/g2/G2-325-spelling-rules-rule-detective.js)
- `G2-326` Sort by Spelling Rule: {UNIT} — Say each picture word. Write it in the bin with its spelling, one word on each line. · screen version (scripts/worksheet-gen/types/g2/G2-326-spelling-rules-sort-by-rule.js)
- `G2-327` Write the Word: {UNIT} — The rule letters are printed in orange. Say the picture word and write all the other letters in the boxes. · screen version (scripts/worksheet-gen/types/g2/G2-327-spelling-rules-write-the-whole-word.js)
- `G2-328` Plurals: {UNIT} — Read the word for one. Write the word for many in the boxes. The plural changes the spelling. · screen version (scripts/worksheet-gen/types/g2/G2-328-spelling-rules-plural-spelling.js)
