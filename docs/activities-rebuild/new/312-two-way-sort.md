## The skill
Classify objects by two attributes at once in a two-circle (Venn) diagram, including the overlap and the outside.

## The apparatus and its invention
THE CROSSROADS HOOPS. Two overlapping hoops on the floor, each with a gate post carrying its rule as a library picture + glyph (left: "is an animal" = a library animal silhouette; right: "is big" = a big/small pair glyph). Pictures wait in a basket. The child drags a picture into a region (left only, right only, both, outside). Both gates test it: each gate nods or shakes. Right: it rests. Miss 1: it slides to the region where both gates agree, passing through the overlap boundary so the child sees which gate changed its mind; Miss 2: the gate that disagrees glows. Success: all pictures placed, both hoops light.

- **Misconception the apparatus makes visible:** Seeing only one attribute (putting a big animal in 'animals' but not in the overlap); thinking the overlap means 'neither'.
- **Pictures:** animals, fruits, vehicles, toys at two sizes (scale transform, as in comparing-length)
- **Settings:** Rules: kind + size / kind + kind (animals + can fly)
- **Rounds:** 9 rounds of 6–8 pictures, every region non-empty, overlap and outside ≥ 1 each round; big/small are scale transforms of one picture; one right region per picture.
- **Worksheet types it covers:** G3-353
- **Distinct from:** All existing sorts (Mim's Baskets, Sort Bins, sort-count) are single-attribute; Ziggy's Odd One Out excludes one item.
- **Build risk:** Distinct from the sorting-hoops TOOL (hidden rule, teacher-led) because the rules here are given and each placement is checked.
