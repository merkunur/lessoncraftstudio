## 5 Quality verdict

Would I print this for my first graders? The base, yes, and I would run the tub test with it the same afternoon: every object on it is something I can put in a basin, nothing pretends a candle or a sponge is simple, and the surprise star is exactly the moment I want to talk about. The heavy-or-light page is the one I would have been embarrassed by in either design's version, because a page where the big thing always floats is a page my strongest reader solves by glancing and my weakest learns a new wrong rule from; with two heavy floaters and two light floaters on a real balance it finally does what its title promises. What would still embarrass me: a pink key my class calls "a toy key" (it only appears on the page we test with a real key), and any label a panel leaves as the dictionary word; one "uña" under a nail and the whole page is a joke, so the label rule is the one I would check first on every locale's render.
