## 1 Page concept (base)

**"The Ring and the Table."** A 636 px ring fills the body. Station N (12 o'clock) is a 136 px white window holding the drawn butterfly EGG on its leaf (with a magnifier detail, see §5). Stations E, S, W are identical windows, each empty but for one dashed-coral letter box (64). Between the stations, four coral arrow arcs ride a 16 px tealSoft track; the arc from W back to N (adult to egg) is the same weight as the others, because the return is just another step of the cycle. In the ring's hub lie three loose stage cards (caterpillar, chrysalis, butterfly), 120 px, each tilted a few degrees, each with a coral letter badge A / B / C. The child reads the cards, follows the arrows round from the egg, and writes each card's letter in the window where that stage comes.

What makes it top quality:
- **One focal apparatus, zero stray elements.** The bank does not sit in a strip below competing with the diagram (the classic printable look); the material lives inside the thing it belongs to. 86 px of body slack stays as whitespace round the ring (d2 at 722).
- **The cycle is the shape of the page.** A closed track has no seam, so "after the butterfly comes the egg" is visible before a word is read. Anchoring the egg at 12 o'clock makes the answer unique (a wheel without an anchor accepts every rotation).
- **Pencil first:** four marks, one letter each, in 64 px boxes a G1 hand can fill.
- **Drawings a biologist signs and a six-year-old recognises:** a real chrysalis (not a cocoon), a clubbed-antenna butterfly, a caterpillar with true legs and prolegs, and scale kept honest by the leaf.
- **Greyscale-proof by construction:** every distinction the task needs is carried by SHAPE (egg on a leaf, striped tube, hanging drop, four wings), never by colour.

## 4 Answer-hiding + uniqueness

- **What prints:** the anchored egg window, three empty windows with empty boxes, three lettered cards. No stage word, no numeral, no stage order anywhere.
- **What the child marks:** one letter per empty window (E, S, W).
- **Uniqueness:** the egg anchors station 1; arrows fix direction; each window expects `STAGES[animal][k]`; each stage occurs on exactly one card. One solution.
- **Hub placement rule (the spatial tell, both directions):** a card never sits in the hub slot NEAREST its own window (triangle: A-slot is near N and W, B-slot near N and E, C-slot near S), and the letter order A, B, C is never the cycle order nor its reverse. Enumerated at d2 there is exactly ONE legal assignment: **A = chrysalis, B = butterfly, C = caterpillar** (answer E = C, S = A, W = B). Fixed, locale-neutral, stamped; the verify re-enumerates and asserts the shipped instance is legal (a tell ships to 11 locales at once). d3 grid: slots NW {N,W}, NE {N,E}, SE {E,S}, SW {S,W}; the engineer enumerates the legal set and picks by seed.
- **Visibly wrong to the teacher:** a wrong letter sits in a window whose neighbour arrows lead from and to the wrong picture; the teacher checks with the key "E C · S A · W B" held in `data-lcs-*`, never printed.
- **Stamps:** window `data-lcs-slot=<k> data-lcs-stage="butterfly.<id>"`; anchored window adds `data-lcs-anchor`; card `data-lcs-card=<A..> data-lcs-stage`; drawing root `data-lcs-figure="life-<animal>-<stage>"`; arcs `data-lcs-arrow="step"` x3 + `"return"` x1.
