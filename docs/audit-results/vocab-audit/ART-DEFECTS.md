# Art defects — the picture does not show what the key names

**Operator ruling, 2026-07-17:** *"when you think the image and the file name don't match, take the
file name as reference."*

So the **key is the reference**. The word follows the key; a mismatched picture is an **art bug**,
filed here, and it never holds the word. This closes the 38 keys that were blocked pending a
"fix the word or fix the art" decision — the word was never in question.

Found by opening every image in the 193-key ambiguous set plus the full Swedish wave (~1,263 keys,
12 native batches). **No previous round could see any of this: nobody had ever opened a picture.**
These are cross-locale — one drawing serves all 11 languages, so each defect is one fix, not eleven.

---

## 6. 🔴 Content — these want a decision, not a redraw

- **There is WINE on the `picnic` card.** The audience is ages 3–7.
- **English text is baked into the `police_car` and `post_office` artwork** — in a product whose
  entire premise is 11 languages. It cannot be localised without new art.
- **`indian`** — SAOL's own label: *"⟨ngt åld., kan uppfattas som nedsätt.⟩"* (dated; may be
  perceived as derogatory). Flagged independently by the German arc, the v1 Swedish round, and
  Swedish v2. Read aloud to 3–7-year-olds.
- **`mercury` and `neptune` share ONE generic banded gas-giant image** — two planets, one picture.

## 7. Filename traps (engineering, not art)

A blanket `key.replace('-','_')` **falsely reports these as art-less** — and `dogwood-tree` is
exactly where a real correction was hiding:

- the **`tree` theme drops the `_tree` suffix**: `tree/spruce`, `tree/juniper`, `tree/dogwood`, `tree/cedar`, `tree/hemlock`, `tree/lemon`
- `fruits/dragonfruit` — one word, no separator
- `tools bw/double-ended_wrench` — hyphen **kept**
- `travel and holiday bw/double-decker`
- `shoes` resolves only via `shoes_2`; also `high-heeled_shoes`, `flip_flops`

**Consequence: the "84 keys with no image" figure is inflated.** Re-derive it with a resolver that
tries these forms before calling a key dead.
