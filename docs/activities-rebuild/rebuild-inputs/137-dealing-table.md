## The skill
A number is even when its objects can be shared fairly between two (in pairs) with none left over; odd leaves one.

## The apparatus and its invention
TWO PLATES AND A DEAL LEVER. A pile of identical library objects sits between two library animal friends, each with a plate. Each pull of the lever deals ONE object to the left plate, the next to the right, alternately, and a thread joins each new pair the moment it forms. When the pile is empty, an even pile has every object paired; an odd pile leaves the last object alone on a stool between the plates and the seesaw under the plates dips toward the side with one more. The child then writes what happened: the keypad fills 'n = ▢ + ▢' (two equal addends) and, when one is left, a '+ 1' card must be added — the even/odd verdict IS the equation, not a two-button guess. Pairs way: instead of the lever the child draws a loop round two objects at a time; a loop round one or three springs open. Up to 99 (absorbed Chairlift): the tens arrive as already-dealt locked trays (a ten is always five pairs), and only the ones are dealt — so it is visibly the ones that decide. Miss 1 replays the last two deals slowly; miss 2 shows every pair threaded and counted.

- **Misconception:** Decides odd/even by the size of the number or the last digit learned by rote, not by pairing; thinks an odd number can be shared fairly if you cut one in half.
- **Pictures:** farm animals / pets for the friends; fruits, toys, kitchen tools for the pile
- **Settings:** Up to: 10 / 20 / 99 (tens arrive paired) · Way: deal to two friends / circle in pairs
- **Rounds:** 8+ rounds; odd and even each 40–60 % of a pass, never the same verdict three times running; pile counts distinct within a pass (never 0); the answer is typed, so there is no answer position.
- **Worksheet types it must cover:** G1-351, G1-369, G1-370, G2-218, G2-351, G2-352
- **Build risk:** Needs one honest decision control without becoming a two-button quiz: the deal must be done before the verdict unlocks.
