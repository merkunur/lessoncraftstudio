## 2. Concept & creative hook
**A warm woodland vet clinic.** A shy, poorly animal shuffles in, paw on tummy. Its symptom is a quantity STORY — but the story is first **ACTED OUT** in the x-ray window (the critic's D, the premium-defining toy), then read aloud.
- **THE ENACTMENT (non-text situation model — reading-accessibility + the toy):** the x-ray window plays a ~1.5s SVG mini-scene of the SITUATION ACTION — for add-to, friends visibly JOIN; for take-from, some visibly LEAVE; for compare, two animals stand side-by-side. **CRUCIAL: the UNKNOWN quantity is HIDDEN/fogged in the enactment too** (start-unknown → the start is behind a fog; result-unknown → the result is behind the tummy x-ray) → the child CANNOT count the answer off the scene (no perceptual-count cheat); the enactment gives the STRUCTURE (what's known, what's unknown, the action), not the number. Then `ctx.speak()` reads the story. A Grade-1 early-reader gets a non-linguistic situation model — the math, not the reading, is the test.
- **THE MODEL-FIRST X-RAY (the unanimous spine + the critic's A/B/C fixes):** the x-ray panel is a SITUATION-MODEL diagram with ICONIC/UNLABELED role-slots (NO "START/WHOLE/BIGGER" words — the critic's B). The child binds the known quantity tiles (incl. a magnitude-DECOY tile to REJECT — the critic's C) into their role-slots + marks the unknown slot. **The FULL binding is graded** (which known is change vs result — reject role-wrong-but-magnitude-correct). Only when the structure is bound does the dial appear; **the number is DERIVED from the model** (no `answer` field). The frosted x-ray clears → the patient heals.
- **THE 3 DISTINCT DIAGRAM METAPHORS (the critic's F — distinct TO THE CHILD, NOT one widget):** add-to/take-from = a **time/change-STRIP** (start → [+/− change] → result, with the change ANIMATING left-to-right); put-together/take-apart = an **enclosing BRACKET** (a whole that physically contains two parts); compare = **two stacked length-BARS** (a literal side-by-side length comparison + a difference bracket). Different visual metaphor + different drag affordance + different "aha."
- **MAGNITUDE CAN'T CHEAT IT (the critic's A — the headline):** the deck is MAGNITUDE-BALANCED (biggest-known → container correlates ≈ 0 with the correct binding) — over-weight the magnitude-breaking cells (compare-bigger/smaller, take-from-change, where the known difference/change > the smaller quantity) + the magnitude-decoy tile (larger than the true container but subordinate → must be REJECTED by reading). A bind-by-magnitude solver scores ≤ chance.
- **THE PAYOFF (earned by the model):** correct full-binding + derived number → the frosted x-ray CLEARS (a magic-eye focus reveal), the patient gets a tiny heart-bandage, **un-curls + meets the child's eyes** + nuzzles + presses a gratitude sticker on the wall. `ctx.correct()`. Wrong → the x-ray stays gently cloudy (NO red), the narrator re-reads / re-enacts, the tiles reshuffle (anti-brute-force), re-diagnose freely.
- **Anti-generic statement:** NOT a word-problem worksheet with a vet sticker — (a) the ENACTMENT makes the situation a non-text toy (no free part-part-whole PDF does this); (b) the model-first binding makes situation-modeling the ASSESSED act; (c) the magnitude-balanced deck + iconic slots + full-binding defeat the bind-by-magnitude + slot-label pincer the model-first fix walked into; (d) the gate proves a keyword-match + number-grab + brute-force + MAGNITUDE-heuristic + LABEL-match solver all lose while a situation-modeler oracle wins.
