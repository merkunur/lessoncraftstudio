## Classes and results

Teachers with a Teacher plan can make a class on LessonCraftStudio, give its children worksheets to do on a screen, and see how each child did. This section explains what that feature stores. If you use the site without a class link, this section does not apply; the rest of this policy describes what the site does for every visitor.

### Who is responsible

The school decides whether this feature is used and for which children. Where a teacher works in a school, the school (or the authority that runs it) is the "controller" of the class data, and the teacher uses the feature on its behalf. A private tutor or a home-educating parent is the controller herself. We run the feature for them and follow their instructions; in data-protection terms we are their "processor", under the [data processing terms for classes](/class-terms), which apply to every class and which a school can have countersigned. For two things we are responsible ourselves: delivering the pages safely (which uses the device's internet address for the moment of the request) and the teacher's own account.

### What we store about a child

- **No name.** A class works with numbers: each child has a seat number and a picture of an animal. The teacher keeps the list of who has which number; we never receive it.
- **Results**: for each worksheet a child does through the class link: which worksheet it was, when it was opened, how many answers were right when the child first pressed Check and when that was, how many answers there were, which ones were right, how many times Check was pressed, and whether the page was finished. For a set with levels we also store which level the page was.
- **The class**: the name the teacher gave it and its language. The class name is shown on the class page, so a teacher should not put a person's name in it.

That is all. We do not ask for or store a surname, a date of birth, an email address, a photo, an address or a location. We do not store what a child typed or drew, only whether an answer was right. No timer runs, and nobody is shown how long a child took.

### How it works for a child

A child opens the class link, taps their own number and picture and does the worksheet. No account, no password, nothing to install. The child sees no score, no ranking and no timer. The class page is shared: a child who taps another seat sees which worksheets that seat has already done (done or not done, never how many were right).

The class page shows the seats of the whole class (numbers and pictures) so that each child can find their own. Anyone who has the class link can open that page, so a teacher should share the link only with the class. The link contains a long random key, and the teacher can replace it at any time, which switches the old link off.

### Who can see results

On the site, only the teacher who made the class can see results, when signed in. We do not show results to other teachers, to other customers or to the public, and there is no page for parents. We ourselves do not look at class data; we can reach the database only to run and repair the service. A parent who wants to see what is stored about their child asks the teacher or the school.

### What we use the data for

Only to show teachers the results of their own classes. We do not use class data for advertising, we do not sell it, we do not share it with anyone except the two companies that host and deliver the site (below), and we do not use it to train any system. We build no profile of a child for any purpose of our own. One thing is automatic and is part of the teaching: in a set with levels, the next page is easier or harder depending on how the last one went, and the teacher's screen sorts each result into "almost all right", "some wrong" or "many wrong". No decision about a child is made by the site.

### Cookies and tracking

On the class page and on every page a child opens from it, nothing is loaded from another company, no analytics runs and no advertising tag is present. The requests these pages send carry no cookie and set none. So that a child comes back to their own list, the browser tab remembers the tapped seat for 20 minutes, on the device only. Like every web server, ours receives the device's internet address with each request; for the class page and the requests behind it we do not write that address into our log. Our general log of requests (internet address, time, page address) is kept for security and deleted after 14 days.

### How long we keep it

- The teacher can delete one child's results, one child, or the whole class at any time. Deletion is immediate in our database.
- A class that has not been used for 14 months is deleted automatically.
- Every single result is deleted at the latest 14 months after it was made, even if the class is still in use. A page a child opened and never checked is removed after 7 days.
- If the teacher's plan ends, their classes are deleted 60 days later. The teacher can still read and delete them during those 60 days.
- Deleted data disappears from our backups within 7 days.

### Where it is

In one database on a server we rent from Hetzner Online GmbH (Germany), located in Finland. Backups that contain class data are kept on that server only. Cloudflare, Inc. (United States) delivers the site: every request, including a result, passes through its network and is not stored by it beyond short technical logs. Cloudflare is certified under the EU-US Data Privacy Framework, and our contract with it contains the EU standard contractual clauses. These two companies are the only ones that handle class data.

### Your rights

Parents and children have the right to see what is stored, to have it corrected or deleted, to have its use restricted and to object to it. Because the school is responsible for the class and only the teacher knows which seat is which child, please ask the teacher or the school first; we help them answer. You can also write to us at support@lessoncraftstudio.com; we pass the request to the teacher without delay. You can complain to the data-protection authority of your country at any time. Accounts on LessonCraftStudio are for adults (18 or older); children never make an account.

If class data is lost or seen by someone who should not see it, we tell the teacher and the school without delay and no later than 48 hours after we learn of it.
