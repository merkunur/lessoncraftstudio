# Maker: Maps & Coordinates (`maps-grids`)

Group **math** · language need **bound** · 10 existing templates + 2 new · replaces old app(s): `treasure-hunt`

## Settings a teacher sets

- grid size
- task: colour by coordinate / write codes / map key / directions / continents
- with or without compass
- (plus the settings every maker has: language (one of our 11); template (gallery by sub-topic); level 1-3; picture theme / own pictures where pictures appear; number of problems / page fill; title + instruction text (editable); answer key on/off; pages: add / duplicate / delete; regenerate (new seed, same settings); paper: Letter for en-US, A4 elsewhere (switchable))

## Templates from today's worksheet types

**Match a side view to the view from above (the first map skill)**

- `K-377` Bird's-Eye View: From the Side and From Above — Each thing is drawn from the side. Draw a line to the same thing seen from above. (scripts/worksheet-gen/types/k/K-377-maps-birds-eye-view.js)

**Read a map key: find each symbol on the map and count them**

- `G1-379` Read the Map Key — Find each thing from the map key on the map, then write how many there are in its box. (scripts/worksheet-gen/types/g1/G1-379-map-skills.js)

**Find a square by its letter-number code (B2) and colour it; write the code of a square**

- `G2-279` Grid Coordinates — Find each square by its letter and number, like B2. Color it with the color of its group to reveal the picture. (scripts/worksheet-gen/types/g2/G2-279-grid-coordinates.js)
- `G2-302` Grid Coordinates on a 6x6 Grid — Find each square by its letter and number. Color it to reveal the picture. (scripts/worksheet-gen/types/g2/G2-302-grid-coordinates-6x6.js)
- `G2-303` Grid Coordinates on a 10x10 Grid — Find each square on the big grid by its letter and number. Color it to reveal the picture. (scripts/worksheet-gen/types/g2/G2-303-grid-coordinates-10x10.js)
- `G2-308` Grid Coordinates: Write the Codes — The picture is colored in. Write the code of each square in the list for its color. (scripts/worksheet-gen/types/g2/G2-308-grid-coordinates-write-the-codes.js)

**The four compass directions and using them on a map**

- `G2-369` North, East, South, West: Label the Four Directions — The orange tip on each compass rose points north; write the three missing letters in the empty boxes. (scripts/worksheet-gen/types/g2/G2-369-maps-north-east-south-west.js)
- `G2-371` Cardinal Directions on a Map — Start at the first picture on the map, look the way the word says, and circle the one of the three pictures that lies that way. (scripts/worksheet-gen/types/g2/G2-371-maps-directions-on-a-map.js)

**Name and locate the continents on a world map**

- `G2-370` Label the Continents — Write the name of each numbered continent on its line. Use the names in the box. (scripts/worksheet-gen/types/g2/G2-370-maps-label-the-continents.js)

**Locate the seven continents and five oceans on a world map**

- `G3-396` Continents and Oceans — Find each continent and ocean on the map. Write its number in the box next to its name. (scripts/worksheet-gen/types/g3/G3-396-maps-continents-and-oceans.js)
