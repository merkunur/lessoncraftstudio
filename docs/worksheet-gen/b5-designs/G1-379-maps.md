## 2 The base page

**Concept. "The island on the wall" (B's invented island inside A's printed map sheet).** The upper part of the page is ONE framed map sheet: a wordless island in a tealSoft sea, drawn strictly from above (a road coast to coast, a river from a spring to the sea with its bridge, 0 or 1 dashed footpath, 11 to 16 plan symbols), a north arrow with the locale's N letter in the top-right sea, and the map KEY docked INSIDE the same frame as a band under the island, exactly where a printed map puts its legend. Below the sheet a strip of five word cards, each a key WORD over an empty numeral box. The child reads a word, finds it in the key, sees its symbol, hunts the symbol on the island, counts, writes. The key is the only bridge (cards never print the symbol), so the page cannot be done without reading the key; the tree / bush near-miss forces the key to be read, not guessed.
