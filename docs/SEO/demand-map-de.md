# German (de) demand map — Phase 1a

**Purpose:** map real German K-3 search demand → the page that should own it → gap/priority, so Phase-1b hub strengthening targets what teachers/parents actually search. Method: web-based demand research (§17.5, strategic not volume-precise) + the live `de` published-deck inventory. Date: 2026-07-05.

## Core finding — the structural mismatch

German K-3 search is organized as **Fach × Klasse (subject × grade)** with the modifiers **kostenlos / zum Ausdrucken / PDF**. Every SERP owner is built that way:
- **grundschulkoenig.de**, **materialguru.de**, **grundschule-arbeitsblaetter.de** (`/deutsch/1-klasse/`, `/mathe/1-klasse/`, `/sachunterricht/1-klasse/`), grundschulheld.de, kleineschule.com.de, vorschulkids.de, klassenarbeiten.de.

LessonCraftStudio's hubs are **fine-grained exercise-types** (`/de/topic/addition`, `/subtraktion`, `/mehr-weniger`…) and **bare levels** (`/de/topic/vorschule`, `/1-klasse`…). **There is no "Mathe Klasse 1" / "Deutsch Vorschule" subject×grade hub** — the content is fragmented *below* the granularity Germans search at, and no single strong page aggregates it. This is the #1 German demand-alignment gap.

Secondary: the modifiers **kostenlos / zum Ausdrucken / PDF / mit Lösungen** are exactly what LCS offers (free, printable, answer key) but are under-used in titles/meta. And **DaZ (Deutsch als Zweitsprache) / mehrsprachig** is real demand that maps directly to the 11-language moat.

## Recommended Phase-1b execution for `de` (≈20-30 pages)

1. **Build the missing subject×grade hubs (P0)** — the biggest lever: `Mathe`/`Deutsch`/`Logik & Wahrnehmung`/`Sachunterricht` × `Vorschule`/`Klasse 1`/`Klasse 2`. These match how Germans search AND how every competitor is structured, and aggregate existing decks into a page with real breadth. (Requires a new subject-hub route/page type — the one genuinely new build; the rest is strengthening.)
2. **Strengthen the level hubs (P1)** `/de/topic/{vorschule,1-klasse,2-klasse}` with demand titles (+ kostenlos/zum Ausdrucken/PDF), unique intros, and links down to the subject×grade hubs.
3. **Re-title the top exercise-type hubs (P1)** to German-natural search terms (Silben, Anlaute, Buchstaben, Uhrzeit lernen, Einmaleins, Rechnen bis 10/20, größer/kleiner, Suchbild) with per-page unique meta descriptions (kill the template fallback).
4. **Internal linking**: homepage/nav/footer → subject×grade hubs → exercise-type hubs → decks/landings, concentrating PageRank on the money hubs.
5. Defer the DaZ/mehrsprachig moat page + Schwungübungen content gap to P2.

**Measure** (per plan): after shipping, watch GSC impressions/position for clusters #1-#8 before rolling the playbook to the next locale.
