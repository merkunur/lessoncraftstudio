## The skill
Organise objects in up to three categories into a picture graph (one per cell) and read it: which has most, how many more.

## The apparatus and its invention
SHELVES WITH SLOTS. A jumble of identical library objects of 2–3 kinds tumbles onto a table. Beside it a shelf with one row per kind (each row labelled by the library picture of its kind), all rows starting at the same line with equal slots, so a row can never be made longer by spacing. The child drags each object into its row; it snaps into the next free slot (the wrong row refuses and the object slides back). When the table is empty a question card asks: which has most / fewest (the child taps the row), or how many more X than Y — the child taps the OVERHANG (the slots of the longer row beyond the end of the shorter one) and types how many. Table setting: each row's count writes itself into a small table beside the shelf as the row fills. Miss 1: a straight edge slides down from the end of the shorter row; miss 2: the overhanging slots get numerals. Right: the question card turns over to the answer sentence.

- **Misconception the apparatus makes visible:** Judges "most" by how spread out the pictures look; computes "how many more" by naming the bigger count instead of the difference.
- **Pictures:** fruits, vegetables, toys, farm animals, insects and bugs (identical instances per kind)
- **Settings:** Categories: 2 / 3 · Question: most and fewest / how many more.
- **Rounds:** 8+ rounds; counts per row distinct within a round (no ties unless the question is "same"), the answer row index balanced over a pass; objects fall in shuffled order.
- **Worksheet types it covers:** G1-141, G1-142, G1-146
- **Distinct from:** Sort and Count stops at a count; Pip's Stacking Fence builds bars from given numbers. This builds the graph from objects and reads the difference as cells.
- **Build risk:** Library art must give three same-size kinds per round.
