# Retell It to the Next Friend — kid-facing "Wake Up, Pip!" — APPROVED DESIGN SPEC
**id:** narrate-roleplay-14 · **PRIMARY standard:** **RL.K.2 (Kindergarten) — with prompting and support, RETELL familiar stories, INCLUDING KEY DETAILS** (BOTH clauses load-bearing: causal SEQUENCE + KEY DETAILS — who/what/problem-stakes/resolution) · **also_teaches:** SL.K.4 (tell to an audience — honestly carried; the friend IS the audience) · **G1 reach (SEPARATE alignment):** RL.1.2 (central message — ONE sub-act, marked Grade-1, does NOT count toward the K claim) · **family:** narrate-roleplay (head of a reusable "reconstruct-a-narrative / retell" engine family) · **engine:** new `engine-retell-story.js` (descriptor = beat-sequence + a causal-dependency DAG + key/trivial details; NO baked story, NO stored right/wrong; `validateRetell` = a pure function over the DAG; localized narration + retell templates) · **runtime:** SIMPLE · **EN-first proof corpus**
**Status:** approved 2026-06-21 (6-expert ensemble; critic returned NEEDS-REWORK; all 6 fixes baked into the spine). Build deferred.
**Scope note (NAMED, not hidden — Game-8/9 precedent):** instantiates RECONSTRUCT-AND-RETELL with key details, audience-directed; does NOT exercise free-oral narration / own-words paraphrase / prosody (the no-mic boundary); on-page + JSON-LD say "reconstruct-and-retell", never "narrates aloud".
**Distinctness — spine = RECONSTRUCT a heard story from comprehension and TELL it to an audience, with key details.** vs Game 6 "Mending Basket" (reorder caption-strips to REPAIR a torn page on VISIBLE strips, RF.1.4.a); vs narrate-roleplay-04 "Answer the Story Character" (single recall Q&A, RL.K.1, retrieval); vs Game 8 (referential turn) / Game 9 (compound order); vs a generic picture-ordering puzzle (panels GONE at retell — the art is never the answer key).

## Concept & creative hook
**Pip** is a sleepy story-loving creature who naps through every story + wakes devastated ("What HAPPENED? You were awake — tell me!"). The child = **the only one who was awake** — the eyewitness/bard, NOT a quizzed student. The win = **FOLLOWED** not "correct" ("I feel like I was THERE! you told it so I could SEE it!").
- **The film that disappears (no-copy made diegetic):** stage 0 the story plays as a narrated SVG diorama panel-by-panel synced to TTS, then **the film is GONE** (the diorama empties, Pip wakes into a blank stage, the same region becomes the retell-assembly) → rebuild from MEMORY, not a visible model (+ the mobile single-column enforcement).
- **The killer premium idea — Pip visualizes EXACTLY what you tell him — built as a STUB-MIRROR (fix #4, buildable not over-promised):** a thought-bubble over Pip MIRRORS the ladder's stub set — correct beat = stub resolves to its silhouette; missing key detail = a puzzle-gap outline + "?"; wrong detail = a stub with a mismatch tint. Key-detail load-bearing-ness made literally visible (a missing piece in Pip's mental picture) — a DEFINED stub-mirror render, NOT a freeform picture-book scene that would ship as a weak CSS approximation.
- **Diegetic causal confusion (reconciled with the no-feedback-leak fix):** out-of-order genuinely breaks Pip's understanding + he names the CAUSAL CONTRADICTION ("the door was LOCKED — how did Bramble open it with no key?!") — a symptom the child must still LOCATE in their own ladder, NEVER "beat 3 is wrong." Curious + on-the-child's-side, never disappointed.
- **Anti-generic:** NOT a causal-ordering puzzle + a key-detail picker with a sleepy-friend skin — (a) the eyewitness frame inverts "answer the teacher" into "you possess something Pip needs" (SL.K.4 audience-need); (b) key-ness is two-source so WHO/problem/resolution are never droppable; (c) a board ships only if surface-cue AND feedback-hill-climbing solvers both FAIL.

## Core loop & the distinct experiences
**Loop:** (1) **Watch (stage 0):** Pip asleep; the story plays panel-by-panel narrated by TTS; generous penalty-free Replay; "Tell my friend!→". (Replay between placements is PERMITTED scaffolding — the film + the answer-surface are NEVER co-visible, fix #5; ping-pong watch→place = spaced re-encoding, not copying.) (2) **Wake + assemble (stage 1):** the film is gone; Pip wakes; child fills the sub-task surface from scrambled wordless-stub-cued trays. (3) **Tell it! (validate ONLY here — fix #2):** TTS voices the assembled retell top-to-bottom in the child's order; Pip's stub-mirror bubble fills beat-by-beat; **Pip reacts to the WHOLE retell** (NOT live per-swap). Clean → bubble completes, Pip delighted "saw it." Break → **Pip DIFFUSELY confused, naming the KIND of causal break** (effect-before-cause / a missing piece / a face that doesn't fit); the child must **re-read their own ladder to LOCATE it** (the comprehension act) — never the slot index or the fix. (4) **With-prompting-and-support re-teach (fix #4 terminal):** re-read + re-place (no per-swap re-eval; each attempt = a full "Tell it!"); repeated struggle → Pip RE-NARRATES the relevant causal fact ("remember — the door was locked first…"); after N attempts Pip warmly co-constructs THAT ONE PART ("let's put this here — see, the key comes before the door opens?"), modeling the causal reasoning. **Never hands the whole answer; never sticks; never a "you broke it again" counter; no score/timer/fail.**

**Distinct experiences — HONEST re-frame (fix #3): ≥7 = ≥7 perceived-DISTINCT STORIES (different cast/problem/setting/emotional shape), with the SUB-ACTS as the underlying SKILL-COVERAGE spine** (NOT 7 slot-position relabels — the §A.13.60 fraction-partition ruling). All funnel into the SAME `tellIt → validateRetell → diffuse-friend-reaction` path:
| # | Sub-act (skill-coverage) | The act | Why non-guessable |
|---|---|---|---|
| 1 | **order-by-causal-logic** | place 4-5 beats into the ladder (each carries who+what) | beats carry NO order cue (reshuffled, uniform, narration `order` not exposed); only the causal DAG `requires` fixes it; surface-cue/recency/position/length AND feedback-hill-climb solvers all FAIL |
| 2 | **supply-the-missing-key-EVENT** | one slot empty; pick the WHAT | the correct WHAT = the causal hinge a later beat `requires`; a trivial true-fact leaves later beats unsupported |
| 3 | **select-KEY-over-true-but-trivial** | two WHATs both stated in narration; pick the one that matters | the trivial WHAT = a DAG island — BUT key-ness is TWO-SOURCE (fix #1): a `narrative_key` WHO/problem/resolution is ALSO key even if not a hinge |
| 4 | **identify-the-WHO** (a `narrative_key` slot) | pick the actor | `who===beat.key.who` obligatory; a wrong-but-real-cast WHO → a face-that-doesn't-fit; an `in_story:false` other-story WHO never satisfies |
| 5 | **state-the-PROBLEM** (DAG root + `narrative_key`) | pick the initiating problem | the DAG root (nothing requires it) AND flagged `narrative_key` (stakes never droppable) |
| 6 | **state-the-RESOLUTION** (DAG terminal + `narrative_key`) | pick the resolution | the DAG terminal AND flagged `narrative_key` (the meaning never droppable) |
| 7 | **correct-the-friend's-wrong-memory** (discrimination) | Pip remembers ONE beat wrong; find + fix the break | run the DAG backwards — detect the single who/what/position violating `requires`; a guesser can't localize (no feedback leak) |
| 8 [G1 reach] | **tell-the-central-MESSAGE** (`referenceMode:'none'`) | after a clean retell, pick the lesson | separate RL.1.2, Grade-1; an inference over the whole problem→resolution arc; does NOT count toward the K claim |

- **The two-story-tangle (recall-discrimination) = the `in_story:false` distractor woven through 2/3/4/7**, not a separate type.
- **Ship plan:** 1-7 = K core (RL.K.2 + SL.K.4 carried); 8 = the G1/RL.1.2 reach. **≥7-distinct met by ≥7 perceived-distinct STORIES**, order-only reshuffle. **Free slice = order-by-causal (1) + select-KEY-over-trivial (3) + identify-the-WHO (4).**

## Win-states & juice (no competition)
No timer/score/streak/countdown/fail. Vessel = a **glowing storybook filling with illustrated pages** (one page per round) — non-numeric. **Win = being FOLLOWED:** Pip's stub-mirror bubble completes into a glowing scene, Pip leans in, gasps, "I feel like I was THERE! you told it so I could see it!" (mood asleep→awake→following→hooked→delighted). The confused state is WARM juice (curious head-tilt, soft "hmm?", the diffuse causal-symptom question) — never a buzzer/X/sad-sound/disappointed face. Reward = diegetic + relational (Pip's understanding + delight, the storybook gaining a page). Full-pass keepsake = the completed storybook → cross-game `GameCollection`. CSS/WebAudio; reduced-motion; mute-safe.

## Pedagogy
- **RL.K.2 both clauses FUSED into one act:** reconstruct-the-EVENTS-WITH-KEY-DETAILS (place the beat in sequence AND supply the key detail = ONE act). Never a 4-separate-questions quiz (that's RL.K.1 retrieval in a costume).
- **3 impostors guarded:** picture-sequencing (panels GONE; stubs wordless/scrambled) · single-fact-recall=RL.K.1 (assemble INTO the retell, not answer ABOUT) · memory-span (4-5 beats, ~5-8 sentences, ONE protagonist, ONE problem, ≤2 named chars — holding it isn't the bottleneck). **Memory-span guardrail (fix #3):** the faded stubs are recognizable-but-underspecified — they CUE which beat is which (so the task is "re-sequence + supply details I recognize," not "recall 5 cold") while carrying NO order/who/what (so they can't be transcribed); replay-between-placements = permitted spaced re-encoding.
- **4-5 BEATS not 3** (three = 6 perms brute-forced + drops the key-details construct). Story-grammar (Stein & Glenn): character/setting/PROBLEM (the spine)/key-action(1-2)/resolution. **Causally-FIXED** ("and then" must be "and SO"; test = read out of order to an adult → "that can't happen yet").
- **KEY vs TRIVIAL — TWO-SOURCE (fix #1, the keystone correction):** KEY if EITHER (i) a **causal hinge** (the `what` a later beat `requires`, proven from the DAG) OR (ii) flagged **`narrative_key:true`** because it answers a fixed story-grammar slot — **WHO (protagonist) / PROBLEM-stakes / RESOLUTION-why-it-mattered.** The DAG-island definition ALONE wrongly marks the protagonist/stakes/resolution trivial (no later beat mechanically requires the actor's identity) → that narrows "key detail" to "causally-necessary event" = the WRONG, too-narrow lesson. The gate enforces no `narrative_key` detail is ever a true-but-trivial distractor + every story has WHO+PROBLEM+RESOLUTION non-droppable. TRIVIAL = true (stated in narration) but neither hinge nor `narrative_key`. Route the key-judgment through the problem/character/resolution skeleton + the AUDIENCE-NEED ("can Pip follow without it?").
- **The friend = the construct-validity instrument** (genuinely can't follow a scrambled/gappy retell → both clauses functionally necessary). **The diagnostic is DIFFUSE (fix #2):** Pip names the KIND of causal break, NEVER the slot index or the fix → the child must locate-and-reason, and a feedback-hill-climb can't converge.
- **With-prompting-and-support embodied** (re-narrate the causal fact; co-construct the tricky part — modeling reasoning, not error-location). **No-mic honest scope named** (reconstruct-and-retell, NOT free narration/own-words/prosody).

## Interaction & UX
- **Two-stage time-shared single region** (panels GONE at retell = no-copy + mobile single-column): `.rt-root[data-stage]` + persistent `.rt-friend` (Pip `data-mood` + the stub-mirror bubble + the comprehension thread) + `.rt-story` (watch: one panel synced to TTS + Replay + "Tell my friend!→") + `.rt-retell` (retell, same region: `.rt-beat-slots` vertical ladder = faded wordless stub + beat-drop + who-slot + what-slot; `.rt-trays` beats/who/what; "Tell it!").
- **Validity DERIVED, validated ONLY on "Tell it!" (fix #2):** `validateRetell` = pure function over the DAG (each placed beat's `requires` all at earlier slots — permits equivalent orderings, fails any causal break; `who===key.who`; `what` KEY if hinge OR `narrative_key`; trivial what ≠ key → fail-follow). **NO live per-swap re-eval.** On a break the engine knows the failing beat internally but surfaces only a DIFFUSE symptom (the KIND of causal contradiction) — never `failPos` to the child. `key.what` (hinge) COMPUTED as the `what` later beats `requires` point at; `narrative_key` authored + gate-audited.
- **The comprehension thread / stub-mirror:** during "Tell it!" the bubble fills beat-by-beat (correct→silhouette resolves; missing→gap+"?"; wrong→mismatch tint); clean → the thread completes; break → it TANGLES/doesn't-complete WITHOUT a slot index. **At <600px (fix #6)** the drawn Pip→slot thread degrades to a per-slot inline state glyph (a link-icon on the slot: solid-reaches vs dashed-frays) + the bubble collapses to a compact beat-pip row of stub-dots above Pip.
- **TTS timer-free:** `playStory` awaits `ctx.speak` per panel; `tellIt` = the DOM read top-to-bottom via a per-locale `retellLine`/`detailTemplate` template (slots-not-concatenation, §A.13.54/§A.13.56 — Finnish: a fixed-nominative `{who}` apposition is ungrammatical → author inflected).
- **Mobile @280-768:** ONE phase in the column; beat-slots vertical; the 3 trays a tab-swapped single shelf <600px (side-by-side ≥600); chips ≥48px, drop-zones LARGER than chips; tap-to-select-then-tap-slot fallback (no pointer-drag required); "Tell it!" sticky. Pass `audit-game-mobile.js` 280-768 empty+filled (the overstuffed-narrow class — hard gate).
- **Accessibility:** TTS everywhere; not color-only (friend = shape+motion+bubble+TTS; thread = dashed-vs-solid + reaches-vs-stops / the per-slot glyph); ≥44px; reduced-motion; mute-safe; `aria-live` + hidden running transcript.

## Runtime mapping + MEASURED build-gate + PER-LOCALE
- **Round descriptor (DATA; engine never holds a baked story/boolean):** `{ id, type, referenceMode:'stubs|count-only|none', story:{ cast:[{id,who,narrative_key?}], setting, beats:[{ id, order(NARRATION-only NOT the answer key), requires:[beatIds], panel, key:{who,what}, narrative_key?:true, trivialWhats:[{id,in_story:true}] }], foreignWhats/foreignWhos:[{id,in_story:false}], lesson:{id,distractors} }, strings:{[locale]:{narration,who,what,lesson,friend,retellLine,detailTemplate}} }`. Validity DERIVED. JSON-LD: PRIMARY RL.K.2; SECONDARY SL.K.4; SEPARATE alignment = RL.1.2 (G1, only sub-act 8). On-page `teaches` = "reconstruct-and-retell a story with key details, told to a friend." Framework name localizes (§20.10/§A.13.49); the CCSS code stays the machine anchor.
- **`verify-retell-core.js` (MEASURED — drives the real `validateRetell` + the real round set; HALTS build):**
  1. **CAUSAL-DAG-NOT-SURFACE:** surface-cue / recency / position / length solvers each pick the correct first-beat/order at ≤ chance → FAIL if any beats the DAG-blind baseline.
  2. **FEEDBACK-HILL-CLIMBER must FAIL (fix #2 — the keystone gate, analog of Game 7's anti-leak):** a solver that places arbitrarily, reads Pip's response, applies any leaked slot-index/directed-swap, loops — must NOT converge faster than chance-with-comprehension-removed. If it converges, the diagnostic leaks → FAIL.
  3. **CAUSAL-GATE REAL:** resolution-before-problem → `validateRetell` returns a break + cannot-advance; every topologically-valid equivalent ordering PASSES.
  4. **TWO-SOURCE KEY-NESS (fix #1):** (a) `key.what` (hinge) === the `what` a later beat `requires` (a non-hinge hand-tag → FAIL); AND (b) **every `narrative_key:true` detail (WHO/problem/resolution) is present, non-droppable, NEVER a true-but-trivial distractor**; every story has WHO+PROBLEM+RESOLUTION.
  5. **TRUE-BUT-TRIVIAL per beat:** ≥1 `trivialWhat` `in_story:true` AND neither-hinge-nor-`narrative_key` (a DAG island); a trivial what in a key slot → fail-follow; pick-any-true FAILS.
  6. **DISTRACTOR-FROM-OTHER-STORY:** ≥1 `foreignWhat`/`foreignWho` `in_story:false` never satisfies.
  7. **NO-COPY invariant (expanded, fix #7a):** at `stage==='retell'` — (i) the bubble shows ONLY child-supplied state, never the target, before "Tell it!"; (ii) stub DOM order ≠ solution order (scramble VERIFIED); (iii) no `data-*`/aria on stubs carries who/what/order; (iv) snapshot+grep for any `key.who`/`key.what` text or narration `order` → absent.
  8. **WHO obligatory** (`who===beat.key.who`).
  9. **≥7 distinct PERCEIVED STORIES (fix #3):** ≥7 stories the child experiences as genuinely different (distinct cast/problem/setting/emotional-shape — NOT 7 slot-position relabels), sub-acts 1-7 the skill-coverage spine; order-only reshuffle (pass-2 ≠ pass-1; never synthesizes unvalidated content).
  - Plus standing gates: `audit-game-mobile.js` (both phases, empty+filled, 280-768, incl. the per-slot-glyph + beat-pip-row degrade <600px), `audit-game-variety.js`, `audit-no-competition.js` (lcs-shell 0-line), SEO/JSON-LD §21. Companion `local-test-retell.js` (11-viewport; tap-tap fallback; TTS narrates + retell voices in chosen order; the bubble fills; the thread tangles WITHOUT a slot index on a driven break; mood reaches delighted on a clean retell; mute-safe). Cache-bust `?v=N` (§A.13.42).
- **PER-LOCALE — the MOST EXPENSIVE class:** stories **NATIVELY AUTHORED per locale, NOT translated**, over a **shared difficulty-calibration SKELETON** (character + problem-type + attempt(1-2) + resolution, 4-5 causally-fixed beats, ≤2 named chars, ~5-8 sentences). A translated story BREAKS it: the key-detail set may not map; the retell grammar is language-specific (tense/aspect, the "then/so/because" connective register, narrative conventions); the central message is culture-bound. The retell is assembled from slots + templated per locale (never concatenation; §A.13.54/§A.13.56, esp. Finnish). **EN-first proof corpus** (one tight 4-5 beat story spanning 1-7 + the G1 lesson); each later locale = a §A.13.48 native 3-agent ensemble (children's-lit author + K-reading educator + linguist), plan-mode; `[NSR-FLAG]` sv/da/no/fi; a locale's ensemble may decline a sub-act.
- **Feasibility:** SIMPLE engine + DOM/CSS/WebAudio; the cost is the STORIES (irreducible, per-locale). Stub-first; local preview; tune the diffuse-confusion diagnostic + the stub-mirror bubble fill + the film-disappear transition BEFORE wiring the pool; run the feedback-hill-climber + surface-cue solvers FIRST (they reject a leaky or surface-gameable pool — that's the gate working).
