## 2. Concept & creative hook
**Dewey the magnifying-glass ladybug naturalist keeps LOSING facts inside his field guides — and the child finds them by reading the book's own navigation tools (TOC, headings, glossary, icon-menu) and its captioned diagrams, never by guessing what the picture looks like or what they already know.**
- **THE NAVIGATION FEATURES ARE THE SPINE (KNOW + USE — the binding pedagogy):** Dewey hands the child a field-guide page with a real text-feature apparatus — a **table of contents**, **section headings**, a **"Words to Know" glossary**, an **icon/menu strip** — and a creature asks a question BY FUNCTION/MEANING. The child reads the feature to LOCATE where the fact lives (which page / which section / which definition / which tool). The diagram+caption is ONE constrained feature-type among these, never the whole game.
- **THE MAPPINGS ARE NON-PRE-KNOWABLE BY CONSTRUCTION (the critic's deepest fix — HYBRID spine):**
  - **Fictional invented creatures for diagram/caption rounds:** *"The gribbet uses its **frell** to glow in the dark."* No child has a prior for gribbet→frell, so the question *"Which part helps the gribbet GLOW?"* is answerable ONLY by reading the caption. (Real animals with common-knowledge mappings — wings→fly — are FORBIDDEN here; they let a knowledgeable child skip the feature.)
  - **Feature-internal bridges for navigation rounds:** the question references a term that ONLY the feature defines/disambiguates — *"The glossary says a 'kit' is a baby beaver. Which heading tells what a kit EATS?"* — so the child must read the glossary to learn kit=baby, then navigate. (A naked topic-prior bridge like "where does it SLEEP?"→"Homes" is FORBIDDEN — sleep→home is itself common knowledge.)
- **THE QUESTION IS BY FUNCTION/MEANING, THE ANSWER-WORD ABSENT (the load-bearing read):** the question says "GLOW / EATS / what 'X' MEANS"; the label/heading says "frell / Food / kit"; the only bridge lives INSIDE the feature text. Picture-resemblance, word-match, and prior knowledge all fail — the feature is the sole path.
- **THE CHILD READS; DEWEY READS ONLY THE QUESTION ALOUD (RI, not SL):** TTS speaks the QUESTION (and a "hear it again"); there is **no feature-text TTS** — reading the heading/caption/glossary IS the assessed cognition. Pre-readers are out of scope for this Grade-1 *reading* game (routed to the RF/phoneme catalog) — stated, not apologized for.
- **THE PAYOFF:** a correct locate → Dewey stamps a tiny "FOUND IT!" + a pressed-leaf / feather / pebble keepsake drops into his **Field Journal** (a non-numeric abundance vessel). `ctx.correct()`. A wrong tap → no fail; the **relevant feature text gently highlights** ("Let's re-read what the page says about glowing…") and Dewey nudges warmly; the child reads + taps again.
- **Anti-generic statement:** NOT tap-the-part-that-looks-right — (a) the NAVIGATION features carry it (TOC/heading/glossary/icon, not just diagram-labels); (b) every question is by FUNCTION/MEANING with the answer-word ABSENT (the bridge lives only in the feature); (c) the mappings are NON-pre-knowable by construction (fictional creatures + feature-internal bridges) so even a knowledgeable child MUST read — and the **`WORLD_KNOWLEDGE_SOLVER` gate adversary** proves it; (d) child READS the feature, TTS reads only the question (RI, not SL); (e) the gate proves visual-search + word-match + first/random + blind-to-feature + **world-knowledge** solvers ALL fail while the read-the-feature-to-locate oracle passes.

## 3. Core loop & the ≥7 experiences (KNOW + USE; distinctness in the FEATURE-TYPE × NAVIGATION-FUNCTION)
**Loop (read the question → read the FEATURE → LOCATE the target → tap):** Dewey poses a function/meaning question (TTS, question-only) → the child reads the round's text feature (TOC / heading / glossary / caption / icon-menu) → finds the target the feature points to → taps it (a tappable entry / heading / glossary term / labeled part / icon) → a correct locate → Field Journal + `ctx.correct()`; a wrong tap → guided re-read (the relevant feature text highlights), then re-tap. **No timer/score/streak/countdown/fail/attempts/"X of Y".** Reshuffle rotates choice ORDER **and the distractor SET** (F6).

**The ≥7 distinct experiences (the pedagogy's 6 firm + 1 conditional; distinctness in the FEATURE × FUNCTION, NOT diagram-swap padding — F5: each must survive world-knowledge filtering):**
| # | Experience (`cog`) | Verb | The child's act | Why genuinely distinct |
|---|---|---|---|---|
| 1 ★ | **use-a-TOC** (`toc`) | USE | read TOC entries, map the topic → tap the entry/page-number | maps a fact's MEANING to a section title/page (the purest locate; target = a contents line) |
| 2 ★ | **use-a-HEADING** (`heading`) | USE | scope WHICH section by reading headings, tap the heading | in-page navigation; two-step (scope → land); distinct from the TOC list |
| 3 ★ | **use-a-GLOSSARY** (`glossary`) | USE | navigate alphabetical entries to a WORD'S MEANING, tap the definition | a definition lookup (term→meaning), a different bridge type |
| 4 ★ | **use-an-ICON/MENU** (`menu`) | USE | pick the tool/button by its FUNCTION (magnifier = search) | no words to match — pure function-of-a-symbol; medium-native; named in the standard |
| 5 ★ | **find-by-function (fictional diagram + caption)** (`diagram`) | USE | read the caption to bridge an invented function → the labeled part of a FICTIONAL creature | the constrained diagram type; non-pre-knowable by fictional referent |
| 6 ★ | **which-feature-would-help (book-specific)** (`which-feature`) | KNOW | "THIS book has a glossary and a TOC — to find what a word MEANS, which do you open?" | instantiates the KNOW verb (feature-function judgment); capped to a minority (F4) — book-specific so it isn't pre-knowable trivia |
| 7 △ | **caption-match (reverse, fictional)** (`caption-match`) | USE | given a located fictional part, find the caption that describes its FUNCTION | reverse direction; conditional — only when ≥2 captions are plausible + no word-match (drop the trivial form) |
| 8 | **use-an-INDEX / bold-term (2.RI.5 stretch)** (`index`) | USE | follow an index "see-also" / a bold key-term to its referent | a redirection/typographic feature; `also_teaches 2.RI.5` flavor, sparse |
- **Honest framing (pedagogy + critic F4/F5):** the variety comes from **FEATURE-TYPE × NAVIGATION-FUNCTION** (TOC ≠ heading ≠ glossary ≠ icon ≠ fictional-diagram ≠ feature-judgment), NOT from re-skinning the creature (creature-swap is a theme-wave, never a distinct cognition). DROPPED: **leader-line-trace** (visual line-following, not reading). **`which-feature-meta` capped ≤ a minority** (the KNOW verb is legit but thin); the **≥7 floor is measured AFTER the `WORLD_KNOWLEDGE_SOLVER` filters pre-knowable rounds** — 5 firm USE cognitions (toc/heading/glossary/menu/fictional-diagram) + 1 KNOW (which-feature, capped) + 1 conditional (caption-match) clears 7 honestly. §A.13.60 ≥7 distinct-to-the-child; reshuffle rotates order + distractor set.
- **Free slice = use-a-TOC + use-a-glossary + find-by-function(fictional diagram)** — proves both verbs (KNOW + USE), the navigation spine, AND the non-pre-knowable construction; the visual-search + word-match + first/random + blind-to-feature + world-knowledge solvers all fail.

## 4. Win-states & juice (no competition)
No timer/score/streak/countdown/**fail-state**/attempts/"X of Y". **THE FIELD JOURNAL (signature):** a correct locate → Dewey stamps "FOUND IT!" and a pressed keepsake (leaf / feather / pebble / acorn) drifts into his journal (`GameCollection` — a growing collage of finds; NEVER a count). **Warm wrong-handling (no-shame, the critic's F1):** a wrong tap → NOT a bare beep — the **relevant feature text gently highlights/underlines** (the TOC line, the caption sentence, the glossary entry) and Dewey says "Hmm — let's re-read what the page says about *glowing*"; then the choices re-enable (order + distractor set reshuffled so positional memory gives no signal). NO red, NO buzzer, NO attempts-counter — infinite warm tries, each routed THROUGH a feature-read. The honest brute-tap ceiling is stated: with ≤5 choices and no penalty a determined brute-tapper eventually wins a single round; the defense is that **the session never re-serves the same round in the same shape** (distractor-set rotation), so there's no stable stimulus→position pair to learn. Discovery beats ("help a friend read their guide") use `ctx.advance()`. `ctx.correct()` only on a correct tap → auto-advance. CSS/SVG + TTS (question-only); reduced-motion → instant + the guided re-read is text; mute-safe (the features-as-list + the spoken question carry everything; all feature text is on-screen).

## 5. Pedagogy
- **1.RI.5 instantiation (both verbs):** the child KNOWS the features (recognizes what a heading/TOC/glossary/icon IS and is FOR — the which-feature judgment) AND USES them to LOCATE a key fact by its FUNCTION/MEANING (navigate the feature to the target).
- **THE KEYSTONE RULES (pedagogy + critic):** (i) **both verbs load-bearing** (know AND use-to-locate). (ii) **the navigation features are the SPINE** (TOC/heading/glossary/icon-menu); the captioned diagram is ONE constrained feature-type. (iii) **every question by FUNCTION/MEANING, answer-word ABSENT** (the bridge lives only in the feature). (iv) **NON-pre-knowable by construction** (fictional referents for diagrams; feature-internal bridges for nav) — even a knowledgeable child must read; the `WORLD_KNOWLEDGE_SOLVER` proves it. (v) **child READS the feature; TTS reads only the QUESTION** (no feature-text TTS → RI, not SL). (vi) **decodable text bounds** (1-4-word headings; 1-sentence captions; 3-5 choices; high-frequency vocab → comprehension, not RF). (vii) **picture-proof** — blank the feature text and a non-reader cannot win (the gate's `ANSWER_REQUIRES_TEXT` + the affordance tag).
- **§20.8 demonstrate-don't-touch (the critic's headline):** as a real-animal "tap the part that does X" design it TOUCHED 1.RI.5 (a knowledgeable child answers wings→fly from their head, label-matches the word, or eyeballs the picture — zero feature-reading; the gate blind to the world-model). As a navigation-spine + fictional-diagram + feature-internal-bridge + question-only-TTS design it DIRECTLY INSTANTIATES both verbs (reading the feature to locate by function/meaning is the ONLY path). The line is exactly: the bridge lives only in the feature AND is not pre-knowable AND is read not heard. The gate (visual-search + word-match + first/random + blind-to-feature + **world-knowledge** all FAIL; the read-the-feature oracle PASSES) is the machine-checked proof.
- **also_teaches:** `2.RI.5` (feature-BREADTH — index/bold/subheading, NOT efficiency/timers; the no-timer rule independently forbids the "efficiently" criterion). `RI.K.5` optional warm-up. Strand-opener (no RI game owns this). HARD FENCES vs `RF.1.*` + `RL/SL` + `RI.1.1` + i-spy.
- **Grade fit:** Grade 1; reading-informational; the child reads short decodable feature text; 3-5 choices; the LOCATE is the cognition (no efficiency/speed). Early/emergent readers (Grade 1+); pre-readers out of scope (a reading standard).
- **No-shame:** the bountiful Field Journal is the reward; wrong taps get a guided re-read (never a fail); Dewey never red-X'es the child.

## 6. Interaction & UX
- **Runtime: read-question → read-FEATURE → LOCATE → tap.** `field-guide-core.js` holds the round `{ id, cog, skin ('diagram'|'page'), feature:{ type ('toc'|'heading'|'glossary'|'menu'|'caption'|'index'), text, functionMap }, targets:[{id,label,affordance}] (≥3 plausible), question:{ functionPhrase, correctTargetId }, expectedAnswer (resolves functionPhrase→target FROM feature.text, NEVER stored) }`. **The answer = `f(read the feature, map function/meaning→target)`, never `f(picture-resemblance)` / `f(word-match)` / `f(prior knowledge)` / `f(tap till accepted)`.**
- **State separation (anti-cheat):** `snapshot()` exposes `{ cog, skin, feature (the live text + entries), targets (labels only), question }`. `facts()` exposes per-round `{ winRoutesThroughFeature, questionWordNotInLabel, functionNotVisuallyObvious (affordance tags equal-salience), answerRequiresText (blank feature → oracle fails), notPreKnowable (world-knowledge solver ≤ chance), navBridgeIsFeatureInternal (nav rounds), childReadsFeature_noFeatureTTS (===true), multiplePlausibleTargets (≥3), labelsAreLiveDomText, answerNotStored, distractorSetRotates, whichFeatureCapped }`.
- **Tap + locate (no Check button):** the child taps a target (a TOC line / heading / glossary entry / labeled fictional part / icon — each a real `<button>`). A correct tap → `ctx.correct()` auto-advance (the tap IS the deliberate selection; there is no separate commit/checker — the only feedback is the warm result or the guided re-read). A wrong tap → the guided re-read (relevant feature text highlights + Dewey nudges), then re-enable with order + distractor-set reshuffled.
- **Mobile @280px (the critic's F5/§A.13.55):** the **FEATURES-AS-LIST is canonical** — at <480px (incl. 280px) drop leader-lines/overlaid labels; render `[ wordless art aria-hidden ] [ question + 🔊 ] [ feature text block ] [ ANSWER = vertical list of label/entry BUTTONS ≥44px ] [ Field Journal ]`. TOC/heading/glossary/menu are already vertical lists → degrade for free. `audit-game-mobile.js` empty/mid/answered at 280-768.
- **Accessibility (the critic's F8 — the features-as-list is the CANONICAL model, not an afterthought):** the art `<img>`/decorative `<svg>` is `aria-hidden`; the interactive part is a `role="group"`; the QUESTION is visible text + `ctx.speak()` + an `aria-live="polite"` region; the FEATURE is a focusable readable block (TOC `<nav><ol>`, headings `<section><h3>`, glossary `<dl>`, diagram caption `<p>` + labels as a `<button>` list); the targets are tabbable `<button>`s with `aria-label`=the entry/label. The SR child performs the IDENTICAL task (read the feature → pick the label) — guaranteed because the answer is non-visual by construction. **F8 runtime equivalence assert (local-test):** `correctTargetId`, the choice set, and every label string are byte-identical between the features-as-list DOM and the ≥480px visual DOM at the 479/480 boundary (the "verify on the rendered path, not the metadata path" lesson). The guided re-read emits to the same live region. Reduced-motion → instant. Mute-safe (no audio gates anything — all feature text is on-screen). Not color-only (entries differ by text+shape, never hue alone).
