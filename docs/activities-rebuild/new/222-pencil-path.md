## The skill
Control the stroke: trace straight lines, slants, zigzags, waves, loops, spirals and shapes from the start dot in the right direction.

## The apparatus and its invention
THE CART THAT ONLY ROLLS ON THE ROAD. Each stroke is a road shaped as the stroke (a zigzag mountain road, a wavy sea lane, a loop-the-loop track, a spiral snail shell road) with a library vehicle or animal at the orange start dot. The child's finger drives it: the vehicle follows the finger only while the finger stays on the road; leaving the road stalls it at the edge, waiting, and the road behind it stays painted, so a lift-off resumes from where it stopped (no restart). Direction matters: dragging backward does nothing. Reaching the end delivers the passenger to a library picture (picture-to-picture path). Road width is the precision setting.

- **Misconception the apparatus makes visible:** Starting at the wrong end / wrong direction, and lifting and jumping instead of a continuous stroke.
- **Pictures:** vehicles (car, train, boat, plane, tractor), animals (snail, bee, frog) as the mover; goal pictures from any colour theme
- **Settings:** Stroke family: lines & slants / zigzags & waves / loops & spirals / shapes / picture-to-picture · Road: wide / narrow
- **Rounds:** 9 roads per family, each a different stroke; start side varies (left, top) so direction is read, not habit; completion only by the full path so one right result.
- **Worksheet types it covers:** K-236, K-244, K-245, K-246, K-247, K-248, K-385, K-386, K-387
- **Distinct from:** The Fading Line (#4) and the letter traces trace FORMED symbols; this is the stroke control before symbols, and the road (not a fading guide) is the invention.
- **Build risk:** Precise tracking at 360 px with a fat finger — road width must be measured, and the "trace-path" maze screen code is a precedent but is a deck screen, not an activity core (own core needed).
