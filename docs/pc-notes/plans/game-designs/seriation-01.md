## §3 — THE ARCHITECTURE REWORK (the heart; the deepest flaw + fix)
**The critic's deepest catch — the memory scaffold, rendered as an EVALUATED VERDICT, is a truth-table the child READS (not a relation the child composes).** The Bryant-Trabasso scaffold freezes the premises ("A ▸ longer ▸ B", "B ▸ longer ▸ C") to keep them perceptually available — but a rendered VERDICT-token is a TRUTH-TABLE: a child answers "A vs C?" by **ROLE-FREQUENCY** ("the object that is never a 'shorter-party' wins") with ZERO transitive logic. And that read is **INVARIANT under the obvious scramble fixes** (left/right flip, presentation order) — so scrambling the layout kills only the shallow POSITIONAL read and leaves the ROLE-FREQUENCY read alive. (The Game-65 scaffold-enables-bypass lineage; the classic Bryant-Trabasso "labeling/end-anchor" critique.)

**THE FIX — render the premises as RE-PERCEIVABLE MEASUREMENT EVENTS, not evaluated verdicts:**
1. **Frozen cord-SEGMENTS on a "memory rail."** When the cord measures A, it FREEZES a cord-segment at A's length on the rail, **labeled ONLY with A's icon** (NO "longer/shorter", NO ▸ arrow, NO verdict). Same for B, C. The premises are now re-perceivable MEASUREMENT EVENTS (icon + the act), NOT readable verdicts.
2. **The frozen segments INHERIT the scale-inversion** (`pxExtent(frozenSegment) = trueLength × scale`, `orderBy(pxExtent) ≠ orderBy(trueLength)`) — so re-perceiving/eyeballing them IS the killed pixel-cheat (scores at chance). The child must RECALL the qualitative result of each measuring act (the cord found A longer-than-B; C shorter-than-B) and COMPOSE — genuine transitive inference. The rail supplies the memory HOOK (three icons, three measuring-events) WITHOUT a readable answer-key OR honest pixels.
3. **`REMEASURE_IMPOSSIBLE`** — the cord is CONSUMED by the measuring act (retracts into the frozen rail segment, can't be re-grabbed; the measured wall seals — "Pip already noted that shelf"). The two query endpoints A and C are NEVER simultaneously cord-reachable → the FLOOR mechanic can't be used to avoid the ceiling; the child MUST chain two held premises.
4. **Mandatory non-metric diegetic art** — every object is a same-size category ICON (`OBJECT_ICONS_LENGTH_INVARIANT`); the cord is the ONLY length-bearing element; taught from rung 1 ("the icon is a name-tag; only the cord knows length") so the scale-inverted lying pixels never read as "drawings lie."

## §4 — Anti-cheat architecture (the gate; consumes RENDERED geometry)
- **PREMISE-TOKEN ROLE-FREQUENCY (the deepest cheat) — killed** by §3 (frozen re-perceivable events, no verdict label): `PREMISE_TOKEN_POSITION_SOLVER` (chain-head/leftmost) + **`PREMISE_ROLE_FREQUENCY_SOLVER`** (never-a-loser wins — the one the scramble fix MISSES; failing it PROVES the verdict-strings are gone) + `FROZEN_SEGMENT_PIXEL_SOLVER` (sort the rail segments by px width — killed by the inherited scale-inversion, on the 3-object triple too) — ALL must FAIL.
- **OBJECT-LEVEL cheats — killed:** the pixel-inversion (`pxExtent = length × scale`, `orderBy(pxExtent) ≠ orderBy(length)`, on objects + frozen segments + the full triple) + foreshortening + same-size icons → `DIRECT_VISUAL_COMPARE_SOLVER` / `PIXEL_LENGTH_SOLVER` / `OBJECT_ICON_SIZE_SOLVER` FAIL (litmus: a bounding-box-width sorter scores at chance). `PAIRWISE_NO_INFERENCE_SOLVER` killed by the structurally-unobservable 3rd pair. **`OBJECT_WALL_POSITION_SOLVER`** (answer = the object on the left/far/top wall) FAIL — wall/lane decorrelated from length.
- **FLOOR-AVOIDS-CEILING — killed** by `REMEASURE_IMPOSSIBLE` (§3.3) + `TRANSITIVE_INFERENCE_REQUIRED ≥ ceil(0.4 × assessedRounds)` (the operator's ~40% genuine-ceiling floor, NOT a toothless N=1).
- **Structural asserts:** `DIRECT_COMPARISON_IMPOSSIBLE` (targets' rendered extents don't sort to the true relation), `THIRD_OBJECT_REQUIRED`, `GO_BETWEEN_LENGTH_FIXED`, `ANSWER_DERIVED_NOT_STORED` (mutate an object's true length → answer flips; mutate the cord's length → answer must NOT move), position-randomized, ≥7 observability-configs. ORACLE + an honest transitive-solver PASS.
- **Wrong-tap re-show — no-reveal:** re-plays the measuring events in their ORIGINAL (randomized) order, byte-identical to the initial presentation (NO length-ordered emphasis, NO winner-segment highlight) — re-teaches the move, never the answer.

## Cohort doctrine this game adds
**The SCAFFOLD-RENDERED-AS-EVALUATED-VERDICT lesson — PROGRAM-WIDE.** A working-memory scaffold that the standard's cognition genuinely REQUIRES (Bryant-Trabasso: transitivity is only Grade-reachable with the premises kept perceptually available) becomes a CHEAT SURFACE if the premises are rendered as EVALUATED VERDICTS ("A longer-than B") rather than RE-PERCEIVABLE OPERATION-EVENTS — because an evaluated-verdict display is a TRUTH-TABLE the child READS (role-frequency: "the never-a-loser wins") instead of a relation the child COMPOSES, and that read is INVARIANT under the obvious anti-cheat scrambles (left/right flip, presentation order) — so scrambling the layout kills only the shallow POSITIONAL read and leaves the ROLE-FREQUENCY read alive (the deeper one). **The fix: render the scaffold as the RAW RE-PERCEIVABLE STATE of the operation (here: the frozen cord-SEGMENTS the child measured — carrying NO verdict label AND inheriting the same answer-hiding render-distortion [scale-inversion] that hides the answer everywhere else, so re-perceiving them is itself the already-killed pixel-cheat). The premises stay perceptually-available (the memory hook the cognition needs) WITHOUT becoming a readable answer-key; the child must recall the qualitative RESULT of each operation-event and compose. Gate with a ROLE-FREQUENCY solver (not merely a positional one) that must FAIL — the positional solver is the shallow skin; the frequency solver is the real test.** Generalizes to ANY game that externalizes premises/intermediate-results as a memory aid (transitive chains, multi-step reasoning, held-relations): show the EVENTS to re-perceive, never the VERDICTS to read. (Companion — the genuine-difficulty principle: a working-memory scaffold for a genuinely-hard cognition either LEAKS the answer or imposes the real load; done right [events not verdicts] the residual difficulty IS the cognition, and the no-fail/warm framing must ABSORB a real miss-rate rather than the design engineering the miss-rate to zero — which would mean the scaffold leaked. The operator's call for the genuine-difficulty ceiling over a guaranteed-pass garnish is the premium-faithful one.)
