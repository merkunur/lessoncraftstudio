## The skill
The area of a rectangle is the number of rows times the tiles in each row.

## The apparatus and its invention
THE TILE ROLLER: a paint-roller whose drum is exactly one row of unit tiles wide (its width is set to the rectangle's side, shown by tile marks on the drum). The child drags it down the empty rectangle; each pass lays one full row of tiles and clicks a row counter beside it. After 1-2 rows the child is asked how many tiles the whole floor needs and types it; the roller then finishes the rows to check. A miss shows the rows already rolled as a running total of equal parts (6, 12, 18...).

- **Misconception the apparatus makes visible:** Counting every tile one by one, or adding the two side lengths (perimeter) instead of multiplying.
- **Pictures:** none (tiles and roller drawn tool-grade); optional library floor-themed picture as decoration only
- **Settings:** Rectangle sizes: up to 5×5 / up to 10×10 · Stop after: 1 row / 2 rows (how much the child must predict)
- **Rounds:** Generated w×h with w,h 2-10, ≥ 9 rounds, no repeated product, never a square in two consecutive rounds; answer typed (keypad).
- **Worksheet types it covers:** G3-313
- **Distinct from:** Patchwork Meadow and Mosaic Menders count tiles one at a time; the roller makes the ROW the unit, which is the multiplicative step. Distinct from array-frame (unknown factor) and quarter-turn.
- **Build risk:** Low.
