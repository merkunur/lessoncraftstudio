**The rule that locks the type.** A frame is a whole panel literal with exactly one `{gap}` and NO answer text: it names `noun` (a vocabKey), `form` (`sg` = the vocab singular through `displayWord`; `pl` = `objForms[noun].pl`; or an `objForms` form `unique | def | defPl | part | gen | a2`), `case` (de), `fits` (every pool noun the panel judges to satisfy the predicate, the answer included), `foil` (F2), `pic`, `predicateKind`; the code READS the answer literal from the reviewed bank (`answerFor(loc, noun, form)`), prints it in the bank / chips / box count and stamps it; the panel never types a noun form. Exclusivity is data too: the composer places a frame only when `bank ∩ fits === {answer}` (mechanical, poisoned) and the panel signs `signedExclusive:true` (semantic). The article before the gap is printed INSIDE the frame literal and checked against the gender code for the declared case, never generated. Nothing inflects; nothing is substituted but `{name}` (where `nameSlot`) and the rendered gap. The de accusative trap is closed by rule (§5 rule 3), the sv definite trap by a mechanical equality check (§5 rule 9), the fi case by the declared form.
