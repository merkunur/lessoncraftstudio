## 4 Answer-hiding + uniqueness

- **Base:** the organ column is a derangement; the object decides the organ. Each of the 5 objects has a DIFFERENT primary sense (`items[].sense` unique per page), so every organ is used exactly once. A wrong line is visible: an organ with two lines or none.

- **Which sense:** 8 rows, one object each, the 5 organ chips in the FIXED order eye ear nose tongue hand on every row (d3 shuffles). The child circles one chip. Uniqueness = the data file's ONE primary sense per item (the panel signs it; the gate refuses an item present under two senses). - **Odd one out:** 4 rows, 3 objects of one sense + 1 of another; the odd index `rng.int(0,3)`, never the same index on 3 consecutive rows (verify).
