## The skill
Find a function rule from input/output pairs and apply it forwards and backwards.

## The apparatus and its invention
THE NUMBER MACHINE: a machine with a funnel, a rule slot and an output chute; two known pairs come out first as balls. The child slots a rule tile (+3, -4, ×2, ×5...) and drops the test balls back in: the machine runs the child's rule and a ball whose output does not match the known one rolls into a reject bin. With the right rule, the remaining inputs drop through and the child types each output; a final ball comes out of the chute with its input missing, and the child must run the machine backwards (the 'reverse' lever).

- **Misconception the apparatus makes visible:** Picking a rule that fits only the first pair; not inverting the rule for an unknown input.
- **Pictures:** none (machine drawn tool-grade)
- **Settings:** Rules: + and - / also × · Ask: outputs only / outputs and one missing input
- **Rounds:** Generated rule per round, ≥ 9 rounds, the two known pairs always ruled so that at least one wrong tile fits the first pair but not the second; tile order shuffled; typed answers.
- **Worksheet types it covers:** G3-328
- **Distinct from:** No machine or rule-finding activity exists; spring-frog has one constant step between neighbours, the machine maps unordered inputs to outputs.
- **Build risk:** Low.
