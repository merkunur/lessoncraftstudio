## The skill
Measure objects to the nearest half unit and record them on a line plot marked in halves.

## The apparatus and its invention
THE HALF-MARK RULER: a library object (pencil, leaf, worm-like crayon) lies on a ruler marked in whole and half inches/cm; the child slides the object's end against 0 and reads its length by dragging a marker to the nearest half mark. The measurement then flies down as an X onto a line plot whose axis is the same ruler, stacking above the matching half mark. After 6-8 objects the child answers one plot question (how many are 4 1/2 long? the longest minus the shortest?).

- **Misconception the apparatus makes visible:** Treating half marks as whole units, starting the measure at 1 instead of 0, and placing X's between marks.
- **Pictures:** classroom/pencil, crayon, marker; spring/leaf; vegetables/carrot, celery; insects-and-bugs/worm; accessories/ribbon; around-the-house/key — each drawn at a set length measured from its ink box
- **Settings:** Units: whole and half / quarter marks too · Questions: count only / differences
- **Rounds:** Generated lengths with ≥ 40% halves, 7+ objects per round set, ≥ 7 rounds; which plot column is tallest is balanced.
- **Worksheet types it covers:** G3-335
- **Distinct from:** Shelly's Tide-Line (2.MD.D.9) uses whole units only; the half mark and measuring are the new content.
- **Build risk:** Units per locale: inches with half (and quarter) marks in en; centimetres with half-centimetre marks elsewhere (a cm ruler's mid-marks are real). Object lengths come from the ink box at a fixed px-per-unit, verified by a gate.
