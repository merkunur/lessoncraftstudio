## The skill
Retell a four-picture story in order and pick the time-order starter each frame needs.

## The apparatus and its invention
A FILM STRIP with four empty frames and a reel of four story frames (library pictures composed into simple scenes) out of order. The child drags each picture into a frame, then each frame needs a starter tile (First / Next / Then / At the end) and a short caption tile chosen from two. Pressing Play runs the strip like a little film: the pictures animate in order, so a wrong order shows the story going backwards (the cake eaten before it is baked).

- **Misconception the apparatus makes visible:** Ordering by picture position on the reel, and using "Then" for the first event or "First" twice.
- **Pictures:** Stories composed only from library pictures in sequences whose order a K-2 child can see: e.g. snow day: weather (snowflake) → winter (snowman) → weather (sunny) → weather (puddle); camping: camping (tent) → camping (campfire) → space (moon) → beach (sun). Stories needing a made state (a baked cake) are refused. The story-line tool's card sets may be reused if (and only if) they are library pictures.
- **Settings:** Frames: 3 / 4 · Starters: shown in order / child chooses
- **Rounds:** ≥ 8 stories per setting, the reel order shuffled (never already in order); caption choices swap position.
- **Worksheet types it covers:** G2-378
- **Distinct from:** Wake Up, Pip! retells key details to a friend; Dot's Story Spine names start/trouble/fix. The film strip adds temporal sequence words, the W.2.3 skill.
- **Build risk:** Story supply is the risk: ≥ 8 four-frame stories with an unambiguous order from library pictures; the reviewer refuses any story whose order is not visible. Starter words (First / Next / Then / At the end) ×11 by the native panel.
