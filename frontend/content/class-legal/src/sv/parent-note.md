# Brev till vårdnadshavare

> **Till läraren (den här rutan hör inte till brevet):** Använd brevet bara om din skola tillåter att du använder det här verktyget. Det informerar vårdnadshavarna; det ersätter inte skolans egen information om personuppgifter. Skriv ut eller skicka det; fyll i raderna inom hakparentes. En sida, inga juridiska ord.

---

**Hej vårdnadshavare!**

I klassen övar vi ibland på en skärm med arbetsblad från LessonCraftStudio. Jag använder en klasslänk för det, så att jag kan se vilka uppgifter varje barn har förstått och vem som behöver öva mer.

**Vad ditt barn gör.** Ditt barn öppnar klassens sida, trycker på sitt nummer och sin djurbild och gör arbetsbladet. Det finns inget konto, inget lösenord och inget att installera.

**Vad som sparas.**
- Inget namn: bara ett nummer och en djurbild. Listan över vem som har vilket nummer har jag själv.
- För varje arbetsblad: vilket arbetsblad det var, när det öppnades, hur många svar som var rätt och vilka, hur många gånger svaren kontrollerades och om sidan gjordes klar.

**Vad som inte sparas.** Inget efternamn, inget födelsedatum, inget foto, ingen adress, ingen e-postadress. Webbplatsen registrerar inte vad ditt barn skriver, och det finns ingen tidtagning.

**Vem som ser det.** Bara jag kan se resultaten. Andra vårdnadshavare och andra lärare kan inte det. På klassens gemensamma sida kan ett barn se vilka arbetsblad en annan plats har gjort klart, men aldrig hur många svar som var rätt. Ditt barn ser inga poäng, ingen topplista och ingen tidtagning.

**Vad det används till.** Bara till min undervisning. Det används inte för reklam och säljs inte. Det sparas för [skolans namn] på en server i Finland av den som driver webbplatsen, som bara får använda det till detta.

**Hur länge det sparas.** Jag kan när som helst radera ditt barns resultat. Varje resultat raderas automatiskt senast efter 14 månader[, och i slutet av läsåret raderar jag klassen].

**Dina frågor.** Om du vill se vad som är sparat om ditt barn, få det rättat eller raderat, eller om du inte vill att ditt barns resultat sparas, säg till mig. [Kontakt.]
