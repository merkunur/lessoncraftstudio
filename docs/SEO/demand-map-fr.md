# French/France (fr) demand map — subject×grade hubs (Execution Unit 4)

Source: native **French (France)** ensemble (linguist/programmes-officiels + SEO/demand + K-3 educator/cycles), 2026-07-05. Operator-signed-off. Target = **France metropolitan** register.

## Core demand facts
- **Head noun by band:** **fiches** at maternelle ("fiches maternelle", "fiches GS") · **exercices** at élémentaire ("exercices de maths CP"). Top pages stack both. `coloriage magique` = a separate large cluster (moat gap, not this unit). Avoid the Belgian calque **"fiches de travail"**.
- **Modifiers:** **à imprimer** (dominant, mandatory) > gratuit(es) > PDF. Body: "avec corrigés", "en ligne". Adjective agreement (fiches gratuit**es** / exercices gratuit**s**) dodged via adverb "gratuitement".
- **Grade demand (ranked):** **CP** (anchor — apprentissage de la lecture) · **maternelle** (huge umbrella) · **GS/grande section** · CE1 · CE2 · MS · PS. Elementary uses codes (CP/CE1/CE2) near-universally.
- **Search-register words:** **maths** (not "mathématiques"), **lecture**, **phonologie**, **graphisme**.
- **Title pattern (locked):** `{fiches/exercices} de {subject} {GRADE} à imprimer – gratuit (PDF)` — "Fiches de maths GS à imprimer – gratuit (PDF)" / "Exercices de maths CP à imprimer – gratuit (PDF)".

## Competitor landscape / moat
- **Maternelle:** fiche-maternelle.com, mamaternelle.com, i-profs.fr, exercicematernelle.com (section×domaine). **CP/maths:** les-coccinelles.fr, mathovore.fr, pass-education.fr (by cycle→notion), recreakidz/reussiralecole (SEO-native grade×subject). **Moat:** playable+PDF (incumbents static/dated/ad-heavy); clean per-(subject×grade) grid; coloriage-magique-as-maths; "en ligne" interactive.
- **France vs BE/QC:** France CP/CE1/CE2 (NOT Belgian "1re primaire"/Québec "1re année"). "à imprimer"+"gratuit"+"fiches" pan-francophone. Lead France.

## Authentic French structure (programmes officiels / cycles) — labels flip at CP
- **math** → *premiers outils mathématiques* (maternelle) / **Mathématiques** (cycle 2); title uses "maths".
- **literacy** → *langage/phonologie/graphisme/lecture (préparation)* (maternelle+GS) / **Français, lecture** (CP+). "Lecture" is the CP flagship. Formal "lecture maternelle" avoided.
- **science** → **Explorer le monde** (maternelle/GS) → **Questionner le monde** (CP-CE2) [authentic, operator-signed; "Sciences" only from cycle 3].
- **logic + spatial** aren't French disciplines → standalone hubs **only at maternelle** (real *fiches de logique / discrimination visuelle* genre), folded into Mathématiques at CP-CE2.
- Maternelle-collision fixed: preschool→**"maternelle"** (umbrella) vs kindergarten→**"GS"** (display "Grande section (GS)").
