**The rule that locks the type.** Every item is a set of REFERENTS (1 or 2 named portraits; in de/nl also 1 captioned object) whose key is COMPUTED, never typed: `keyOf(refs)` = `m1` (one m) | `f1` (one f) | `mp` (two m) | `fp` (two f) | `xp` (one of each) | an object key off the vocab gender code (de m/f/n -> er/sie/es; nl d -> hij, h -> het) | `p` for any pair in fi. The NAME's panel `gender` tag must EQUAL the portrait's OPENED `depicted` tag on every referent (the composer pairs a name only with a portrait of the same tag; validator and gate refuse a mismatch). The answer is `map[face][key]` -> a chip index into the fixed table, or `null` = the item is refused for that locale on that face (de/nl `mp/fp/xp` -> null on base and F4 so the sie/zij collision never reaches a chip; -> the she-literal on F1 / F5 where the verb literal proves the number; fi every pair key -> `he`). Frames never inflect: the panel writes the singular and the plural variant of every sentence as two whole literals with a `{subj}` token that the code fills with `{name}` or `{name} {and} {name}` (the `and` is a locale literal); the pronoun printed in F2 is `initial[key]`, never a lowercase chip capitalised by code.
