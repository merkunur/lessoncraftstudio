## 2. Concept & creative hook
**Inchie the inchworm is the garden's measurer.** Inchie can't stretch — so Inchie calls a family of IDENTICAL helper-worms who **lie down nose-to-tail** along an object. The length = "how many helpers it took."
- **THE WORM IS THE UNIT (both designers' winning insight):** the helpers are visibly identical siblings → the **same-size pillar is the fiction itself** (you literally cannot place a bigger helper in a normal row). Nose-to-tail = no gaps ("a helper could fall in the gap — drafty!"); no piling ("two helpers sharing a spot is rude — and we'd count one twice").
- **FINE INTEGER SUB-UNIT LATTICE (the web expert's central solve — binding):** the rail snaps a helper's left edge to the nearest **lattice step (U=8 per unit)** — NEVER to a neighbor's edge. Lattice-snap gives a 6-year-old a forgiving drop target; **edge-snap is BANNED** (it would do the abutment for them = dead standard). So **every wrong state stays distinct, visible, representable, and the CHILD's to fix:** a 1-step gap is a ~5px sliver (gap), overlap shows a darkened seam, the row can overshoot (overhang) or fall short, or start off the left notch (misaligned-start). Abutment is exact **integer equality** (`pos[i+1] === pos[i]+8`) — no physics, no float epsilon.
- **THE COUNT IS AN ENACTED COUNT, NOT A GUESS (the critic's F1 — the headline):** after a valid gapless span, the child **taps each helper once to count it** — each tap bumps a visible tally + Inchie says "one… two… three…" (one-to-one correspondence, the actual hard Grade-1 skill). NO ruler, NO scale, NO live count ever rendered. **Layout-validity is acknowledged FIRST** (Inchie: "all snug, no holes!" — warm, non-advancing), THEN the count is its own act. A wrong count → Inchie **re-counts WITH the child** (each helper lights 1..N) and asks again — never a penalty, never a free re-roll (brute-tapping now triggers a full guided count, strictly slower than just counting, and teaches the skill on the way).
- **NO RULER, EVER (the pedagogy wall):** length is the count of helpers the child laid, never a number at the endpoint. (That's the sibling Ruler Lab / 2.MD.A.1.)
- **THE PAYOFF:** valid span + correct enacted count → a flower blooms in Inchie's garden patch, Inchie claps (`ctx.speak`), auto-advance (`ctx.correct()`). Wrong placement → no red; the gap/overlap shows honestly; the child nudges to fix. Helpers start UNPLACED in a "more helpers waiting" queue (supply > L).
- **Anti-generic statement:** NOT count-the-cubes-with-a-worm — (a) units start unplaced + the child produces every one (no count-the-pre-placed); (b) no slots + fine lattice (no slot-drop; gaps representable); (c) no scale/ticks/live-count (no read-the-number); (d) identical-helper fiction + width-check (no mixed-unit); (e) **the enacted tap-to-count + guided-recount + layout-ack-first make "length IS the count" load-bearing** (the critic's deepest catch — a brute-tapper is structurally caught); (f) the gate proves count-the-pre-placed + slot-drop + read-the-number + mixed-unit + gap/overlap/overhang/short/misaligned + **brute-tap-count + pick-the-neatest-row** solvers ALL fail while the lay-and-enumerate oracle passes.

## 3. Core loop & the 7 genuinely-distinct cognitions
**Loop (`stage`: lay → validate → enumerate):** Inchie shows an object (left notch = the start) → the child drags identical helpers from the queue onto the rail (snap-to-lattice; gaps/overlaps stay visible) → nudges to abut → when the span is gapless+exact, Inchie **acknowledges the layout** (warm, non-advancing) → the child **taps each helper to count it** (enacted; Inchie counts along) → correct count → flower blooms → `ctx.correct()`. **No timer/score/streak/countdown/fail/attempts/"X of Y".** Wrong placement → honest gap/overlap render + warm nudge; wrong count → guided re-count WITH the child; per-pass order-only reshuffle.

**The 7 pedagogy-locked cognitions (each a different reasoning ACT — clears ≥7 on cognition alone; objects are surface dressing, NOT the ≥7 backbone). Each round carries a `cog`:**
| # | Cognition (`cog`) | The child's act | Why genuinely distinct |
|---|---|---|---|
| 1 ★ | **lay-to-span** (`span`) | lay helpers end-to-end from the left notch across the object, then enumerate | the constructive iteration itself + length=count |
| 2 ★ | **close-the-gaps** (`gaps` — misconception: gap = uncounted space) | a pre-placed row with a gap; abut it, then re-count | "the empty bit isn't a helper — it can't be counted" |
| 3 ★ | **fix-the-overlaps** (`overlaps` — misconception: overlap = double-counting) | a pre-placed overlapping row; separate it, then re-count | "two helpers share a spot — we'd count one twice" (OPPOSITE correction to #2 + a different named misconception) |
| 4 ★ | **same-size-only** (`samesize`) | the queue offers a bigger/smaller helper; a mixed row is REFUSED ("only the same helpers, or it's not fair") | unit uniformity as the child's judgment (tested by refusal AND construction) |
| 5 ★ | **start-at-the-end** (`start`) | object offset; the first helper must begin exactly at the left notch | end-anchoring / origin (misaligned-start is a rejected state) |
| 6 ★ | **is-it-valid?** (`judge`) | shown 2-3 finished rows, tap the correctly-measured one | evaluate vs produce — length=count-not-endpoint confronted head-on |
| 7 ★ | **smaller-unit-bigger-count** (`inverse` — NON-graded discovery) | measure the SAME object with normal then smaller helpers; notice smaller unit → bigger count | unit-size↔count relationship (the deepest 1.MD insight); observational, NO verdict |
- **Honest framing (pedagogy + critic F4):** **7 genuinely-distinct cognitions** — #2 and #3 stay DISTINCT by NAMED misconception (gap=uncounted / overlap=double-count) + OPPOSITE corrections, NOT a re-skin; collapsing them would drop below 7 (the critic's flag). **Estimate-then-iterate DROPPED** (graded estimation barely in-grade); **"predict which needs more" DROPPED** (object-comparison = drifts to 1.MD.A.1). #7 is **non-graded** (Fork C1: advances via neutral `ctx.advance()`, never a right/wrong verdict; strictly observational — Inchie NAMES the two counts, the child never RELATES them as a ratio = stays out of 2.MD.A.2; the small helper is flagged non-standard so it can't pollute the graded unit-size).
- **§A.13.60 ≥7 distinct-to-the-child experiences:** met on **cognition alone** (the 7 acts); object/unit variety (pencil-with-cubes, ribbon-with-clips, leaf-with-helpers, varied L ∈ {3,5,7,8}, varied unit size) is FRESHNESS layered on top, never the backbone (avoids the reskin trap — the critic's F3: vary L AND unit size so the child never learns "pencils are always 5"). Order-only reshuffle + §20.2 per-session Fisher-Yates.
- **Free slice = lay-to-span + close-the-gaps + is-it-valid?** — proves iteration, the no-gaps pillar, and the judge-the-pillars act; the count-the-pre-placed/slot-drop/read-the-number/mixed-unit/brute-tap-count solvers all fail.

## 5. Pedagogy
- **1.MD.A.2 instantiation:** the child lays identical helpers end-to-end (owning gaps/overlaps/same-size/start), then ENUMERATES them one-to-one to claim the length. Both halves — the iteration AND "length = count" — are the child's acts.
- **THE KEYSTONE RULES (pedagogy + critic):** (i) **PLACE-AND-VALIDATE core verb** (the engine is a truthful mirror, never a corrector). (ii) **length = count of units, NEVER an endpoint number** (the wall against 2.MD.A.1). (iii) **gaps/overlaps are REACHABLE + the child's to fix** (forgiving lattice placement, no auto-snap-abut). (iv) **the count is ENACTED (tap-each-unit) with guided-recount-on-wrong** — NOT a free numeral-guess (the critic's F1). (v) **whole-units-only is a GENERATION INVARIANT** (object length = exact multiple of unit; the inverse round both units divide evenly — the fractions-core "exact divisions only" precedent). (vi) **same-size tested by refusal AND construction**. (vii) **no ruler/scale/standard-units/endpoint-number** (HARD WALL).
- **§20.8 demonstrate-don't-touch (the critic's headline):** as a free-numeral-chooser design it TOUCHED 1.MD.A.2 (a child brute-taps the count, skipping enumeration — the half that's hard at Grade 1). As an enacted-tap-count + layout-ack-first + guided-recount design it DIRECTLY INSTANTIATES the standard (laying AND enumerating are both the only path). The line is exactly: the count must be ENACTED, not selected; and "a piece stayed" must carry no correctness. The gate (brute-tap-count + count-the-pre-placed + slot-drop + read-the-number + mixed-unit + gap/overlap/overhang/short/misaligned all FAIL; the lay-and-enumerate oracle PASSES) is the machine-checked proof.
- **also_teaches: NONE** (no K.CC laundering — tap-to-count is the MECHANISM, not an assessed standard; one-line comment at the alignment site so no future editor adds K.CC.B.5). `1.MD.A.1` only if a compare-OBJECTS round ships (it doesn't). **Hard NO:** `2.MD.A.1` (ruler — sibling), `2.MD.A.2` (two-unit relate), `2.MD.A.4` (length difference), fractional/partial units.
- **Grade fit + object/unit set:** objects = familiar horizontal things (pencil, crayon, ribbon, leaf, carrot, worm-friend); units = NON-STANDARD (helper-worm / cube / paper-clip); **whole-number counts L ∈ {3..8}, capped ≤6 on small screens** (the critic's F8). Whole-units-only for ALL graded rounds (the standard demands it); the meta-pattern is defeated by L + unit-size VARIETY, never by fractional objects (the "doesn't-fit-evenly, closest-whole" experience is logged OUT-of-grade → a future Grade-2 measurement game). Ladder: lay-to-span (short) → gaps/overlaps → same-size → start → judge → inverse-discovery.
- **No-shame:** the blooming garden is the intrinsic reward; errors are Inchie noticing + the child fixing; wrong counts trigger a guided re-count, never a red-X; Inchie never fails the child.

## 6. Interaction & UX
- **Runtime: lay → validate → enumerate.** `lay-units-core.js` holds the round `{ id, cog, objectNoun, objectLengthUnits (L), unitSize (U=8), unitKind, trackSteps ((L+margin)*8), supplyCount (>L), legendOfPillars }` + `placeUnit/nudge/removeUnit` + `evaluate(round,state)` → distinct status (the web expert's predicate: sort by pos → mixed-size? → start≠0 misaligned? → walk chain: delta>8 gap / delta<8 overlap → span<L*8 short / >L*8 overhang → reportedCount==null placed-ok-awaiting-count → reportedCount≠units.length wrong-count → else correct). **The answer = `f(lay identical units gaplessly + enumerate them)`, never `f(count pre-placed)` / `f(read a scale)` / `f(fill N slots)` / `f(tap numbers till accepted)`.**
- **State separation (anti-cheat):** `snapshot()` exposes `{ cog, object (no baked length-number), rail (continuous, NO slots), queue (unplaced helpers + "more waiting" badge), placedHelpers (with visible gap/overlap/overhang renders), startNotch (visual-only, pointer-events:none), countTally (the child's enacted taps) }` — **NO ruler, NO ticks, NO live count, NO scale.** `facts()` exposes per-round `{ roundStartsUnplaced (===true), supplyExceedsLength (===true), noSlotArray (===true), latticeIsSubunit (U>=4), oneStepGapRepresentable (===true), noScaleOrTicks (===true), countIsEnumeratedNotSelected (===true), wrongCountTriggersRecount (===true), mixedWidthRejected (===true), startNotchIsVisualOnly (===true), wholeUnitsOnly (===true), judgeFoilsIncludeNeatWrong (===true for cog=judge), inverseRoundHasNoVerdict (===true for cog=inverse), inverseRoundNonStandardUnits (===true for cog=inverse) }`.
- **Place + nudge + count:** drag a helper from the queue (pointer-capture; one path mouse/touch/pen) → snap to nearest lattice step on release; ±1-step **nudge buttons** = the precision affordance (drag coarse, nudge exact). The count is **tap-each-helper** (each tap → tally+1, Inchie says the number); the claim = the final tally (numeral strip ELIMINATED on small screens — the critic's F8). NO Check button — `evaluate` fires on each commit; layout-ack first, then count.
- **Judge round (#6 — the critic's F2):** every item shows the correct row + **≥2 "looks-neat-but-wrong" foils** drawn from {gapless-but-overhang, gapless-but-mixed-size, gapless-but-doesn't-start-at-the-end}; all rows within 1 lattice step of equal visual length (so length-eyeballing can't shortcut); answer position rotates. - **Mobile @280px (the critic's F8):** single column — prompt (DOM `<text>`) → SVG stage (object + rail + placed helpers; `viewBox` auto-scales, never overflows) → ◀ ▶ nudge (≥44px) → **queue = a single "next helper" + "more waiting" badge** (one-unit footprint regardless of supplyCount; no spread tray to overflow) → garden-patch vessel (thin).
