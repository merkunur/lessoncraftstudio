## Recognition-scope discipline (load-bearing)
2.G.A.3 is claimed via its **recognition clause** ("recognize that equal shares need not have the same shape") on the 0-core E2 engine; the active-partition clause (clause 1) is deferred to #3. EVERY locale: the child *recognizes* (recognition verb), never divides. Each #2 prose carries an explicit **guardrail** ("the child does NOT divide the shape, but recognizes…"); 0 active-partition-verb at the child. The prompt's count-phrase uses cardinal + "equal parts" (NOT the fraction noun); the fraction nouns (halves/thirds/fourths) are PROSE-only.

## The #2 two-sentence anchor+comparison construction + per-locale grammar-trap taxonomy
Construction: **anchor declarative** ("This shape is split into N equal parts.") + **instruction** ("Tap another shape that is ALSO split into N equal parts."). Reuses each locale's #1 share-verb. Per-locale traps validated by a native ensemble (linguist + K-3 educator + B2C marketing) per CLAUDE.md §A.13.48/§A.13.56:
- **FI** partitive object + "myös" placement · **DE** "auch" before the predicate ("die auch in N … geteilt ist") · **FR** "aussi" after the conjugated verb + feminine "partagée" · **ES** "también" before the verb phrase + forma(prompt)/figura(prose) + watch the #1 "comparar" register-bleed · **IT** "anche" between è and divisa + **un'altra** elision · **PT(-BR)** "Toque em outra" (em+indefinite, no contraction) + feminine "duas" · **NL** V2 anchor / verb-final relative ("verdeeld is") + "ook" scope + button "Controleer" (not "Nakijken") · **SV** BIFF subordinate order ("som också är delad") + §20.10 leak did-NOT-recur + "lika stora delar" content · **DA** "der" relativizer+comma + single-definiteness "Denne form" + lowercase "ikke" · **NO** "som" relativizer no-comma + double-definiteness "Denne formen".

## §20.10 framework-name + content-vs-discovery (per-locale)
Non-EN prose cites the **national framework NAME** only (Lehrplan/programmes officiels/Currículo LOMLOE/Indicazioni nazionali/BNCC/SLO-kerndoelen/Lgr22/Fælles Mål/LK20/OPS 2014), never "Common Core" or the CCSS code in prose. The CCSS code (2.G.A.3) is retained ONLY as the JSON-LD `educationalAlignment.targetName` + teacher chip + `/standards/<code>` hub (machine anchor; ~11 on-page occurrences, matches across locales). **Content-vs-discovery split:** the educator's pedagogical equal-parts term lives in prose+prompt; the shorter SEO term lives in title/intro/slug — **normalized to the discovery term across the cluster** (e.g. SV "lika delar"/DA "lige dele"/NO "like deler" in slug+title, while prose uses "lika/lige/like store delar/dele/deler"); the size signal is carried by the title phrase ("samme størrelse, …"), not duplicated into the slug. hreflang chain = 12 (11 locales + x-default; pt→pt-BR on BOTH head `<link>` and the body anchor strip via `getHreflangCode`, the `fda70f19` fix).
