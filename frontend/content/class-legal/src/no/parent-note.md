# Brev til foresatte

> **Til læreren (denne boksen er ikke en del av brevet):** Bruk brevet bare hvis skolen din tillater at du bruker dette verktøyet. Det informerer de foresatte; det erstatter ikke skolens egen personverninformasjon. Skriv det ut eller send det; fyll ut linjene i hakeparentes. Én side, ingen juridiske ord.

**Kjære foresatte**

I klassen øver vi noen ganger på en skjerm med arbeidsark fra LessonCraftStudio. Jeg bruker en klasselenke til dette, slik at jeg kan se hvilke oppgaver hvert barn har forstått, og hvem som trenger å øve mer.

**Hva barnet deres gjør.** Barnet deres åpner klassens side, trykker på nummeret sitt og dyrebildet sitt og gjør arbeidsarket. Det er ingen konto, ikke noe passord og ingenting å installere.

**Hva som lagres.**
- Ikke noe navn: bare et nummer og et dyrebilde. Listen over hvem som har hvilket nummer, har jeg selv.
- For hvert arbeidsark: hvilket arbeidsark det var, når det ble åpnet, hvor mange svar som var riktige og hvilke, hvor mange ganger svarene ble sjekket, og om siden ble gjort ferdig.

**Hva som ikke lagres.** Ikke etternavn, ikke fødselsdato, ikke foto, ikke adresse, ikke e-postadresse. Nettstedet registrerer ikke hva barnet deres skriver, og det er ingen tidtaker.

**Hvem som ser det.** Bare jeg kan se resultatene. Andre foresatte og andre lærere kan ikke det. På klassens felles side kan et barn se hvilke arbeidsark en annen plass har gjort ferdig, men aldri hvor mange svar som var riktige. Barnet deres ser ingen poengsum, ingen rangering og ingen tidtaker.

**Hva det brukes til.** Bare til undervisningen min. Det brukes ikke til reklame og selges ikke. Det lagres for [navnet på skolen] på en server i Finland av den som driver nettstedet, som bare får bruke det til dette.

**Hvor lenge det lagres.** Jeg kan når som helst slette resultatene til barnet deres. Hvert resultat slettes automatisk senest etter 14 måneder[, og ved slutten av skoleåret sletter jeg klassen].

**Spørsmålene deres.** Hvis dere vil se hva som er lagret om barnet deres, få det rettet eller slettet, eller hvis dere ikke vil at resultatene til barnet deres skal lagres, si fra til meg. [Kontakt.]
