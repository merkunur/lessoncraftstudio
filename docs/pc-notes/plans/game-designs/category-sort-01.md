## 2. Concept & creative hook
**Mim** is a soft, sleepy, half-forgetful cloud-creature who keeps a row of **woven Memory Baskets** — one for each kind of thing Mim loves (a Pet basket with a little paw-print, a Food basket with a bitten-apple mark, a Things-You-Ride basket with a wheel). Mim's basket of treasures got tipped over in a sneeze and now a jumble of objects is scattered everywhere — and Mim, being a bit forgetful, **can't quite remember what goes where.** The child helps Mim **put each thing back in the basket where it BELONGS** — and as each object lands, Mim's eyes light up: *"Oh YES — a dog is a PET! I remember now!"* The hook: **you're helping a gentle, forgetful friend remember what things ARE** — and every time you do, Mim remembers a little more of the world.
- **THE SORT (the L.K.5.A act — category-FORMATION):** a few mixed objects sit in a "spill" tray; 3+ **labeled category baskets** wait below (Pets / Foods / Things-You-Ride — each with a concept-icon + a spoken label). The child **drags each object into the basket of the category it belongs to.** Correct → Mim brightens + speaks the CONCEPT ("a dog is a PET!"); the object nestles in. The child has CONSTRUCTED the partition — the literal "sort to gain a sense of the concept."
- **WHY CATEGORY KNOWLEDGE IS LOAD-BEARING (not appearance — the critic's flip, rigorous):** (A) the Pet basket's objects look NOTHING alike (furry dog, scaly fish, feathery bird) → you can't group by appearance; (B) a red apple (Food) and a red fire-truck (Vehicle) SHARE a color → sorting by color sends the apple to the wrong basket → only knowing "an apple is a FOOD" works; (C) the basket holds a DIFFERENT object each round (a Pet is a dog now, a fish next) → you can't memorize "the dog goes there," you must know the CONCEPT.
- **THE NON-LEAKING WRONG-DROP (no-shame + non-cheatable):** drop the apple in the Vehicle basket → Mim tilts their head, *"hmm, that doesn't feel like it belongs there"* — the apple **gently floats back to the spill tray** (it does NOT reveal the right basket, does NOT dim a basket, does NOT auto-correct). No buzzer, shame impossible (Mim is forgetful about ITSELF, you're its kind helper). The child re-reasons. (3+ baskets → no coin-flip; the wrong-drop gives no information → category knowledge is the only path.)
- **THE REMEMBER PAYOFF (the concept spoken):** each correct drop → Mim speaks the superordinate CONCEPT ("an apple is a FOOD!" / "a fish is a PET!" via TTS), the basket glows, the object settles with its concept-mark. When the spill is sorted, **Mim does a happy remembering-shimmy** + the baskets each do a little "we're complete!" bounce — and the sorted objects are added to **Mim's Memory Garden** (a growing keepsake of remembered things, `GameCollection`).
- **Anti-generic statement:** NOT a sort-by-color toy with a creature — (a) within-category visual diversity + cross-category visual confound make CONCEPT knowledge load-bearing (a color-sorter FAILS, gate-proven); (b) category-generalization (different objects per round) defeats instance-memorization → the gate observes category cognition directly (sorting IS the concept act); (c) the concept is SPOKEN on each correct drop (the L.K.5.A reinforcement); (d) the warm forgetful-friend frame makes shame impossible; (e) a board ships only if a **visual-feature-sorter** (by color/shape, no concept) FAILS while a **category-sorter** passes (§8).

## 3. Core loop & the honest sort-cognitions
**Loop (`stage`: spill → sort → remember):** Mim's spill tray shows a few mixed objects + 3+ labeled category baskets → the child drags each object into its category basket → correct drop → Mim speaks the concept + the object nestles; wrong drop → non-leaking float-back → repeat until the spill is sorted → Mim's remember-shimmy + the Memory Garden grows → `ctx.correct()`. **No fail, no timer, no score, no Check button, NO COUNTING.** A wrong drop → Mim "that doesn't feel like it belongs" (the object returns, the right basket never revealed); the child re-reasons. First-attempt-correct is the internal signal (never shown).

**The genuine sort-COGNITIONS (the critic's honest de-padding — NOT category-TYPE variants). "sort Pets-vs-Foods round A vs round B" with different objects = the SAME operation; a different category-CONCEPT set is legitimate VOCABULARY CONTENT (the child learns a new concept), NOT a §A.13.60 dodge — but the sort OPERATION variety is the small honest set below. Each round carries a `cog`:**
| # | Cognition (`cog`) | The child's act | Why distinct |
|---|---|---|---|
| 1 ★ | **Sort to the named concept** (`sort` — the core) | drag each object into its labeled superordinate basket | the L.K.5.A category-formation act; the spine |
| 2 ★ | **Resist the visual confound** (`confound` — sort by concept despite a misleading shared feature) | a red apple [Food] + a red fire-truck [Vehicle] → sort by CONCEPT, not color | resist the perceptual lure — proves the concept is load-bearing, not appearance |
| 3 ★ | **Group the visually-diverse** (`diverse` — see past visual difference to the concept) | a furry dog + a scaly fish + a feathery bird → all into the Pet basket | the superordinate concept over visual dissimilarity (the inverse of #2) |
| 4 ★ | **Find the odd-one-out** (`odd` — exclusion: which doesn't belong) | a basket of Pets + one Vehicle snuck in → pull out the one that doesn't belong | category EXCLUSION (negative membership) — a distinct judgment from inclusion-sorting |
- **Honest framing (the critic's de-padding + §A.13.60):** **4 genuine sort-cognitions** (sort / resist-confound / group-diverse / odd-one-out). The **number of baskets** (2 vs 3+) is a difficulty knob (NOT a cognition; 3+ required for the anti-cheat). The **category-CONCEPT sets** (Pets/Foods/Vehicles/Clothes/Shapes) are legitimate VOCABULARY CONTENT — different concepts the child must KNOW — so different category-sets ARE distinct-to-the-child for a VOCAB game (knowing pets ≠ knowing vehicles), unlike a number game where the number is incidental; but they ride WITHIN the 4 cognitions, not counted as separate cognitions. The **≥7 distinct ROUNDS** (DATA requirement) = the 4 cognitions × the category-concept sets + the confound/diverse/odd configs — honestly, the number-skin/pure-reskin blocklist enforced. Order-only reshuffle.
- **Free slice = sort (1) + resist-confound (2) + group-diverse (3)** — the concept-load-bearing core (a color-sorter fails on 2+3 immediately).

## 4. Win-states & juice (no competition)
No timer/score/streak/countdown/**fail-state**/attempts-counter/"X of Y"/**NO COUNTING** (the K.MD.B.3-differentiator — never count a basket). **THE REMEMBER (signature — the concept spoken):** each correct drop → Mim's eyes light + Mim speaks the superordinate CONCEPT ("a dog is a PET!" / "an apple is a FOOD!" via `_NUMBER_WORD_HELPERS`-free TTS), the basket glows warm, the object nestles with its concept-mark; the spill thins. **THE FULL-SORT payoff:** spill sorted → Mim's happy remember-shimmy + each basket's "complete!" bounce + the sorted objects drift into **Mim's Memory Garden** (`GameCollection` — a growing row of remembered things, the keepsake). **Non-numeric vessel = the Memory Garden filling** (remembered objects, NOT a count, NOT "5/8") + Mim visibly remembering more (brighter, more awake). **Negative signal = a NON-LEAKING float-back ONLY:** wrong drop → "hmm, that doesn't belong there" (the object returns to the spill; the right basket is NEVER revealed, no dimming, no auto-correct, no buzzer); the child re-reasons. Mim is forgetful about ITSELF, never disappointed in the child. **`ctx.wrong()` is a soft "not there."** `ctx.correct()` on the full sort → auto-advance. Full-pass keepsake = the Memory Garden → cross-game `GameCollection`. CSS/SVG/WebAudio; reduced-motion (instant nestle/float-back); mute-safe (the basket-glow + the nestled object carry it; the spoken concept has a TEXT label on the basket).

- **No-shame + §20.8 demonstrate-don't-touch:** the struck riddle only TOUCHED categories (bypassable); the SORT DIRECTLY instantiates category-formation — the gate (a visual-feature-sorter fails; a category-sorter passes; generalization across rounds) is the structural proof. ## 6. Interaction & UX
- **Runtime: drag-to-bin (the sort).** `category-sort-core.js` holds `{ cog, spill:[{noun, theme, category}], baskets:[{categoryId, label}], placed:{} }` + a HAND-AUTHORED `OBJECT_CATEGORY` map (noun → superordinate category; the round-builder enforces within-diverse + cross-confound). Mutators: `drop(noun, basketId)` → `{correct: OBJECT_CATEGORY[noun]===basketId}` (reads the CATEGORY, not a visible attribute); correct → `placed[noun]=basketId` + speak the concept; wrong → non-leaking return (no state leak about the right basket). `solved = every spill object placed in its correct category`. **No counting API; the categories are the bin labels (stated).**
- **State separation (anti-cheat):** `snapshot()` exposes `{ cog, spill, baskets, placed }`; `facts()` exposes per-round `{ withinCategoryVisualDiverse (===true — a category's objects share no single visible feature), crossCategoryVisualConfound (===true — objects across categories share a feature), basketsCount (≥3), wrongDropLeaksRightBin (===false), categoryGeneralizes (===true — a category holds different objects across rounds), noCountingSurface (===true), firstAttemptCorrect }` for the gate.
- **The drag interaction:** drag an object (a `<g>`/`<img>` from the image library, ≥44px) from the spill into a basket (a ≥44px drop-zone with a concept-icon + a TEXT label + a TTS-on-tap). Pointer + keyboard (focus an object, arrow to a basket, Enter drops). The concept is SPOKEN + LABELED on each basket (so a pre-reader hears + a deaf child reads the category).
- **Mobile @280px:** vertical stack — Mim + the spill tray (3-4 objects) top, the 3+ category baskets below (a row or 2×2 grid; each ≥44px with a legible concept-icon + label). The objects are VISUALLY DISTINCT (the within-diversity design HELPS legibility here — unlike the deduce version's look-alike visible-twins which hurt it; a key win of the flip). `audit-game-mobile.js` 280-768 empty+filled (3-4 spill objects + 3+ baskets; ≥44px drag + drop targets; legible object pictures + basket labels; no overflow/clip/overlap).
- **Accessibility:** TTS speaks the basket labels + the concept on a correct drop ("a dog is a PET!"); `ctx.announce()` mirrors the drop result; **keyboard path = objects + baskets are focusable; arrow + Enter sorts** (NO drag required); ≥44px; the basket categories are TEXT labels (deaf/muted-safe — never audio-only); reduced-motion (instant nestle); mute-safe (the basket-glow + the label carry it); not color-only (the basket has a concept-icon + text, never a bare color). **TTS is concept-words, per-locale authored.**
