## 2 The base page

**Concept.** "Guess, then splash" (B's apparatus on the pedagogy's predict-test-record table). Six rows; each row = an object picture tile, a GUESS tank (thought-bubble glyph) and a TEST tank (splash glyph), then a "Surprise?" star.
