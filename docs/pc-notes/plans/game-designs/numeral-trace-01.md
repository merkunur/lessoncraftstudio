## 2. Concept & creative hook
**Quack Creek** at dawn. Mama Duck stands on the far bank and **calls the morning roll**: *"I need FIVE ducklings for the lily-pad swim!"* On the near bank bobs a big **raft of sleepy ducklings** — more than she asked for. The child's job: **send Mama exactly the number she called** — count them out one by one across the water — and then **sign the roll by writing that number** in the soft creek-mud, so Mama knows the count is true. The agency hook: **you're Mama's roll-caller — you send exactly the right number home, and you write each roll yourself.**
- **THE COUNT-OUT SPINE (the distinct B.5 reverse — Game 20 never does this):** Mama calls a number; the child **taps ducklings out of the raft one at a time** — each tapped duckling paddles across to Mama (one-to-one production). **There is NO game reaction as they go** — no seal, no Mama-nod, no audio-shift at the "right" duck — so the child cannot stop on a signal; *they must decide for themselves when they've sent enough.* The raft holds MORE than the target (abundance), so "send everything" fails — the child must STOP at N. This is "given a number, count out that many" made physical.
- **THE FORMATION AS THE COMMIT (the critic's binding fix — the trace earns its slot):** when the child believes they've sent the right number, they **commit by forming the numeral in the mud** — tracing its strokes in order (lenient: ordered directional checkpoints, wobble fine, precision NOT graded). **Forming the numeral IS the "done" — there is no other commit button.** The mud-numeral is the child's *declaration of the count they produced.* The roll seals IFF the set they sent === the number on Mama's call (checked only NOW, at the commit — never during the count-out).
- **Why this is genuinely load-bearing + non-cheatable:** (a) form-the-numeral-without-sending → the set (0/wrong) ≠ the call → no seal (the SET production is load-bearing, not the trace); (b) no reaction during count-out → no stop-on-reaction cheat (the child's count is the only stop-signal); (c) vary-N every round + N≥6 on count-out → can't subitize, can't memorize a sequence; (d) the trace requires ordered stroke traversal → no scribble.
- **THE 0-CASE (required, hardened):** sometimes Mama calls *"This morning I need… NONE — let them all sleep!"* The child sends **zero** ducklings (sends none) → commits by forming **"0"** in the mud (a single closed loop; a soft ripple crosses the still water — "zero ducklings, and you wrote the zero — the whole raft sleeps in"). Same mechanic; the cardinal of absence; interleaved unpredictably; leading-zero guard ("0" valid only alone).
- **THE ROLL BOOK (the keepsake + the non-numeric vessel):** every sealed roll presses the child's own **wobbly hand-formed numeral into the creek-mud**, kept in a growing **mud-bank roll-book** (`GameCollection`) — *their* handwriting, the wobble celebrated (no "neatness" judgment). The bank fills with duck-families settling in (the non-numeric progress — more broods home, NOT "5 of 9").
- **Anti-generic statement:** NOT a trace-the-number worksheet + a duck — (a) the SPINE is set PRODUCTION (count out exactly N), the reverse B.5 Game 20 can't do; (b) the trace is the count-out's COMMIT channel (load-bearing, gate-proven non-decorative), not an epilogue; (c) NO reaction at the commit boundary (the stop-on-reaction cheat structurally dead); (d) vary-N + N≥6 kill subitize/memorize; (e) the 0-case; (f) a board ships only if a **form-without-count-out solver**, a **stop-on-reaction solver**, and a **scribble solver** ALL fail while a **count-out→form solver** passes, AND the cardinality probe holds (§8).

## 3. Core loop & the ≥7 distinct experiences
**Loop (`stage`: call → count-out → sign):** Mama calls a number (spoken + a numeral card) → the child **counts ducklings out of the raft one at a time** (each paddles to Mama; NO reaction; the child decides when to stop) → the child **signs the roll** by forming the numeral in the mud (ordered lenient strokes — the COMMIT) → the roll seals IFF set===call → the brood settles, repeat until the roll-book page is full → `ctx.correct()`. **No fail, no timer, no score, no Check button.** A mismatch (set ≠ formed numeral) → **non-directional no-shame redirect:** the sent ducklings paddle back to a fresh raft, Mama: *"Let's call that roll again"* — re-do from scratch, **NO signal whether they were high, low, or by how much** (per the critic: redirects must be non-informative about the quantity). The assessment signal = **first-attempt-correct** (internal, never shown).

**The ≥7 distinct experiences — re-derived as genuine COUNTING acts (the critic CUT the padding: count-on = Grade 1; pen-lift = non-math handwriting; miscount-recovery = error-handling; the subitize half = a leak). distinct = a different COUNTING reasoning, NOT a bigger number / a stroke-variation / a different duckling.** Each carries a declared **`act_type`** (gate-keyed with a blocklist, §8):
| # | Experience (the distinct COUNTING act, `act_type`) | Render / act | Why it's distinct & instantiates B.5 |
|---|---|---|---|
| 1 ★ | **Count-out-that-many** (`count-out` — the SPINE; produce a set of exactly N from an abundant raft, commit by forming N) | Mama calls N → send exactly N (no reaction) → form N | the REVERSE B.5 (set production from a target) — Game 20 never does this; the spine |
| 2 ★ | **Count-out with a distractor raft** (`count-out-distract` — stop at N amid abundance + a 2nd kind) | the raft has 2 duckling kinds / many more than N → send exactly N of the called kind | selective count-out (stop-at-N under abundance + attribute) — a distinct control demand |
| 3 ★ | **Count-out to MATCH a reference group** (`match-set` — target given as a QUANTITY, not a numeral) | Mama shows a GROUP of N (e.g. 6 lily-pads) → send a matching set of exactly that many → form the numeral | one-to-one between two SETS (the cardinality "second-vessel" probe as an experience) — distinct reasoning |
| 4 ★ | **The 0-case** (`zero` — produce the empty set; the cardinal of absence) | Mama calls "none" → send zero → form "0" | producing/representing absence — the standard's named special case; conceptually distinct |
| 5 ★ | **Count-a-set → sign** (`count-set` — the FORWARD minority, de-emphasized) | a brood already at Mama → count how-many came → form the numeral (the guide absent until the count completes) | count-to-answer-how-many (B.5 forward); a MINORITY (not a co-equal lane — the redundant-with-Game-20 half, kept small + N≥6 so no subitize) |
| 6 ★ | **Running-total / "more keep arriving"** (`running-total` — maintain a count as the set grows) | ducklings arrive a few at a time → maintain a running count → answer the final how-many → form it | maintaining a running cardinal across additions (the cardinality the gate must prove) — distinct |
| 7 ★ | **Count-out under SCATTER** (`scatter-out` — the raft spread across the pond; track 1:1 across space) | the raft is scattered, not clustered → send exactly N, tracking which you've already sent | one-to-one under spatial scatter (anti-double-count) — distinct from a tidy raft |

- **Honest framing (the §A.13.60 fix + the critic's blocklist):** **7 genuinely-distinct COUNTING acts**, spine-weighted toward count-out (1/2/3/7 are count-out variants; 4 zero; 5 the forward minority; 6 running-total). The variety gate keys on `act_type` with a **BLOCKLIST**: "differs only in number magnitude" (teens), "differs only in stroke/pen-lift" (handwriting variation), "differs only in modality," and "count-on" (Grade 1) do NOT count as a distinct B.5 act. Teens (two-digit formation) ride as an optional-advanced magnitude knob WITHIN any act, never a separate experience. Order-only reshuffle.
- **Free slice = count-out (1) + the 0-case (4) + match-set (3)** — proves set-production + the absence-cardinal + the two-set cardinality probe.

## 4. Win-states & juice (no competition)
No timer/score/streak/countdown/**fail-state**/attempts-counter/"X of Y". **THE ROLL CALL (signature):** Mama calls a number; the child sends ducklings across the water one by one — **silent, no reaction** — each paddling with a soft wake; when the child signs the roll, the mud-numeral inks under their finger (the COMMIT) and — only now — IF set===call, Mama gathers her brood with a warm double-quack and the formed numeral presses into the bank. **THE 0-CASE reveal:** call "none" → send zero → form "0" → a single ripple crosses the still water, the raft sleeps in ("zero — and you wrote it"). **Non-numeric vessel = the bank filling with settled broods** (`GameCollection` roll-book of the child's own hand-formed numerals) — each sealed roll a new family on the far bank; the page gilds when full; NO "5/9", no bar. **Negative signal = a NON-DIRECTIONAL re-do ONLY:** mismatch → the ducklings paddle back to a fresh raft + *"Let's call that roll again"* — **no high/low/by-how-much signal** (the critic's no-leak rule); a fresh count-out from scratch. The forward-minority stroke nudge (out-of-order stroke → the duckling paddles back to the last good checkpoint, "this way") is a STROKE-ORDER redirect on the non-math trace — no quantity information. Never a buzzer/removal. **`ctx.wrong()` is a soft "let's try again."** `ctx.correct()` fires on the FULL page → auto-advance. Full-pass keepsake = the gilded roll-book → cross-game `GameCollection`. CSS/SVG/WebAudio; reduced-motion (instant ink/settle); mute-safe (the visible paddle-across + the inked numeral carry it).

## 5. Pedagogy
- **K.CC.B.5 instantiation (both directions, REVERSE-led):** the child PRODUCES a set of exactly N (count out that many — the reverse half Game 20 omits) and answers how-many (the forward minority); the numeral formation is the child's COMMIT/declaration of the cardinal they produced. The kept mud-roll is the permanent record of *their* count + *their* hand.
- **THE KEYSTONE RULES (non-cheatability — the critic's fixes):** (i) **FORMATION IS THE COMMIT + NO REACTION DURING COUNT-OUT** — the child sends ducklings with zero game feedback; the only "done" is forming the numeral; the roll is checked ONLY at the commit → the stop-on-reaction cheat is structurally impossible (`reactionDuringCountOut===false`). (ii) **SET PRODUCTION IS LOAD-BEARING** — form-without-sending mints a set of 0/wrong ≠ the call → no seal; the trace alone cannot pass. (iii) **VARY-N + N≥6 ON COUNT-OUT/SCATTER** — kills subitizing (N≥6 forces real count-out) + memorization (N varies every round; no fixed sequence). (iv) **CARDINALITY PROBE** — the match-set experience (#3, produce a set equal to a shown GROUP) + the running-total (#6) prove the child HELD a cardinal, not just touched-each-once (the critic's "one-to-one ≠ counting" catch). (v) **FORWARD-MINORITY ANTI-CHEAT** — in #5, no numeral guide exists in the DOM until the count completes (`numeralPathPresent===false` while `countComplete===false`); a trace-without-count solver has nothing to trace. (vi) **NON-DIRECTIONAL REDIRECTS** — a mismatch reveals NO high/low/amount; just a fresh re-do (no answer-leak). (vii) **0-CASE via the SAME mechanic** (send zero → form "0"; leading-zero guard).
- **The trace earns its draw-trace slot (the critic's identity test):** the formation is NOT a decorative epilogue — it is the count-out's COMMIT channel (the child's declaration of the cardinal) + genuine numeral-handwriting practice (a real K skill: forming numbers, correct stroke order) + the keepsake. Lenient on precision (no-shame; immature fine-motor never penalized), STRICT on stroke order/direction (the formation's integrity) + on the count being load-bearing.
- **also_teaches (re-based to honesty per the pedagogy ruling):** keep **K.CC.A.3** (the count maps to its numeral — secondary, the forming-the-numeral touch); **DROP L.K.1.A** (alphabetic letters, not numerals — DRIFT) **+ RF.K.1.A** (text print-concepts, not a one-numeral trace — DRIFT).
- **Number ranges (pedagogy):** **0-9 core** (count-out N≥6 forces real one-to-one; the 0-case required); **10-20 teens optional-advanced** (two-digit formation — two stroke-paths left→right, e.g. "1" then "4"; counted via a tens-frame raft at ≥10 per the mobile rule; NOT place-value; never weighted; a magnitude knob WITHIN an act, blocklisted from the act-count). Page = 4-6 distinct, non-ascending calls, ≥1 zero.
- **Distinctness from Game 20 + the free numeral activity:** Game 20 = count → which numeral (symbolization). This = produce-a-set-to-a-target (the inverse) + the formation-as-commit. The free tile = SELECT/read a numeral. If the game could be completed without PRODUCING the set, it's redundant — REJECTED.
- **No-shame + §20.8 demonstrate-don't-touch:** a mismatch → a fresh non-directional re-do; the 0-roll is celebrated; the trace is the intrinsic reward (your own roll). The catalog "count → trace its numeral" TOUCHED counting while the trace carried everything (and duplicated Game 20); the count-out spine + the formation-as-commit ENACT B.5's set-production — the gate (form-without-count-out + stop-on-reaction + scribble solvers all fail; cardinality probe holds) is the structural proof.

## 6. Interaction & UX
- **Runtime: count-out + commit-by-formation (the two primitives).** `numeral-trace-core.js` holds `{ call:{n, kind?, target:'numeral'|'group'}, sent (the ordered list of ducklings sent this roll), stage, committed }` + a static **`GLYPHS`** table (per-digit ORDERED stroke-checkpoint paths in a normalized glyph box; per-locale variant paths for 1/4/7/9 — §8). Mutators: `sendDuck(id)` (count-out; appends to `sent`; **emits NO success/seal signal** — `reactionDuringCountOut===false` is an invariant), `traceStroke(points)` (lenient ordered-checkpoint scoring on the called numeral's glyph), `commit()` → seals IFF `sent.length === call.n` AND the formed numeral traversed its strokes in order. `numeralFor(n)` renders `String(n)` (leading-zero guard; teens two glyph boxes left→right). **No pre-rendered answer in the count-out lane; in the forward minority (#5) the glyph guide is injected ONLY after `countComplete`.**
- **State separation (anti-cheat):** `snapshot()` exposes `{ call, sentCount, stage, committed, sealed }`; `facts()` exposes per-roll `{ n, target, reactionDuringCountOut (===false), numeralPathPresent (#5: ===false pre-count-complete), strokeOrderOK, firstAttemptCorrect, nVariesPerRound, scatterMinN (≥6) }` for the gate.
- **The count-out interaction:** tap a duckling in the raft → it paddles to Mama (≥44px hit-halo; a visible wake; the sent duck leaves the raft so it can't be re-sent); **no counter, no reaction** — the child tracks their own count. The raft holds MORE than N (abundance → "send all" fails). **Commit = the child forms the numeral** (trace the mud-glyph's ordered strokes; ≥44px channel; restart-the-stroke anytime) — there is no separate Done button.
- **Teens (the tens-frame raft):** for calls 10-20 the raft arrives as a **tens-frame** (a full 10 + loose ones) so count-out stays tidy + countable at 280px; the commit forms the two-digit numeral (left→right).
- **Mobile @280px (truth-tested — sequential stages, the tens-frame-≥10 rule MANDATORY):** **sequential surfaces, NOT co-resident** — the **count-out surface** (the raft + Mama) and the **sign surface** (the mud + the glyph channel) are separate `stage`s, so the raft + the formation channel never compete. **Hard rule: any raft ≥10 ⇒ tens-frame (2 rows × ≤5)** — never a scattered 15-20 (the web designer's mandate; a scatter of 15-20 cannot pass at 280px). **Jostling/overlap is OUT at 280px** (the critic: overlap makes tap targets <36px + ambiguous) — the raft uses a non-overlapping flow/tidy layout; "deliberate scatter" (#7) is a SPREAD of non-overlapping ducks at ≥44px, not an overlap pile. `audit-game-mobile.js` 280-768 empty+filled (the count-out raft [tens-frame worst case] + the sign-stage glyph channel; ≥44px halos + lever; no overflow/clip/overlap; the two stages never co-resident).
- **Accessibility:** TTS speaks Mama's call + the running help (`_NUMBER_WORD_HELPERS` — "Mama needs five"); `ctx.announce()` mirrors the call, the sends, the seal; keyboard path = each duckling a button (Enter sends), the formation has a **tap-the-strokes-in-order fallback** (a non-fine-motor child taps numbered stroke affordances in order — same ordered invariant, no precise trace needed) so no child is blocked; ≥44px; reduced-motion (instant); mute-safe (the visible paddle-across + the inked numeral carry it); not color-only (the count + the numeral are real structure/text). **TTS of whole number-words is SAFE** (not the isolated-phoneme hazard of the literacy engines).
