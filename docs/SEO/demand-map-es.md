# Spanish/Mexican (es) demand map — subject×grade hubs (Execution Unit 3)

Source: native **Mexican-Spanish** ensemble (linguist/SEP + SEO/demand + K-3 educator/NEM), 2026-07-05. Operator-signed-off. Target = **Mexico** register (not Spain).

## Core demand facts
- **Head noun by intent:** `fichas` (dominant) · `actividades` (#1 for **preescolar**) · `ejercicios` (math/primaria) · `cuadernillo` (MX-distinctive) · `material` (teacher-facing). We lead: **"Ejercicios de"** (math/logic), **"Fichas de"** (español/ciencias/percepción), **"Actividades para"** (preescolar bare-grade, future).
- **Modifiers:** `para imprimir` > `gratis` > `PDF`. Title tail: **"para imprimir gratis (PDF)"**. Body seeds `con respuestas`, `en línea`, aliases (`primero de primaria`, `kínder`, `cuadernillo`) + NEM/*campos formativos* as a credibility squiggle (do NOT rename hubs to "Lenguajes").
- **Grade demand (ranked):** **preescolar** (huge — Mexican preescolar is compulsory + fichas-heavy) · **primer grado (de primaria)** · primero de primaria · kínder · numeric variants.
- **Title pattern (locked):** `{Ejercicios/Fichas} de {materia} para {grado} – para imprimir gratis (PDF)` — e.g. "Ejercicios de matemáticas para primer grado – para imprimir gratis (PDF)".

## Competitor landscape / moat
- **Mexican:** materialescolar.com.mx (dominant free hub), editorialmd.com (by nivel/grado/campo formativo), materialeducativo.org, imageneseducativas.com (Lainitas cuadernillos), cuadernillos-sep.mx, twinkl.com.mx. **Spain sites that rank in MX (one `es` index):** mundoprimaria.com, educapeques.com, orientacionandujar.es.
- Strongest MX sites index **subject×grade** + **topic×grade** (sumas y restas / sílabas) + **campo-formativo**. **Moat:** free interactive + PDF in Mexican register; **topic×grade beyond sumas/restas + sílabas**; preescolar-by-skill (grafomotricidad, vocales, conteo); "kínder"-worded aliases (incumbents only target "preescolar").

## Mexican authenticity (educator/SEP-NEM) — labels vary by grade-band
- math → **Matemáticas** (title); body cites *Pensamiento Matemático* at preescolar.
- literacy → **Español** (primaria) / **Lectoescritura / iniciación** (preescolar/kínder — formal reading starts 1°; use "aprestamiento").
- science → **Exploración del Mundo** (kínder) → **Conocimiento del Medio** (1°-2°, the real SEP subject) → *Ciencias Naturales only from 3°*.
- **logic + spatial are NOT Mexican asignaturas** → standalone only at preescolar/kínder (folded into Matemáticas at primaria).
- **jardín infantil** (the current es axis name for the 5-6 level) is Colombian/Chilean → display **"Kínder"** (slug unchanged).

### Honesty + cannibalization guardrails (binding for the build)
- **Grade-language mismatch class:** the biggest demand formulations say *primer grado* while the deck pools sit at 5-7 (kínder) — e.g. cryptogram (101 decks kínder vs `criptograma primer grado` demand), sopa de letras preescolar (demand) vs wordsearch decks at 6-8. NEVER claim a grade the decks don't carry; the intersection pairs each type with its true deck level, and the type-head page absorbs the grade-mixed demand.
- **`criptograma numérico`**: high demand but means letter=digit arithmetic; our cryptogram is picture/symbol→letter decode and code-addition is picture→number sums. code-addition may honestly claim `criptogramas de sumas` (harvested); cryptogram may NOT claim "numérico".
- **`sin llevar / con llevadas`** (regrouping qualifiers, harvested under fichas suma/resta): only honest on within-10/20 no-carry decks — same gate as de `ohne Zehnerübergang`.
- **Subject-hub boundary:** `ejercicios de matemáticas <grado>`, `fichas de matemáticas <grado>`, `español <grado>`, `razonamiento lógico` belong to the LIVE subject×grade hubs — topic pages must not title-target them (math-worksheet×kínder is the closest edge; its title leads with "Fichas de matemáticas para kínder" ONLY because the hub owns *ejercicios*+numeric-grade faces — keep body/H1 mechanic-specific: cuadrículas de operaciones).
- **Deck-landing boundary:** type+theme+grade three-axis queries (`sopa de letras de animales primer grado`) belong to deck landings; topic pages stop at two axes.
- **Level display register:** kindergarten axis displays **Kínder** (taxonomy name "jardín infantil" is Colombian — same ruling as the hub unit); grade-1/2/3 display **primer/segundo/tercer grado**.
