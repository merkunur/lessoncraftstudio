## Cross-panel rulings the design files must obey
- **Refusals lower the hub expectation explicitly; fillers never pad.** Known at the lock: `digraphs` es + it REFUSED whole-family (pedagogy: the whole inventory is owned by spelling-rules/syllable-reading; es "sílabas trabadas" is already one of our live syllable pages). sv/da/no/fi digraphs: the Nordic panel says the searched inventory (sv sj/tj/ng, no kj/skj, fi long vowels/diphthongs) overlaps `spelling-rules`; the design file must MEASURE the unowned inventory per locale (≥3 graphemes × ≥6 approved picture words each, else REFUSED) — da re-targets to "stumme bogstaver" (silent letters) only if that inventory passes.
- **2d-shapes owns only:** the shape NAME (both directions), non-prototypical recognition (rotated / skinny / near-miss), flat shapes in real objects, shape riddles, writing the name, drawing on dots. It never repeats K-070 (find the same shape), K-075/076 (count sides), K-077-080, K-265 (colour by shape), G2-241..248 (attributes), G2-243 (solids). Shapes are drawn by a primitive (exact geometry), never by library pictures, except on the real-object face.
- **Squares vs rectangles:** no closed K/G1 face asks "circle the rectangles" while a square is present.
- **road-safety:** sign art is a NEW geometric primitive keyed on the locale's convention (Vienna-convention Europe vs US MUTCD vs Brazil CTB vs Mexico: stop sign text ALTO / PARE / STOP; pedestrian-crossing and school signs differ by country); a sign's MEANING answers are per-locale data authored by the native panel; no "safe/unsafe scene" faces (no scene art).
- **earth-and-space:** moon phases are drawn by a primitive; pt-BR mirrors the waxing/waning shapes (southern hemisphere); the `space/sun` picture is BLOCKED (black square) → the sun is drawn by the primitive; planets use the 8 library planet pictures (each OPENED).
- **animal-life-cycles:** the stages are NEW SVG art (egg / caterpillar / chrysalis / butterfly; frogspawn / tadpole / froglet / frog; ladybird egg / larva / pupa / adult); a biologist-accurate stage count per animal is a data fact, not a locale choice; the chicken is NOT used (G1-203 owns it).
- **plants:** the plant figure is a NEW primitive (root, stem, leaf, flower, seed, fruit anchors); the plant life-cycle face is seed → sprout → seedling → flowering plant (→ fruit/seed); "what plants need" (water/light/air/soil) is a face only if single-answer by construction.
- **maps:** the world map is a NEW primitive built from simplified public-domain outline data (Natural Earth, simplified) stored as a data module; continent names AND the continent count follow each locale's school convention (en 7; es/pt/it/fr commonly 6 or 5 — the native panel rules and the face adapts); oceans 5 (or 4) likewise; compass letters per locale; the map-key face uses geometric map symbols drawn by the primitive.
- **family:** portraits come from the library only after OPENING (pronouns bank precedent, `data/b4/pronouns.js`); kin terms are native literals (sv/da/no farmor/mormor/farfar/morfar: the Nordic rebuild is a genuine teaching point); no face presumes one family shape (a family-tree face is a "who is who" reading task on a GIVEN tree, never "draw your family" as a closed task).
- **synonyms / word-parts:** text-first families; every closed item is single-answer by construction (a synonym pair is only offered where no other chip on the row also fits); word-parts never repeats compound-words (G2-316 family) or opposites' un-/dis-/in- face (G2-320).
- Every rule in `_STUDIO-BRIEF.md` (722 body, lanes 639, density floors, no answer printed, the instruction names only apparatus on the page, no visible "free", d2 ships) binds all ten.
