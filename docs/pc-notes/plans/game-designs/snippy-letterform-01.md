## 2. Concept & creative hook
**Snippy the snail's ink trail IS the letter.** Snippy hums; the child forms the letter Snippy needs and a plant blooms (s → sunflower).
- **WORD-ANCHORED PROMPT (the critic's F4 — permanent default, TTS-safe):** "Snippy needs the letter that **starts *sun***!" — `ctx.speak` says the WHOLE WORD "sun" (TTS-safe) + the letter NAME "S" (TTS-safe). **The game NEVER speaks or promises an isolated /s/ phoneme via TTS** (TTS says the letter name — the platform's RF.K.2.c finding); a pre-recorded phoneme clip is a PURE optional enhancement, and the prompt copy only says "this *sound*" when `phonemeClipAvailable`. **The target letter IS SHOWN** (the sound→letter step is exposure, not a graded gate).
- **FORMATION IS THE GRADED ACT — VIA A 3-LEVEL SCAFFOLD THAT MUST WEAN (the critic's deepest fix):** **Guided** (full faded path + start-dot + direction arrow + order numbers — practice, TEACHES the letter) → **Checkpointed** (path shown, NO arrows, start + order gated) → **CERTIFYING PASS** (the connecting **path is HIDDEN** + the **order numbers are HIDDEN**; the start-dots remain as **UNLABELED, UNORDERED** targets). To CERTIFY a letter (pop it into the garden) the child must, at the certifying pass: **(i) pointerdown on the CORRECT start-dot among all the stroke-starts** (start knowledge) **and (ii) take the strokes in the right ORDER unprompted** (sequence knowledge). The checkpoint-in-order trace stays LENIENT (large R, K-fair) — the load-bearing anti-cheat has MOVED to start-selection + order, which a line-follower with no letter knowledge cannot supply once the path/numbers are off. **This is NOT blank-recall** (start-dots + checkpoint targets remain — within the K ceiling); the fully-blank Faded level stays ENRICHMENT, never a pass-gate.
- **THE DOT-TRACE IS DEFEATED WHERE IT MATTERS:** at Guided it's developmentally-fine scaffolding (a K tracing guide); at the CERTIFYING pass a dot-follower has no path + no order to follow → must know the letter. Only certifying passes count.
- **THE PAYOFF:** a certified letter inks solid, Snippy hums the word, a plant blooms into the garden-row vessel. `ctx.correct()`. Wrong start at certify → Snippy gently "let's practice this one" → demotes to Checkpointed (no red, no score — the critic's F8).
- **Anti-generic statement:** NOT a trace-the-dots toy — (a) the letter is SHOWN + formation is the only graded skill (no recognition poaching); (b) the **required order-and-path-hidden certifying pass** makes start-point + stroke-order knowledge load-bearing (the fade is real, not cosmetic — the critic's deepest fix); (c) the word-anchor is honest TTS-safe audio (never a fake phoneme promise); (d) the gate proves a dot-follower + **checkpoint-homing-follower** + sound-ignorer + scribbler ALL fail the certifying level while the form-from-the-plan oracle passes.

## 3. Core loop & the ≥7 genuinely-distinct experiences
**Loop (`stage`: word-prompt → form → certify-or-practice):** "starts *sun*" plays + `s` is shown → the child forms `s` at its current per-letter level → at the certifying pass (path+order hidden, unlabeled start-dots): correct start + correct order → inks → plant blooms → `ctx.correct()`. At Guided/Checkpointed it's PRACTICE (re-cued, no-fail, doesn't certify). **No timer/score/streak/countdown/fail/attempts/"X of Y".** Per-pass order-only reshuffle.

**The ≥7 distinct experiences (the critic's F1 — ≥7 distinct LETTERS carried to certification, each a different motor program; NOT the 3 scaffold levels, NOT letter-swap padding):**
| Experience | The child's act | Why genuinely distinct |
|---|---|---|
| **straight-line letters** (`l`, `t`, `i`, `L`, `T`) | form down-strokes + crossbars/dots in order | the straight-stroke motor program + start-at-top |
| **single-curve letters** (`c`, `s`, `S`) | form the "magic-c" / serpentine curve, correct direction | the curve motor program (counter-clockwise start) |
| **closed-loop letters** (`o`, `a`, `d`, `O`) | form the loop THEN the stick (order matters) | loop-first sequence (the a/d formation) |
| **mixed multi-stroke** (`f`, `k`, `r`, `E`, `b`) | down-stroke first, then the bumps/arms in order | stroke-ORDER is the challenge (the reversal payload) |
| **uppercase-vs-lowercase pairing** (same sound: `S`→`s`, `M`→`m`) | form the BIG one, then the little one | two different motor programs for one sound (L.K.1.a "upper AND lower") |
| **word→first-letter** (`moon`→`m`, `top`→`t`) | hear a word, attend to its first sound, form that letter | the RF.K.3.a bridge done as EXPOSURE (form, not choose) |
| **reversal-confront pair** (`b` then `d`, order-hidden) | form each via its DISTINCT stroke order (b: line-then-bump; d: loop-then-line) | the reversal is disambiguated by FORMATION, never side-by-side discrimination (pedagogy lock) |
- **Honest framing (pedagogy + critic F1):** the **3 scaffold levels (Guided/Checkpointed/Certifying) are within-letter PROGRESSION, NOT separate experiences** (the §A.13.60 "same thing reconfigured" trap). **≥7 = ≥7 distinct LETTERS carried to the certifying level** — 26 letters × 2 cases = genuinely-different motor programs (NOT swap-padding; `b` vs `e` vs `k` are different start-points/stroke-counts/directions). First wave = frequent consonants + short vowels (s,m,a,t,p,n,i,f,r,o,d,c,g,b). An optional **2-foil "which starts *sun*?"** warm-up is a `ctx.advance()` flavor beat (never a 4-foil recognition gate, never a standard claim). `audit-activity-variety.js` sees ≥7 distinct certifying letter-rounds.
- **Free slice = 3 first-wave letters (a straight + a curve + a closed-loop) carried to certification** — proves the formation plan is load-bearing; the dot-follower + checkpoint-homing-follower fail the certifying pass.

## 4. Win-states & juice (no competition)
No timer/score/streak/countdown/**fail-state**/attempts/"X of Y". **THE BLOOM (signature):** a certified letter inks solid → Snippy hums the word → a plant blooms (s→sunflower) into Snippy's **garden row** (`GameCollection` — a growing variety of plants; abundance, NEVER a count). **Warm wrong-handling (no-shame, the critic's F8):** at PRACTICE (Guided/Checkpointed) a wrong stroke softly un-inks to the last good checkpoint + a gentle re-cue ("start at the top ↓") — lenient, self-correcting, NO fail. At the CERTIFYING pass a wrong start does NOT re-cue-to-pass (that would re-admit the homing cheat) — instead Snippy warmly "let's practice this one a little more" → **demotes the letter to Checkpointed** (no red, no buzzer, no score, no attempt-counter — the no-fail lock honored by *demote-not-fail*, never *pass-on-retry*). The 2-foil warm-up + level transitions use neutral `ctx.advance()`. `ctx.correct()` only on a certifying pass → auto-advance (no Check button). CSS/SVG + TTS (words + letter-names only); reduced-motion → instant ink-fill; mute-safe (the shown letter + the word-anchor TEXT carry everything — audio is never the sole channel; a deaf child sees the letter glyph + the word text).

## 5. Pedagogy
- **L.K.1.a instantiation (operator A1 — claim earned):** at the certifying pass the child supplies the formation PLAN — the correct start-point (chosen among unlabeled starts) + the stroke order (unprompted) — which IS the transferable handwriting cognition (grip/pressure aside). The prose is honest: on-screen formation-plan practice, a complement to paper.
- **THE KEYSTONE RULES (pedagogy + critic):** (i) **formation is the only graded skill** (the letter is shown; the sound→letter is a light word-anchor frame, never a graded recognition gate). (ii) **the certifying pass hides the path + the order-numbers** (start-selection + unprompted order are load-bearing — the fade is REAL). (iii) **enforce start-point firmly; direction + order leniently at PRACTICE / start+order at CERTIFY** (the F8 level-split — both the anti-cheat AND the no-fail lock coexist via demote-not-fail). (iv) **never gate a pass on blank-recall** (certify keeps start-dots + checkpoint targets — within the K ceiling; the fully-blank Faded level is enrichment). (v) **both cases** (lead uppercase→lowercase per letter). (vi) **reversals via stroke ORDER, never side-by-side**. (vii) **word-anchor audio is TTS-safe; never a synthesized isolated phoneme**.
- **§20.8 demonstrate-don't-touch (the critic's headline):** as an always-Guided / cosmetic-fade design it TOUCHED L.K.1.a (a child line-follows the shown guide with zero formation knowledge — pre-writing, not printing; the gate blind). As a required-certifying-pass design it DIRECTLY INSTANTIATES formation (start + order knowledge unprompted is the only path). The line is exactly: the certifying pass hides the path + order. The gate (checkpoint-homing-follower + dot-follower + sound-ignorer + scribbler all FAIL the certifying level; the form-from-the-plan oracle PASSES) is the machine-checked proof.
- **also_teaches:** NONE in `educationalAlignment` (the critic's F2 — `RF.K.3.a` + `RF.K.1.d` are EXPOSURE-prose only; claiming a recognition standard with no graded recognition is §20.8 + would fail `audit-activity-pages.js`). Distinct from Game 21 numeral-trace + the RF.K.* recognition activities.
- **Grade fit + letter set:** Grade K; both cases (lead uppercase → lowercase per letter); first wave = frequent consonants + short vowels (s,m,a,t,p,n,i,f,r,o,d,c,g,b), later waves the rest (k,x,z,w,y,q,v + remaining vowels). Enforce start firmly, neatness/speed/lifts ungraded. Reversals (b/d, p/q) via distinct stroke order at the certifying pass.
- **No-shame:** the blooming garden is the reward; practice is lenient + self-correcting; a missed certify gently demotes to more practice (never a fail); Snippy never red-X'es the child.

## 6. Interaction & UX
- **Runtime: word-prompt → form → certify.** `snippy-core.js` holds the round `{ letter, case, sound:{wordAnchor, letterName, phonemeClipId?}, rewardWord, strokes[{path, startPoint, checkpoints[], dir}], guideLevel ('guided'|'checkpointed'|'certify'), formationLevelReached[letter] }` + `pointerStroke`/`commitStart` + `isGenuineFormation(round, answer)` → at certify: chosenStart correct among all starts + strokeId order unprompted + checkpointsHitInOrder (lenient). **The answer = `f(supply the start-point + stroke order from letter knowledge)`, never `f(follow the shown line)` / `f(read the order numbers)` / `f(home to the checkpoint coords)`.**
- **State separation (anti-cheat):** `snapshot()` exposes `{ letter (shown), guideLevel, strokeStarts (at certify: UNLABELED, UNORDERED), no path + no order-numbers at certify, garden }`. `facts()` exposes per-round `{ certifyHidesOrderAndPath (===true), startSelectionAmongAllStarts (===true at certify), strokeOrderUnpromptedAtCertify (===true), onlyCertifyCounts (===true), checkpointInOrderLenient (===true), startPointFirmAtCertify (===true; wrong-start demotes not re-cues), noBlankRecallGate (start-dots present), bothCases, reversalViaOrderNotDiscrimination, wordAnchorDefault (===true), neverSynthesizedPhoneme (===true), alignment (===['L.K.1.a']; RF absent) }`.
- **Trace + the keyboard plan-reconstruction path (the critic's F3/Fork B):** pointer-trace (next-checkpoint proximity; each stroke its own pointerdown near its start — no continuous drag); the **accessible non-trace path reconstructs the PLAN in words** — order the UNLABELED strokes by their spatial DESCRIPTION ("the long line down the left", "the curve on the right") + pick each stroke's correct START ("top or bottom?") — feeding the SAME `isGenuineFormation` predicate. **Labeled REDUCED-equivalence** in the manifest (not full parity — a non-motor channel can't do graphomotor; but it tests start+order knowledge, the transferable plan — never lock a disabled child out). NO Check button — `evaluate` on stroke-sequence-complete.
- **Mobile @280px (the critic's F6):** SINGLE-FOCUS per phase — the trace cell owns the full content width (the optional 2-foil warm-up is a SEPARATE step, never co-resident; the bloom reward is a TRANSITION after `ctx.correct()`, not a persistent panel). **The checkpoint hit-tolerance R SCALES with the rendered cell PIXEL size** (not a fixed viewBox R — the §A.13.47 vw/vmin trap; a fixed R becomes too-tight-to-pass at 216px). Snippy + start-dots ≥44px. `audit-activity-mobile.js` empty/mid-trace/certify at 280-768.
- **Accessibility:** the plan-reconstruction path (above) is the keyboard/SR core (stroke-description buttons + start-choice, ARIA-labeled, ≥44px); the shown letter glyph + the word-anchor TEXT are real `<text>` (SR reads "S", "sun"). Reduced-motion → instant ink-fill. Mute-safe (letter + word text carry it; audio never sole). Not color-only (start-dots are SHAPES + ARIA, never hue alone).

## 8. Runtime mapping + MEASURED build-gate + PER-LOCALE
- **Round descriptor (DATA; answer = the produced start+order plan, NEVER line-following):** `{ letter, case, sound:{wordAnchor, letterName, phonemeClipId?}, rewardWord, strokes[{path, startPoint, checkpoints[], dir}], guideLevel, certifyRequired (===true to pop the plant) }`. `makeRounds`: ≥7 distinct LETTERS spanning the motor-program families + both cases + the word→first-letter + the b/d reversal pair; first wave letters; only certifying passes certify; order-only reshuffle.
- **`verify-snippy-core.js` (MEASURED — drives the REAL `isGenuineFormation` via the same checkpoint state machine; HALTS build) — the critic-armed solver set:**
  1. **FORM-FROM-THE-PLAN ORACLE PASSES 100%:** picks the correct start among all starts, takes strokes in order, hits checkpoints in order → `isGenuineFormation` true at the certifying level.
  2. **DOT-FOLLOWER solver FAILS the certifying level:** traces the (now-hidden) path / wrong order / wrong start → at certify there is no path + no order-numbers → cannot derive them → fails; assert `certifyHidesOrderAndPath`.
  3. **CHECKPOINT-HOMING-FOLLOWER solver (the critic's DEEPEST — NEW) FAILS:** knows the checkpoint COORDS (the thing the engine holds) and homes to them in any inferable order → **cannot derive which start is "first" or the stroke ORDER from geometry alone** (that's formation knowledge) → fails the certifying level; assert `startSelectionAmongAllStarts` + `strokeOrderUnpromptedAtCertify`. **If a passing oracle can't beat this homing solver, the level is still line-following — withhold more.**
  4. **SOUND-IGNORER / SCRIBBLER solvers FAIL:** random start/order → fails the start+order gate.
  - **STRUCTURAL asserts:** `CERTIFY_LEVEL_HIDES_ORDER_AND_PATH` (no path `<path>` + no order-numbers in the certifying render payload); `START_POINTS_REQUIRED` + `STROKE_ORDER_REQUIRED` (at certify, from letter knowledge); `ONLY_CERTIFY_COUNTS` (Guided/Checkpointed are practice, don't pop the plant); `NO_BLANK_RECALL_GATE` (start-dots present at certify — K ceiling); `bd_DISTINCT_START_AND_ORDER` (b and d have different start-points + stroke orders in the data — the reversal); `alignment===['L.K.1.a']` (RF absent from JSON-LD); `wordAnchorDefault` + `neverSynthesizedPhoneme` (no `ctx.speak` of an isolated phoneme; "sound" copy gated on `phonemeClipAvailable`); `ACCESSIBLE_PATH_REDUCED_EQUIVALENCE` (the keyboard path tests start+order via descriptions, labeled reduced — not "1-2-3").
  - Plus standing gates: `audit-activity-mobile.js` (single-focus; R scales with rendered size; ≥44px; 280-768), `audit-activity-variety.js` (≥7 distinct certifying letters + order-only reshuffle), `audit-no-competition.js` (engine 0-line; no timer/score/streak; demote-not-fail; first-attempt internal-only), SEO/JSON-LD §21 (L.K.1.a only).

Framework NAME localizes when locales land (§20.10/§A.13.49); CCSS `L.K.1.a` the machine/SEO anchor. 0 lines to any protected core — a NEW clean `engine-snippy.js`/`snippy-core.js`, reusing `game-shell.js` (incl. `ctx.advance()` for the level transitions / 2-foil warm-up), `LCSAudio.speak` (words + letter-names ONLY), `GameAssets`, `GameCollection`.
- **Feasibility:** SIMPLE — DOM/SVG/CSS + TTS (no canvas/physics; next-checkpoint proximity in viewBox units).
