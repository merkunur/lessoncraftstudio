## Deviations from the design file (each measured)

1. **14 lines in 60 px rows at d2 (stack 636), not the design's 12 lines in 48 px rows (stack 490).** The brief's sparse-page rule: the d2 stack must not leave > 180 px of slack under the ONE-line chrome. Measured on this shell: one-line chrome body **811** (the README's 814), 3-line title + 3-line instruction **710** (the README's 722, the G1-352 finding), 4-line fi title **677**. The quotas scale with it: `upMin 5 / downMin 5 / fiveMin 2 / carryMax 2`, plus the brief's "ones digit balanced" as `digitCover:true` (every deciding digit 1..9 on the page) + `digitMax 2` (none more than twice) at every level. d1 = 12 two-digit lines (stack 96 + 12 + 24 + 6 x 60 + 5 x 14 = 502) and d3 = 16 three-digit lines, no rule box (24 + 8 x 60 + 7 x 14 = 602 <= 677) for the same reason (the ladder said 10 / 12). d2 is the only shipped level.
2. **The rule box is exported as `roundRuleBox`, not `ruleStrip`.** `templates/components-b4/odd-and-even.js` already exports `ruleStrip` (G1-351's text rule lane) and the b4 barrel refuses a duplicate name; a rule lane and a rule box are different things, so the name is not reused (the brief's "require it from the sibling" clause does not apply).
