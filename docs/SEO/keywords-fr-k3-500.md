# French K-3 worksheet keyword inventory — 500 base keywords (2026-07-12)

**Purpose:** the base-keyword inventory French K-3 teachers (maternelle PS/MS/GS + CP/CE1/CE2) actually search for fiches/exercices with, for a LATER long-tail-formation + page-application step (NOT yet applied anywhere). Machine-readable twin: `keywords-fr-k3-500.json`. Sibling of the German inventory (`keywords-de-k3-500.md`).

**Method:** 10 parallel native-French keyword web-research agents (one per demand segment), each doing live web research (SERP titles + competitor category trees: fiche-maternelle.com, mamaternelle, i-profs, pass-education, les-coccinelles, lululataupe, tidou, lutinbazar, boutdegomme, dessinemoiunehistoire, recreakidz …). 808 unique raw → force-dropped non-worksheet intent (bricolage, branded reading methods Taoki/Pilotis, classroom-management, dispositifs) → scored (autocomplete-confirmed > topic/level > format) → exactly 500. **123 (24.6%) confirmed in the 2026-07-06 google.fr autocomplete harvest** (`harvests/fr.json`, 2,154 uniques) — the unconfirmed rest is deliberate coverage-expansion beyond that harvest's deck-type-seeded scope (QLM, saisonnier, registre enseignant, FLE/dys).

**Complements (do not duplicate):** `demand-map-fr.md` (fiches/exercices register + à-imprimer grammar + CP-anchor) · `demand-terms-fr.json` (distilled hub titles).
