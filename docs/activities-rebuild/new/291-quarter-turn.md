## The skill
a×b and b×a have the same product: turning an array changes the grouping, not the total.

## The apparatus and its invention
THE TURNTABLE. An array of identical library pictures (e.g. 3 rows of 5) sits on a round turntable; coloured rails ring each row. The child types the sentence for the array as it stands into three boxes (3 × 5 = 15). Before turning, the child taps a prediction on the table: 'same total' (two equal stacks icon) or 'different' (unequal stacks icon). Then the child drags the turntable's handle a quarter turn: every picture travels with the table but stays upright, the rails now ring the new rows (5 rows of 3), and a count badge fixed to the table never changes during the turn. The child types the second sentence. Wrong 'different' prediction: the badge glows as it rides through the turn unchanged; a wrong product: the rails light one at a time adding a row (5, 10, 15); miss 2 numbers the pictures. Right: both sentences stand side by side with an equals bar between them.

- **Misconception the apparatus makes visible:** Believing 3×5 and 5×3 are different amounts (or must be counted again).
- **Pictures:** one noun per round from fruits, flowers, toys, insects
- **Settings:** Arrays: up to 5×5 / up to 10×10 · Ask: total both times / predict before the turn
- **Rounds:** Pairs (a,b) a≠b in 2-10, ≥ 8 rounds; which orientation appears first alternates; answers typed.
- **Worksheet types it covers:** G3-314
- **Distinct from:** Echo Grove teaches that 3 groups of 4 is a different picture from 4 groups of 3; the turntable teaches the product is the same. No existing activity rotates an array.
- **Build risk:** Low; the turn animation must keep pictures upright (rotate positions, not images).
