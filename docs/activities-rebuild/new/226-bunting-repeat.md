## The skill
Find the repeating unit of a pattern (AB, ABC, AABB, ABB, by picture, size, position or shape), extend it, fill a missing piece, and extend a growing pattern.

## The apparatus and its invention
THE UNIT THAT FOLDS UNDER. Bunting flags carrying library pictures hang on a line across the stage, with empty pegs at the end (or one empty peg in the middle). The child drags flags from a basket onto the pegs. Each time a full unit is completed, that stretch of bunting FOLDS down under the previous unit, so the units stack in a column like rows of a table: a correct pattern makes perfectly aligned columns, a wrong flag sits visibly out of line under a different picture. The child is not told the unit — they see it. Position setting hangs flags high/low; size setting hangs big/small; growing setting hangs groups that grow by one flag each unit (the folded stack becomes a staircase).

- **Misconception the apparatus makes visible:** Copying the last picture instead of the unit, and not seeing where the unit restarts (treating AAB as AB).
- **Pictures:** fruits, animals, vehicles, toys (identical instances per kind); shapes theme (circle, square, triangle, star, heart, hexagon) for the shape setting (K-077); size = scale transform, position = high/low peg.
- **Settings:** Pattern: AB / ABC / AABB / ABB / growing · Attribute: picture / size / position / shape · Task: extend / one gap / two gaps
- **Rounds:** 9 rounds per setting; 2–3 visible units, the stopping point mid-unit in ≥ half the rounds; missing-piece rounds put the gap at each unit position equally; TWO-GAP rounds (G1-155, absorbed Pattern Quilt) in the missing setting; basket shuffled with each candidate in every slot across a pass; one right answer.
- **Worksheet types it covers:** G1-155, K-046, K-047, K-048, K-049, K-050, K-052, K-053, K-077
- **Distinct from:** No activity teaches patterns. Not the Animal Train or Counting Necklace (count instruments); the folding unit stack is a new invention.
- **Build risk:** Low. Must keep pictures ≥ 64 px on a phone with 9–12 flags: fold early (two-row line) on narrow screens.

## Merged into this instrument (cover each as a setting or round set)
- grade 1 "The Pattern Quilt" (pattern-quilt): A repeating pattern has a core unit that repeats; find the missing pieces by finding the unit. — A QUILT WITH LOOSE PATCHES: a strip quilt of library pictures (AB, AAB, ABC, AABB) has two holes. Loose patches lie in a basket. The child can drag a "stitch frame" over any stretch: if the stretch is exactly one core unit, the frame locks and copies of the unit shimmer along the quilt, showing where each picture repeats; then the child drops patches into the holes. A wrong patch puckers the quilt at that seam and the stitch frame over its unit flashes the mismatch.
