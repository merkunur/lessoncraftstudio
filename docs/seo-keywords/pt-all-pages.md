## Regras anti-canibalização

| Regra | Descrição |
|-------|-----------|
| App vs. Ferramenta | As páginas de apps visam palavras-chave « criar + vender + para imprimir ». As páginas de ferramentas visam « grátis + online + sem cadastro ». |
| Guia vs. App | Os guias usam palavras-chave informacionais (« como », « guia », « passo a passo »). Os apps usam palavras-chave transacionais (« criar », « gerador »). |
| Pacote vs. App | Os pacotes usam palavras-chave « pacote / kit ». Os apps individuais usam o tipo específico de gerador. |
| Ideia vs. Guia | As ideias usam palavras-chave « nicho / negócio ». Os guias usam palavras-chave « guia / estratégia ». |
