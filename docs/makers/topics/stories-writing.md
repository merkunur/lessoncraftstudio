# Maker: Stories & Writing (`stories-writing`)

Group **literacy** · language need **bound** · 15 existing templates + 2 new · replaces old app(s): —

## Settings a teacher sets

- story / picture / animal
- task: order / next / middle / sentences / retell / write about / fact file
- (plus the settings every maker has: language (one of our 11); template (gallery by sub-topic); level 1-3; picture theme / own pictures where pictures appear; number of problems / page fill; title + instruction text (editable); answer key on/off; pages: add / duplicate / delete; regenerate (new seed, same settings); paper: Letter for en-US, A4 elsewhere (switchable))

## Templates from today's worksheet types

**Put story pictures in order (first, next, last)**

- `K-379` Story Sequencing: Number the Pictures — Look at what changes in each story, then write the numbers in the boxes to put the pictures in order. · screen version (scripts/worksheet-gen/types/k/K-379-story-sequencing.js)
- `K-381` Story Sequencing Cut and Paste: First, Next, Last — Cut out the pictures on each strip and glue them on the line with the same mark, in the empty frames above First, Next and Last. · screen version (scripts/worksheet-gen/types/k/K-381-story-sequencing-cut-and-paste-first-next-last.js)

**Sequence a story: what happens next, draw the middle, order sentences to pictures**

- `G1-400` Story Sequencing: What Happens Next? — Look at each story's three pictures, then circle the picture below them that belongs in the ? frame. · screen version (scripts/worksheet-gen/types/g1/G1-400-story-sequencing-what-happens-next.js)
- `G1-401` Beginning, Middle and End of a Story — Look at the beginning and the end of each story and draw what happens in the middle frame. · screen version (scripts/worksheet-gen/types/g1/G1-401-beginning-middle-and-end-of-a-story.js)
- `G1-402` Story Sequencing Sentences: Match the Pictures — Number each story's sentences in order in the boxes, then draw a line from every sentence to its picture. · screen version (scripts/worksheet-gen/types/g1/G1-402-story-sequencing-sentences-match-the-pictures.js)

**Write sentences about a picture using a word bank and sentence starters**

- `G2-278` Write About the Picture — Look at the picture. Use the word bank to help you write about what you see. · picture themes (scripts/worksheet-gen/types/g2/G2-278-write-about-the-picture.js)
- `G2-299` Write About the Picture: What You See — Sentence starters help you begin. The word bank names everything. · picture themes (scripts/worksheet-gen/types/g2/G2-299-write-about-the-picture-what-you-see.js)
- `G2-300` Write About the Picture: Your Own Words — No sentence starters this time. Use the word bank and write your own story. · picture themes (scripts/worksheet-gen/types/g2/G2-300-write-about-the-picture-your-own-words.js)

**Gather true facts about an animal into a fact file (eats, lives, moves, body covering, babies)**

- `G2-318` Animal Fact File: {U} — Find out about this animal. Write one fact in each row of the fact file, then fill in the rest of the page with your own drawing or words. · picture themes (scripts/worksheet-gen/types/g2/G2-318-animal-fact-file.js)
- `G2-339` {U} Fact File: Circle the True Facts — Read the choices in each row and circle the one that is true for this animal. Then draw where it lives and finish the sentence. · picture themes (scripts/worksheet-gen/types/g2/G2-339-animal-fact-file-tick-the-facts.js)
- `G2-340` {U} Fact File with a Word Bank — Find each true fact in the word bank and copy it into the right row of the fact file. Then finish the sentence at the bottom. · picture themes (scripts/worksheet-gen/types/g2/G2-340-animal-fact-file-with-a-word-bank.js)
- `G2-341` {U} Fact File: Write Three Sentences — Read the fact file. Finish the three sentences with facts from it, then write one more fact of your own on the last line. · picture themes (scripts/worksheet-gen/types/g2/G2-341-animal-fact-file-write-three-sentences.js)

**Compare two animals: which facts are the same and which are different**

- `G2-342` Compare Two Animals: Same and Different — Read both fact files. For each fact, circle same or different. Then write two things that are the same and two that are different. · picture themes (scripts/worksheet-gen/types/g2/G2-342-compare-two-animals-same-and-different.js)

**Use clues one at a time to find a mystery animal**

- `G2-343` Who Am I? Mystery Animal — Read the five clues on each card. Find the animal in the picture bank, write its name on the line and draw it in the box. · picture themes (scripts/worksheet-gen/types/g2/G2-343-who-am-i-mystery-animal.js)

**Retell a picture story in order with time-order starters (First, Next, Then, At the end)**

- `G2-378` Retell the Story with Starters — Write what happens in each picture on its lines, starting with the word printed on the first line. (scripts/worksheet-gen/types/g2/G2-378-retell-the-story-with-starters.js)
