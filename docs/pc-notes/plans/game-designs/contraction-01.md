## §1 — Concept / world
**Wisp the apostrophe-spirit.** A tiny curl of candle-smoke shaped like an apostrophe; Wisp's one job: stand in the EMPTY SEAT a dropped letter left. The binding metaphor (rejecting the apostrophe-as-glue misconception): *the apostrophe is a MEMORIAL standing at the precise spot of a missing letter — not glue between two words.* The child drops the letters that vanish (a letter lifts out, leaving a visible hole) and sends Wisp into the vacated seat. Non-numeric abundance vessel: a night-garden silhouette grows lusher as words form (never a count). `ctx.correct()` auto-advances.

## §2 — The standard + the load-bearing cognition
**L.2.2.c (Grade 2, SOLE primary), CONTRACTIONS ONLY** — use an apostrophe to form contractions. **POSSESSIVES = a SIBLING game** (the apostrophe means something DIFFERENT — possession not omission; mixing is a confound; the dog's-bone never appears here). **Cognition:** the child PRODUCES the contraction by (1) dropping the right letter(s) + (2) placing the apostrophe at the OMISSION SITE (where the dropped letters were). Apostrophe POSITION is GRADED (do'nt / dont' / dont all WRONG). **The contraction set:** lead with the `n't←not` backbone (isn't/didn't/don't/doesn't/wasn't/weren't/hasn't/haven't/couldn't/shouldn't/wouldn't) + `'s←is` (it's/she's/that's) + `'re←are` (you're/we're/they're) + `'ll←will` (I'll/we'll) + `'ve←have` (I've/we've) + `'m←am` (I'm); hold `'d←would/had` (the two-source ambiguity) to an advanced band. **IRREGULARS:** include won't←will not + can't←cannot as FLAGGED WHOLES (NOT rule-derived); QUARANTINE shan't/ain't. **Homophones:** form it's/they're/you're as contractions; DEFER the it's-vs-its USAGE choice (a later standard). **FENCES:** compound-words (no letters drop), broad sentence-repair, possessives, spelling-recall (no type-the-word), it's/its usage, ain't/shan't. Letters/words = real DOM/SVG `<text>`.

## §3 — THE ARCHITECTURE REWORK (the heart; the deepest flaw + fix — a PROCESS-axis fix, NOT a re-center)
**The critic's catch — the no-text-input / causal-chaining / descriptor-recompute architecture genuinely defeats the OUTPUT channel (RECALL/COPY-SHOWN/answer-not-stored — the production is built by SUBTRACTION, never copied/typed), but it is ORTHOGONAL to the PROCESS channel, where the real cheat lives ("you hardened the wrong axis"):**
- **(A) TRIAL-AND-ERROR DROP (a Game-74 observational-equivalence cousin — the deepest interaction cheat).** The "which letter vanishes" search is TINY (≤5 letters) and undo is FREE with no penalty; if any pre-commit signal (the "bloom" / the apostrophe seating) distinguishes a right drop from a wrong one, the child has a hot/cold ORACLE → gradient-climb to green in ~2-3 taps with ZERO omission knowledge. Brute-force-drop and knowledge-drop reach the IDENTICAL end-state → the gate can't distinguish them. The output-channel solvers are orthogonal to this.
- **(B) PLACE-DETERMINED-BY-DROP COLLAPSE (worse than stated).** L.2.2.c contractions are INTRINSICALLY single-hole (one contiguous vacated gap), so the apostrophe-placement has ZERO degrees of freedom (put it in the only hole) → `OMISSION_SITE_LOAD_BEARING` passes VACUOUSLY (the site is never a CHOICE). The two "cognitions" COLLAPSE to one — the brute-forceable drop. The "weight multi-hole rounds" escape barely exists (real contractions almost never have an ambiguous site).
- **(d) APOSTROPHE-BEFORE-LAST-LETTER habit** clears the whole n't family + 'm with one positional rule. **(e) the n't FAMILY-RULE** ("always drop the o of not") is BOTH the legitimate generalization the standard wants AND a cheat — the rule and the omission-understanding only DIVERGE on the IRREGULARS + cross-family items → **those are the ONLY real assessment surface**, and ≥2 is far too thin. **(f) L.2.2.c is intrinsically THIN (~1.3 cognitions)** — thin is fine, trial-and-error-passable is not.

**THE FIX — PROCESS-axis patches (the OUTPUT is genuine → NO re-center; the discrete-symbolic-production exception is validated; MID-SIZE):**
- **PATCH 1 — NO PRE-COMMIT ORACLE + commit-then-grade-with-cost (kills A).** A dropped letter's hole + Wisp's seating must be OBSERVATIONALLY IDENTICAL for a right vs wrong drop pre-commit (the hole appears for ANY dropped letter; **Wisp seats in ANY vacated hole, including a wrong one** — no "it won't fit" signal). NO "bloom" until the round is COMMITTED + graded. A wrong commit → a FRESH round (new word), NOT the same word with free retry (a wrong commit costs a re-show, not a free hot/cold probe). Within a round, pre-commit undo is fine; commit is irreversible.
- **PATCH 2 — CROSS-FAMILY session mix ≥4 drop-shapes + discriminating-round-fraction ≥0.5 (kills B/d/e).** A session spans ≥4 distinct drop-shapes (n't drop-o / 'll drop-wi / 'm drop-a / 's drop-i-or-ha / 've drop-ha) so NO single positional habit ("drop the last vowel" / "apostrophe before the last letter") clears it; ≥50% of the session is DISCRIMINATING (irregulars + non-n't cross-family), NOT ≥2 absolute.
- **PATCH 3 — 3 NEW process-axis gate solvers (all must FAIL).** `TRIAL_AND_ERROR_SOLVER` (tries each single-letter drop, commits, observes pass/fail, CARRIES the learning to the next instance of the same word — must fail to exceed chance under the commit-cost rule) + `FAMILY_RULE_SOLVER` (the single n't positional rule → fails the ≥50%-non-n't session) + `APOSTROPHE_BEFORE_LAST_LETTER_SOLVER` (the positional habit → fails on 'll/'ve).
- **PATCH 4 — demote the weak surfaces to scaffold (zero graded weight).** split-back (sight-recall of the pair, not omission — (c)) + single-hole rounds → scaffold; the GRADED weight is on the cross-family + irregular discriminating rounds. Raise the floor: `DISCRIMINATING_ROUND_FRACTION ≥ 0.5` + `IRREGULARS ≥ 2` + `CROSS_FAMILY_SHAPES ≥ 4`.
- **FALLBACK (only if TRIAL_AND_ERROR_SOLVER STILL passes after single-commit — ≤5-letter words too small):** re-center onto "identify the dropped letter from the SPOKEN word" (say "do not" fast → tap the letter that goes quiet — phonological-discrimination trial-and-error can't observe). The critic expects single-commit + cross-family to HOLD; fallback is the contingency, not the requirement.

## §4 — Anti-cheat architecture (the measured gate)

Solvers — ALL must FAIL:
- **OUTPUT-channel (retained):** `RECALL_SOLVER` (no text input → no entry point), `COPY_SHOWN_SOLVER` (deep-scan payload → no apostrophe-bearing string / no answer / no slot), `APOSTROPHE_ANYWHERE_SOLVER` (off-site → WRONG_SITE), `NAIVE_RULE_SOLVER` (fails on the irregulars), RANDOM.
- **PROCESS-channel (NEW — the critic's required adds):** `TRIAL_AND_ERROR_SOLVER` (per-round drop-search with cross-round learning; must fail under commit-cost — `NO_PRE_COMMIT_ORACLE` assert: right-drop and wrong-drop pre-commit states observationally identical), `FAMILY_RULE_SOLVER` (must fail the ≥50%-non-n't session), `APOSTROPHE_BEFORE_LAST_LETTER_SOLVER` (must fail on 'll/'ve).
- Structural asserts: `NO_PRE_COMMIT_ORACLE`, `COMMIT_THEN_GRADE_WITH_COST` (wrong commit → fresh round), `DISCRIMINATING_ROUND_FRACTION ≥ 0.5`, `CROSS_FAMILY_SHAPES ≥ 4`, `IRREGULARS ≥ 2`, `OMISSION_SITE_LOAD_BEARING` (non-vacuous — graded only where the placement is a genuine choice OR the drop determines it AND the drop is discriminating), `LETTER_DROP_LOAD_BEARING`, `PRODUCED_NOT_COPIED`, `ANSWER_DERIVED_NOT_STORED` (mutate word2/dropSpec/apostropheIndex + the irregular-vs-naive witness — derive(won't)=="won't" AND naiveRule(won't)≠"won't"), `SPLIT_BACK_NOT_GRADED`, `NAIVE_RULE_FAILS_ON_IRREGULAR ≥ 2`, VARIETY ≥ 7.
- **Wrong-answer re-show (no-reveal, single-commit):** a wrong commit → a FRESH round, with the re-show pointing at the omission via the PHONOLOGICAL hook ("say 'do not' fast — the o in 'not' goes quiet; that's the letter that leaves, and the apostrophe stands where it was"), never the bare answer. The "say it fast" hook grounds WHICH letter drops in speech (the genuine cognition), which trial-and-error can't observe.
