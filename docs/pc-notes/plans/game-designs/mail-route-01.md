## 2. Concept & creative hook
**Pip the postal mouse** works her morning round in a cozy, scattered mouse-town — mismatched houses (a tall blue one, a round yellow one with a flower box, a teapot-house that puffs steam), each with a **number plate by the door** and curtains drawn. Behind each curtain a resident waits, a silhouette you can *almost* see. The hook: **someone is waiting for their letter and doesn't know it's coming yet** — when the right letter lands, the curtains fly open, a snail in a nightcap / a kid with a kite / a frog with a teacup waves and clutches the letter. **Delivery is a small act of kindness, decoded.** The number on the door isn't decoration — it's *whose house this is.*
- **THE READING-FORCED TARGET (the critic's shape-match fix — the heart):** Pip pulls ONE envelope. The target numeral is presented so it **cannot be template-matched**: either **AUDIO** (Pip says *"a letter for number fourteen!"* via `_NUMBER_WORD_HELPERS` — NO written glyph on the envelope, so there's nothing to pixel-copy; the child must KNOW the glyph for *fourteen*), OR **CROSS-FONT** (the envelope shows "14" in a deliberately DIFFERENT typeface from the house plates — the pixels don't match even though the number does, so the child must read 14 *abstractly*, not match shapes). **Same-font glyph targets are CUT** (they let a non-reader match squiggles). The houses' plates are in the plate-font.
- **THE SCATTERED MAP + THE CONFUSABLE DISTRACTOR (the navigation-cheat-killer):** 4-6 houses, positions + numbers RESHUFFLED every envelope (no spatial pattern to learn; the correct house is NOT the nearest/leftmost/in-order one). Every round carries a **confusable-distractor house** (a teen-reversal 13/31, a same-tens 14/13/15) positioned so a nearest/in-order heuristic lands WRONG. Reading the numeral — font-invariant or from its name — is the ONLY way to disambiguate.
- **THE ROUTE IS A RENDER-ARTIFACT, NEVER DRAWN (the navigate-spatial spine):** the child's ONLY input is TAP the house they read as matching. `deliver(tappedHid)` returns `{readNumeral, targetValue, matched}` — the answer channel carries a NUMERAL, not a coordinate/path. The route polyline (`pointer-events:none`) extends ONLY on a correct delivery (Pip's scooter rides it to the house). **There is NO draw-the-route gesture — the cheat framing is not implementable.**
- **THE DELIVERY PAYOFF (earned by the READ):** read the number → tap the right house → the curtains fly open, the resident waves + clutches the letter, the route extends, Pip re-voices the number ("Fourteen — that's Mrs. Snail!"). The wave is the *meaning of the numeral made visible* — gated on the read, never on the tap.
- **NO-SHAME:** a wrong tap → the wrong house's curtain stays CLOSED (no neighbor disturbed), Pip "that's house eight — let's find fourteen" (names what they read, **non-leaking** — no high/low/spatial hint, never highlights the answer); re-read. No buzzer. Non-numeric vessel = Pip's SATCHEL emptying / the whole street's curtains opening (every neighbor got their mail).
- **Anti-generic statement:** NOT a numeral flashcard with a mouse — (a) the audio + cross-font target defeats shape-matching → the child must READ the number (gate-proven); (b) the scattered map + confusable-distractor make it reading-under-visual-search (a genuine load), not a 1-of-4 row; (c) the route is a render-artifact (the navigation cheat is unimplementable); (d) the kindness payoff lands on an actual decode; (e) a board ships only if a **navigation-only solver** (taps by position) AND a **template/shape-match solver** (matches glyphs, can't read) BOTH fail while a **number-recognizer** (font-invariant + cross-modal) passes (§8).

## 3. Core loop & the honest cognitions + distractor-configs
**Loop (`stage`: read → deliver):** Pip pulls an envelope (audio or cross-font target) → the child READS the number + taps the matching house among the scattered, confusable set → correct → the route extends + the resident waves + Pip re-voices the number → repeat (single-envelope-per-delivery; 1-3 deliveries/round, ORDER-FREE — no sequence to reproduce) → `ctx.correct()`. **No fail, no timer, no score, no Check button.** A wrong tap → the wrong curtain stays closed + "that's house eight — let's find fourteen" (non-leaking, re-read); positions don't help (decorrelated). First-attempt-correct is the internal signal (never shown).

**The genuine RECOGNITION cognitions (the critic's honest set, de-padded from 8) + the distractor/presentation configs that vary the reading demand (honestly labeled — NOT separate cognitions). "deliver to 3 vs to 5" = number-variant BLOCKLISTED.** Each round carries a `cog` + a `config`:
| | Genuine COGNITION (`cog`) | The reading demand |
|---|---|---|
| 1 ★ | **Read single-digit (0-9)** (`read-single`) | recognize a 1-digit numeral (font-invariant / from its name) |
| 2 ★ | **The 0-case** (`read-zero`) | zero-as-a-numeral (the explicit K.CC.A.3 0-parenthetical; a known stumbling block — a genuine hard-case) |
| 3 ★ | **Read a teen (10-20)** (`read-teen`) | two-digit reading (read 14 as *fourteen*, not "one four") — a genuinely harder skill than single-digit |
| 4 ★ | **Audio cross-modal** (`hear-find`) | map a SPOKEN number-word → the WRITTEN plate (no glyph to copy — the strongest reading-forcer; a distinct receptive CHANNEL) |
| | **DISTRACTOR/PRESENTATION CONFIGS (vary the reading demand within a cog — NOT separate cognitions):** | |
| a | **cross-font** (always-on for visual rounds) | the target glyph ≠ the plate typeface → must read abstractly, not pixel-match (the anti-shape-match) |
| b | **teen-reversal distractor** (13 vs 31) | the distractor differs only by digit ORDER → read left-to-right (the signature trap config of `read-teen`) |
| c | **same-tens distractor** (14 vs 13 vs 15) | first digit identical → the ones digit decides (defeats first-digit-matching — config of `read-teen`) |
| d | **dense-block** | several houses, several plates, one target → recognition under visual-search load |

- **Honest framing (the critic's de-padding + §A.13.60):** **~4 genuine recognition cognitions** (read-single / read-zero / read-teen / audio-cross-modal) — NOT the 8 the synthesis padded. **CUT** (the critic): #8 match-a-count (envelope N stamps → house N — that's *quantity→numeral = Game 20's PRODUCTION face*, the blur; the struck K.CC.B.5-light drift) + #6 6-vs-9 rotation (a visual-orientation trick a shape-matcher also passes — demoted to a distractor-flavor). The teen-reversal (b) + same-tens (c) are DISTRACTOR-CONFIGS of `read-teen`, not separate cognitions (honestly labeled — the §A.13.60 loophole the critic named). The **≥7 distinct ROUNDS** (DATA requirement) are met by the 4 cognitions × the presentation/distractor configs (read-single cross-font, read-single audio, read-zero, read-teen cross-font, read-teen reversal-distractor, read-teen same-tens-distractor, read-teen audio, dense-block) — honestly = configs of 4 cognitions, the number-variant blocklist enforced, **cross-font/audio always-on** (the reading-forcer). Order-only reshuffle.
- **Free slice = read-single (audio) + read-teen (cross-font, reversal-distractor) + the 0-case** — the reading-forced core visible immediately.

## 5. Pedagogy
- **K.CC.A.3 recognition-face instantiation (reading is load-bearing):** the child READS a written numeral 0-20 (knowing 14 = *fourteen*, font-invariant or from its spoken name) and maps it to the house — proven by the cross-font + audio presentations where a shape/template-matcher CANNOT win (no identical glyph to copy). Reading, not matching, is the only path.
- **THE KEYSTONE RULES (non-cheatability — the critic's fixes):** (i) **TEMPLATE-MATCH DEFEATED** — every visual target is CROSS-FONT (≠ the plate typeface) + AUDIO rounds (no glyph); same-font glyph rounds CUT → a non-reader matching squiggles cannot win. (ii) **NUMERAL-ANSWER-CHANNEL + ROUTE-AS-RENDER-ARTIFACT** — `deliver()` reads the NUMERAL of the tapped house (not a coordinate/path); the route (`pointer-events:none`) extends only on a correct delivery; NO draw gesture → the navigation cheat is unimplementable. (iii) **CONFUSABLE-DISTRACTOR + POSITION-DECORRELATED** — every round has a digit-confusable distractor positioned so nearest/in-order lands wrong; numeral↔position Spearman ρ≈0 → a navigation-only solver is at chance. (iv) **NON-LEAKING REDIRECT** — a wrong tap names the read numeral, never the answer/high-low/spatial. (v) **SINGLE-ENVELOPE-PER-DELIVERY** (no sequence to reproduce → no Game-13 collision). (vi) **RANGE 0-20.**
- **The shape-match confound is the cohort through-line one level deeper (the critic's catch):** a same-font glyph target lets a non-reader template-match "14"→"14" (pixel-shape, no /fourteen/); the confusable-distractor gate is powerless against it (13/31 is *more* shape-matchable). The cross-font + audio presentations are the only design where reading (font-invariant recognition / hear-the-name) is forced + the gate can discriminate a reader from a matcher. This is why the visual target is never same-font.
- **also_teaches (re-based per the pedagogy ruling):** **NONE.** Ordinals ("first/then/last") survive ONLY as supporting math-talk vocabulary (no CCSS code) — and are DROPPED from the UI entirely per the critic (the per-locale ordinal-grammar trap). **STRIKE RF.K.3.c** (phonics — no letter-sound), **STRIKE 1.NBT.A.1** (Grade-1 count-to-120 — ceiling violation), **STRIKE RF.1.1** (Grade-1 print concepts — drift). (The cut match-a-count variant would have pulled K.CC.B.5 — also gone.)
- **Number range (pedagogy):** **0-20** (matches A.3's explicit "0 to 20" + the 0-parenthetical); ladder single-digit → teens → the reversal/same-tens distractor configs (the difficulty peak). **1-3 deliveries/round, ORDER-FREE** (no ordinal sequence to reproduce — more stops = sequencing/memory = the Game-13 cheat). No three-digit / count-to-100.
- **Distinctness from Game 20 + Game 13 + Game 4:** Game 20 = PRODUCE the numeral (generative — count→write); this = READ it (receptive — recognize 0-20); a real developmental asymmetry (recognition precedes production). Cross-game guard: Game 20 never shows the target numeral pre-production. Game 13 = sequence-following (count-on); this = independent single reads. Game 4 = compare; this = recognize. If the game could be won by shape-matching (no reading), it's a flashcard — REJECTED (the cross-font + audio + the gate's template-match-solver are the guard).
- **No-shame + §20.8 demonstrate-don't-touch:** the catalog ordinal-sequencing only TOUCHED numbers (decoration) — a removal candidate; the cross-font/audio recognition DIRECTLY instantiates numeral reading — the gate (navigation-only + template-match solvers both fail; number-recognizer passes) is the structural proof. Wrong → Pip patient + non-leaking; the resident's joy is the intrinsic reward.

## 6. Interaction & UX
- **Runtime: read → tap → route (the numeral-answer-channel).** `mail-route-core.js` holds `{ cog, targetValue (0-20), present:'audio'|'cross-font', houses:[{hid, numeral, gx, gy, resident}], deliveredOrder:[] }`. Mutators: `deliver(hid)` → `{readNumeral: house.numeral, targetValue, matched: readNumeral===targetValue}` (**reads the NUMERAL, never a coordinate/path**); on matched, append `hid` to `deliveredOrder` (the route source — `pointer-events:none`, render-only, NO draw handler). `present==='audio'` → no envelope glyph (TTS only); `present==='cross-font'` → the envelope glyph in `targetFont ≠ plateFont`. **Position↔value decorrelated** (Spearman ρ≈0, gate-enforced); the correct house is never the nearest/leftmost/in-order.
- **State separation (anti-cheat):** `snapshot()` exposes `{ cog, present, houses (numerals + positions), deliveredOrder }`; `facts()` exposes per-round `{ answerChannelIsNumeral (===true), routeIsRenderOnly (===true, pointer-events:none), targetIsCrossFontOrAudio (===true — never same-font glyph), confusableDistractorPresent, correctNotNearestOrInOrder, posValueDecorrelated (ρ<0.2), plateFontLegible (min size), firstAttemptCorrect }` for the gate.
- **The read→deliver interaction:** the envelope (audio: Pip speaks + a 🔊-replay; cross-font: the glyph in a different typeface) → the child taps a house (a `<g role=button>` with a ≥44px invisible hit-rect + a legible plate-text). - **Mobile @280px (the critic's legibility + cap fix):** vertical stack — the envelope/target top, the scattered map (SVG `viewBox`, `width:100%`), the satchel vessel. **HOUSES CAPPED 4-5 at ≤360px** (6 above) — because the **PLATE-TEXT legibility** (a two-digit numeral readable, ≥ a min font, in a contrast pill) is the real constraint, NOT just the ≥44px hotspot (a 44px hotspot with 9px text fails the *reading*).
