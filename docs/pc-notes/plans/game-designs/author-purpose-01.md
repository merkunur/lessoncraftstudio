## §1 — Concept / world
The Lighthouse Keeper. The author is a PERSON on the shore who WANTED something; the child reads a short message (2-4 sentence snippet) and sends it to the HARBOR matching the author's WISH/INTENT. The three harbors are phrased as the author's MOVE (not the reader's effect — F2 fix): "the author wrote this to **TELL you facts**" (inform) / "to **TELL a fun story / be playful**" (entertain) / "to **SHOW you how to do it**" (instruct). The graded core is SORT mode (1 snippet → tap the harbor) over SAME-TOPIC divergence; smaller pool (mid-size). A non-numeric abundance vessel (the harbor town lights up; never a count).

## §2 — The standard + the load-bearing cognition
**RI.2.6 (SOLE tag, NO also_teaches)** — identify the author's PURPOSE (inform/entertain/instruct). **FENCES:** RL.K.5 text-type/genre (the FORMAT cheat — the cardinal sin; never "is this a story or a fact-book?"), RI.K.2 main-idea (WHAT, not WHY), RI.1.5 locate (WHERE), **effect-on-reader/feelings** (reader-response — a DIFFERENT family; the prompt is ALWAYS author-intent "what is the author trying to DO," NEVER "how did it make YOU feel"), RI.1.6 author-identity, persuade (Grade-3+, EXCLUDED). **Cognition:** the author's INTENT (why they wrote it), NOT (b) format/genre, NOT (c) effect-on-reader. Three categories INFORM/ENTERTAIN/INSTRUCT (the standard's "answer/explain/describe" all live within INFORM; the foils give contrast). Snippet 2-4 sentences (~20-45 words), Grade-2 decodable, DISPLAYED as TEXT (the child READS — it's RI, not SL), click-triggered TTS scaffold (never auto-play, never the primary channel).

## §3 — THE ARCHITECTURE REWORK (the heart; the deepest flaw + fix)
**The critic's deepest catch — the machine gate proves SELF-CONSISTENCY, the design treats it as VALIDITY.** The swap-invariance gate proves `surface ⊥ purpose` (surface solvers ≤chance, oracle reads the `purpose` tag = 100%) — but the oracle reading the tag it's scored against is a **tautology**; the gate is CONSTITUTIONALLY BLIND to whether the GOLD is the answer a competent Grade-2 child (and competent native adults) would give. The ONE-DOMINANT-PURPOSE LAW is therefore an **unenforceable aspiration** (the gate can't read English). Author's purpose is inherently contestable (a text can inform AND entertain), so the machine gate happily certifies a 50/50 item, the game GRADES the child against a private gold → the Game-30 shame machine + a measurement-VALIDITY failure. **WORSE — the divergence items the assessment RESTS ON are the MOST contestable** (a numbered fact-countdown [inform] vs numbered steps [instruct] is genuinely 50/50 to literacy experts). (The Game-58 circular-gate lineage: a measured gate proves self-consistency, never validity.)

**THE FIX — TWO ORTHOGONAL ship-blocking gates, ANDed:**
1. **The machine SWAP-INVARIANCE gate (surface-can't-win)** — every format AND topic carries ≥2 purposes; keyword-decorrelated; the armed surface solvers (FORMAT/TOPIC/KEYWORD/LENGTH/POSITION) measured on a HELD-OUT train/test split score ≤chance; the oracle (reads the tag) = 100%; the render STRIPS the surface tags (`ANSWER_NOT_SURFACE_RECOVERABLE`).
2. **The human BLIND-AGREEMENT pilot (the-gold-is-the-competent-answer — the Game-58 non-author validity channel)** — ≥N independent native K-3 reviewers classify each snippet BLIND to the authored gold; **UNANIMITY required, tiered harder for the more-contestable item-types** (≥3/3 prototypical + same-topic / ≥5/5 same-format + which-of-3); ANY disagreement → **QUARANTINE** the snippet (re-author a cleaner one — NEVER lower the bar). A per-snippet `blind_agreement:{n,agreement,pass}` STAMP; the machine gate HALTs the deck build if any snippet lacks/fails the stamp. **The human panel IS the executable form of the semantic LAW the machine can't enforce.**
3. **The structural corollary (operator-confirmed MID-SIZE):** the SAME-FORMAT divergence rung — the supposed "load-bearing assessment" — is genuinely contestable → it can't clear 5/5 unanimity → **DEMOTED to ungraded scaffold/discussion.** The GRADED assessment falls to the reliably-unambiguous class: **SAME-TOPIC divergence** (the same dog-text written to inform vs entertain vs instruct — clear because the CONTENT itself differs). Same-topic triads are the graded load-bearing assessment.

## §4 — Anti-cheat architecture (two channels)
- **CONTESTABLE-GOLD / child-vs-gold (the deepest) — killed** by the human BLIND-AGREEMENT HITL gate (§3.2; tiered unanimity; quarantine; per-snippet stamp; ship-blocking).
- **FORMAT / TOPIC / KEYWORD — killed** by the machine swap-invariance gate: `EVERY_FORMAT_HAS_≥2_PURPOSES` + `EVERY_TOPIC_HAS_≥2_PURPOSES` + `KEYWORD_DECORRELATED_FROM_PURPOSE` (by CONTENT — cue words appear across all 3 purposes NATURALLY; **NOT** the Designer-A keyword-POISON / adversarial-planting, which manufactures contestability and fights F1; the machine + human gates must AGREE the cues are invisible to purpose — F7) + `MARGINAL_SWAP_PAIRS_PRESENT` + `PER_BIN_BALANCE` + the held-out-split surface solvers ≤chance + `ORACLE` 100% + `ANSWER_NOT_SURFACE_RECOVERABLE`.
- **INSTRUCT/INFORM boundary (F3):** an INSTRUCT gold requires a performable SEQUENCE (≥2 imperative steps the reader does in order); an INFORM gold has ≤1 incidental imperative and NO performable sequence; all instruct/inform pairs routed through the 5/5 panel.
- **WHICH-OF-3** (if kept as a non-graded enrichment): all three snippets through 5/5 blind agreement + `WHICH_OF_3_TARGET_UNANIMOUS` (a panelist independently picks the same single target).
- **Wrong-tap re-show — no-reveal:** points at the author's MOVE IN THE SNIPPET (cites the intent-bearing clause — "the writer is *telling you how* — look, 'first… then…'"), never asserts the category; legitimate now because only defensible-gold items ship (F4).
- ≥7 variety after the divergence-presence gate (≥2 same-TOPIC triads GRADED).

## Cohort doctrine this game adds
**The SELF-CONSISTENCY-vs-VALIDITY / TWO-GATE lesson — PROGRAM-WIDE.** For a comprehension/judgment game whose answer is an AUTHORED HUMAN JUDGMENT (author's purpose, main idea, tone, theme, character-trait), a machine SWAP-INVARIANCE gate (the same surface carries ≥2 answers → surface solvers ≤chance on a held-out split, the oracle reads the tag = 100%) proves ONLY **SELF-CONSISTENCY** (no surface feature predicts the gold). It is CONSTITUTIONALLY BLIND to **VALIDITY** (whether the gold is the answer a competent child / native adult would give) — because the oracle reads the very tag it is scored against (a tautology). A semantic authoring LAW ("one dominant answer all reasonable adults agree on") is UNENFORCEABLE by the machine gate (it can't read), so when the answer is contestable — and author's purpose is INHERENTLY so (a text can inform AND entertain) — the machine gate certifies a 50/50 item and the game GRADES the child against a private gold → the Game-30 shame machine + a measurement-validity failure. **The fix: TWO ORTHOGONAL ship-blocking gates, ANDed — (1) the machine swap-invariance gate (surface-can't-win) + (2) a HUMAN BLIND-AGREEMENT pilot (the Game-58 non-author validity channel): ≥N independent native reviewers classify each item BLIND to the gold; UNANIMITY required, tiered HARDER for the more-contestable item-classes; ANY disagreement → QUARANTINE; a per-item agreement STAMP the machine gate checks + HALTs on. The human panel IS the executable form of the semantic LAW the machine can't enforce.** And the structural COROLLARY: the MOST contestable item-class (here same-FORMAT divergence) — often the very one the design WANTS as the load-bearing assessment — may be UNGRADEABLE (it can't clear unanimity); the graded assessment must fall to the reliably-unambiguous class (here same-TOPIC divergence, where the CONTENT itself differs), with the contestable class demoted to ungraded scaffold — and that ceiling can scale the whole game down (a flagship → a mid-size activity). Generalizes to EVERY authored-judgment comprehension game in the catalog: the machine gate proves surface-independence; ONLY a non-author human panel proves the gold is the competent answer; and you can only GRADE the item-classes that clear unanimity. (Companion: an "intent" category whose label is a reader-EFFECT verb ["enjoy"] smuggles the fenced reader-response family back in — label it with the author's MOVE ["the author is playing / telling a fun story"], not the reader's feeling.)
