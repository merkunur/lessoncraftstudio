## The skill
Put 3 to 5 objects in order from smallest to biggest (or shortest to tallest) by comparing them directly.

## The apparatus and its invention
THE HEADLINE THAT MUST CLIMB. A photographer's riser stand: 3–5 empty spots on one level floor line and a faint dashed 'headline' rising from the first spot to the last. A tray holds ONE library picture at 3–5 sizes (sizes measured from the ink box, ≥ 18 % apart). The child drags each picture onto a spot; dropped, it stands on the floor line, so tops are compared from one baseline. When every spot is full the child taps the camera: each neighbour pair that breaks the climb flashes and the two lean toward each other ('swap us'); tapping the pair swaps them. Miss 2: faint height ticks appear behind the row. Right: the camera flashes and the photo slides into a small album strip above the stand. 'Biggest first' rounds turn the headline downhill.

- **Misconception the apparatus makes visible:** Ordering only the two extremes and dropping the middle ones anywhere; judging by width instead of height.
- **Pictures:** one noun per round, uniformly scaled: height rounds use tall nouns — zoo-animals/giraffe, vegetables/carrot, christmas/candle, kitchen-tools/bottle, classroom/pencil, flowers/sunflower, space/rocket, beach/lighthouse, tools/ladder; size rounds use fruits/apple, toys/ball, farm-animals/pig, bakery/cupcake
- **Settings:** Pictures: 3 / 4 / 5 · Order: smallest (shortest) first / biggest (tallest) first
- **Rounds:** 9 rounds per count; sizes ≥ 18 % apart; the tray order is never already sorted or reverse-sorted, and the biggest picture appears in every tray position across a pass; height and size rounds alternate; order-only reshuffle.
- **Worksheet types it covers:** K-033, K-034, K-036
- **Distinct from:** Not the Nesting Pots (#22: orders NUMERALS, sizes hidden); not the Faraway Shelf (grade 1: indirect length against a cord). Here the size is the visible attribute and the order is built and checked neighbour by neighbour.
- **Build risk:** Library pictures have different whitespace: heights must be measured from the INK box (the maze program already does this).
