## The skill
Find a square from its letter-number code (B2) and name the code of a square, on 5×5 to 10×10 grids.

## The apparatus and its invention
A grid with letters along the top and numbers down the side. Each letter and number is a LIGHT SWITCH: tapping B lights the whole column B, tapping 2 lights row 2, and the one square where the two beams cross glows. The child paints the crossing square with its group colour; a hidden picture appears square by square. Code mode: a square is already painted; the child switches on the column and the row that cross on it and the code is written from the two switches.

- **Misconception the apparatus makes visible:** Reading the code as row-then-column (2B for B2) or counting the label row as square 1.
- **Pictures:** none (grid apparatus); the revealed picture is pixel art made of grid squares
- **Settings:** Grid: 5×5 / 6×6 / 10×10 · Mode: find the square / write the code
- **Rounds:** ≥ 8 rounds = 8 pixel pictures per grid size, each with 6–12 coded squares in random order; codes never repeat; code-mode squares spread across all rows and columns.
- **Worksheet types it covers:** G2-279, G2-302, G2-303, G2-308
- **Distinct from:** Parking Tower teaches position words; no activity uses coordinates.
- **Build risk:** Low. Letter labels per locale alphabet (A–J is safe in all 11).
