## The skill
Copy a picture square by square onto an empty grid, first by looking, then by using letter–number labels.

## The apparatus and its invention
THE COPY THAT SLIDES OVER THE MODEL. A model mosaic (6×6, later 8×8) and an empty grid of the same size (side by side ≥ 560 px; stacked model-above-copy on phones). The child picks a colour pot and taps squares on the empty grid to tile them (tap again to clear). Check: the copy slides over the model like a transparency sheet. Right: the two merge and the hidden library picture the mosaic depicts fades in under it. Miss 1: every square that disagrees flickers in BOTH grids at once, so the error is located exactly; the copy slides back. Miss 2: the row with the first mismatch is outlined across both grids. LABELLED setting (K-299/K-300): rows carry numbers, columns letters (A–H); tapping a model square lights its letter-number pair, and the same pair glows on the copy — the coordinate is the bridge. G1-416 (draw with the grid) is the 8×8 set with no labels.

- **Misconception the apparatus makes visible:** Losing the row when counting across, and mirror-copying (counting columns from the wrong side).
- **Pictures:** none (tiles in the shell palette); optionally a library picture as the "finished" reward revealed under the completed mosaic
- **Settings:** Grid: 6×6 no labels / 6×6 labels / 8×8 labels · Colours: 1 / 2
- **Rounds:** 9 model pictures per grid size, each asymmetric left-right (a mirror copy is always wrong) and with 8–16 tiles; one right copy (a construction, no answer position).
- **Worksheet types it covers:** G1-416, K-286, K-298, K-299, K-300
- **Distinct from:** No grid or coordinate activity exists below the tools.
- **Build risk:** Tap targets: 8×8 at 320 px stacked = 34 px cells (cell floor met, ≥ 34); 2-colour pots ≥ 44 px. Labels A–H safe in all 11 alphabets.

## Merged into this instrument (cover each as a setting or round set)
- grade 1 "The Grid Copy Loom" (grid-copy-loom): Copy a picture square by square onto an empty grid by keeping track of rows and columns. — TWO LOOMS: a coloured mosaic on the left loom; an empty loom on the right. The child taps a cell on the empty loom and picks a colour bead; a finger-shadow follows the same row and column on the model so the child can check. When a row is finished, a slider bar runs across both looms and marks any cell that does not match. A "no guide" setting hides the shadow.
