## Date-key gotcha (relocated from MEMORY.md index, 2026-07-30)

⚠ **`_dateKey` is NOT string-comparable.** The `Y-M-D` form built without zero-padding sorts
lexically wrong — `'2026-7-9' > '2026-7-10'` is **true**. Compare day keys with **equality only**,
never `<`/`>`. Affects every tool holding a day slot (#24 Feelings Check-In, Center Board,
Calendar Wall). Companion rule for the same family: a child's day slot carries **no history** —
one closed slot, and the day-roll is an *invariant of access* (`_today`/`_commitDay`), because
`center-board.js` runs its roll in `init` only and so never rolls when an async entitlement swap
brings the class board in later.
